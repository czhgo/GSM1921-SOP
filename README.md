## 💡 核心机制（条条与块块）

**支部双线管理体系：**

- **条条（纵向业务线）**: 党小组组长 - 负责具体活动组织和品牌建设
  - 储子禾（第一党小组-学术组）
  - 王峥旭（第二党小组-就业组）
  - 辛长乐（第三党小组-就业组）

- **块块（横向职能线）**: 支委委员 - 负责制度建设和职能保障
  - 侯嘉嵘（组织委员）- 党员发展、考察档案、信息平台
  - 闫鑫岳（宣传委员）- 宣传档案、材料模板、活动记录
  - 韩思宁（纪检委员）- 考勤管理、活动监督、参与记录

**协作原则**: 条条主导活动组织，块块提供职能支撑
