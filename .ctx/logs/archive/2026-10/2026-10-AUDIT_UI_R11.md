# R11 前端脏乱繁审查

## 一、使用的 skill 与审查方法

实际加载并对照使用了 11 个：`frontend-design`、`better-typography`、`better-colors`、`better-layout`、`better-ui`、`better-interface`、`better-accessibility`、`better-writing`、`design-with-taste`、`trae-remote-official:web-app-development:uicraft`、`web-design-guidelines`（后者按 skill 要求拉取了 vercel-labs 的现行规则原文）。

| skill | 本轮 lens | 主要落点 |
|---|---|---|
| better-interface | 先定范围、证据优先、一个根因一条发现、便宜修法优先（删 > 平台 > 复用 > 改值 > 新增） | 分级与去重口径 |
| better-typography | 语义化字号档、行高、measure、tabular-nums | 10px 描述、14/16 倒置 |
| better-colors | 只报实测对比度、token 归属、一个颜色一个含义 | 1.24:1 边框、1.07:1 浅底、2.04:1 警示色 |
| better-layout | 用间距分组、控件与内容可辨、共享对齐边 | 按钮独行、指标带间距 |
| better-ui | 同心圆角、边框承载结构、状态可静态回读 | 12/8px 嵌套圆角、按钮 border |
| better-accessibility | 原生优先、可访问名、焦点环、模态闭环 | 未绑定 label、toast live region |
| better-writing | 标签即说明、空态给下一步、按钮动词 | 繁判定表 |
| design-with-taste | 一屏一个主行动、渐进披露、状态变化要留静态线索 | 按钮分层、三角 |
| frontend-design / uicraft | 结构即信息、克制装饰 | 页签分区、指标带 |
| web-design-guidelines | 表单/焦点/动画/语气硬规则 | label、placeholder、transition |

方法：① 以 spec 的「现行事实」为线索逐条回读当前 HEAD（不采信旧行号）；② 对可计数项做全仓静态计数；③ 以项目自有规范（`content/04_web_design/design-system/DESIGN_SYSTEM.md` §3.2.1/§3.2.2/§4.3/§4.1.1）作为「不合格」的第一依据，skill 作为第二依据；④ 对比度按 sRGB 相对亮度手算，凡未实测的运行时行为一律标「未真机验证」。量化基线：`styles.css` 4888 行、347 处 `!important`、266 个 hex、214 处 `theme-dark`；`docs/src` 303 个 js 中 1675 处 `text-xs`、547 处 `text-sm`、101 处 `text-base`、530 个内联 `style="`、316 处 `text-[10px]/[11px]`（50 文件）、271 处 `rounded-xl`、253 处 `rounded-lg`、64 处 4px `rounded`。

## 二、支书本轮 9 条反馈 → 代码位置

**1 黑边 / 缺描边 / 输入框不统一。** 真源是 `.input-flat-sm` 只有 `padding/font-size/radius`，**无背景、无描边、无 focus 规则**（`docs/src/styles.css:701-706`），而它被单独用在 10 处：`components/ui/modal.js:323`、`:325`，`entries/tabs/org/member-flow-tab.js:302,306,310,322,424`，`entries/tabs/org/inspection-tab.js:344`，`entries/tabs/disc/attendance-tab.js:703`，`entries/pages/activity-entry.js:111`。全局焦点环选择器只列了 `.input-flat`（`styles.css:2763-2770`），`.input-flat-sm` 键盘聚焦无可见环。另有 7 处控件被 `text-sm` 拉到 14px（`components/record/taskforce-view.js:227,229`、`components/governance/workgroup-member-editor.js:60`、`components/governance/signup-panel.js:94,99`），2 处被 `rounded` 压成 4px（`components/feedback/issue-detail.js:153,157`）——均违反 §4.3 ③（`DESIGN_SYSTEM.md:924`）。**事实纠正**：spec 列的 6 处「无颜色 `border`」（如 `entries/tabs/secretary/calendar-tab.js:249`、`entries/tabs/disc/attendance-tab.js:76`、`components/governance/org-setup-wizard.js:677`）实测另有 `.btn-tab` 的 `border-color`（`styles.css:1401`）或内联 `border-color`（`entries/tabs/secretary/group-progress-tab.js:436`）兜底，**不产生黑边**；当前唯一确定的深色边框是 `docs/help.html:68` 的 `border:1px solid`（无颜色 → currentColor #374151）。真正的观感来源是：`--neutral-200 #E5E7EB` 边框落在 `#FFFFFF` 卡片上对比度仅 **1.24:1**（<3:1），肉眼即「没有描边」。

**2 页签分区标识丢失。** `components/shell/tab-bar.js:232-248`：`groupLabel` 只用于判重，DOM 输出的是空 span；`isFirstGroup` 走 `:240-242` 直接丢弃首组标签。CSS 对应 `.tab-group-label` 为 1px 竖线（`styles.css:2058-2066`），≤1024px 整段隐藏（`:2067-2069`）。数据侧分组名健在（`capabilities/org-workspace.js:47,71,73`、`leader-workspace.js:33,56,61` 等）。党委台只有一个组（`capabilities/party-committee-workspace.js:25,30,31` 全为「党委治理」），按现逻辑**永远无任何分组视觉**。

**3 今天/待办中性色与字体、指标带灰底、圆角不一。** 今天页使用 4 档 Tailwind 灰（`text-gray-800` 13 处、`700` 3 处、`600` 2 处、`500` 14 处，`entries/tabs/today/today-tab.js`），同层 h3=800、h4=700，无角色表；计数不用中性色而用内联 `color-mix(accent 60%, #000)`（`:142`、`:159`）。**事实纠正：今天页没有指标带**（全文件 0 处 `metric-band`）；指标带只在待办：`components/record/todo-tab-shell.js:164-177`，样式 `background: var(--neutral-50)`（`styles.css:4616`）、带 12px（`:4618`）而 item 8px（`:4633`）。圆角另有两套：卡片恒 12px（`:351-356`），`rounded` 4px 仍有 59 个 class（如 `components/dashboard/stats.js:49`）。

**4 summary 三角。** 全仓 33 处 `<summary>` / 24 文件，只有 3 处做了去三角：`styles.css:4960-4966`（row-more）、`:5210-5219`（modal-fieldset）、`components/governance/workgroup-member-editor.js:52`。**没有一处** summary 带 chevron（逐行扫描 `chevron|icon(` 命中 0）。待办页顶部折叠条就是裸三角：`todo-tab-shell.js:385`；归档折叠区同样（`entries/tabs/prop/archive-tab.js:103`）。

**5 按钮文字色、archive-upload-btn、p 小字。** ① 主题色变体的文字被统一成近黑：`--app-accent-text: #1F2937`（`styles.css:113`）→ `.btn-accent-soft`（`:924-931`）、`.text-accent`（`:1016`）、页签选中 `color-mix(...,45%,#000)`（`:2052`）、设置侧栏选中（`:3989`）全部落到中性黑；源头是 `accentButtonColors()` 对亮色主题同时返回 `ink` 与 `text` 为 `#1F2937`（`core/domain/constants.js:635-637`）。② `archive-upload-btn` 为 `btn-accent-soft text-xs px-3 py-2`（`entries/tabs/prop/archive-tab.js:90`），三个类的字号/内边距都被 `!important` 压掉（`styles.css:4102-4103`），实得 32px 高、左右 12px，且独占一行右对齐（`:89`），旁边无同排控件，故显「逼仄」。③ 「p 小字」的可量化根因：`--text-xs: 0.625rem`＝**10px**（`styles.css:151`），被用于页签描述 `.page-frame__description`（`:415-419`，由 `components/shell/page-frame.js:29` 在所有 tab 输出）、弹窗分组标题（`:5206`、`:5212`）、首页图片卡 meta（`:5052,5071,5099`）。同一组件族里 `.page-section__description` 却是 13px（`:465-469`），同屏 10px 与 13px 并存。

**6 按钮太单薄。** `.btn-accent` 只声明背景与文字（`styles.css:915-920`），**没有 `border-color`**，而尺寸段强制 `border-width:1px`（`:4091`）；`.btn-outline` 是白底 + `#E5E7EB` 1px（`:956-964`），边界对比 1.24:1。高度 32px 与输入框 38px 不同档（`:4101` vs `:595-597`）。`.btn-accent-soft` 只有 `:hover`，**没有 `:disabled`**（`:924-931`；其余族类都写了 disabled）。

**7 字体字号组件脏乱繁。** 三套并行：Tailwind 档（12/14/16）、CSS token（`--text-xs` 10 / `--text-sm` 12 / `--text-base` 14，`styles.css:151-158`）、rem 字面量（0.6875rem 11px、0.8125rem 13px 遍布）。同名不同值：`.text-xs`＝12px，`--text-xs`＝10px。`--text-*` 全文件只被消费 20 次，等于「有 token 无系统」。`font-title-cn` 强制 800（`:306`），被用于 12–14px 的 h4 与卡片小标题（如 `today-tab.js:135`）。`html.font-size-large` 又对同一批类做第二套映射（`:170-199`）。

**8 toast / modal 是否合格。** 不合格项见 P0-03/04/05：`showToast` 以**全局**在途写判定成功（`core/base/utils.js:87-98`），`entries/pages/activity-entry.js:657-660` 在 `catch` 之后仍报成功并立刻 `reload`，`services/governance/issues.js:513-523` 失败只 `console.warn` 仍返回成功对象；toast 容器 `role=status`、`pointer-events:none`、2.5s 无条件消失、无关闭/暂停/去重/上限（`utils.js:104-167`）；modal 有 `role=dialog`、`aria-modal`、背景 `inert`、焦点进入与回还（`components/ui/modal.js:56-64,164-166,205,242`），但**无滚动锁定、无 Tab 循环、提交中仍可 Esc/遮罩/×**（`:216-236` 常驻；`:402-410` 只禁按钮），错误区无 `role`（`:305`、`:345`），`onSubmit` 返回 `undefined` 被当成功（`:424-431`）。

**9 CLAUDE 清理。** `CLAUDE.md` 乙部 26 行（`:830-856`）中 10 行已标完成/已实施/已澄清：`B-500-3`（`:832`）、`B-500-10`（`:839`）、`B-502-7`（`:846`）、`B-503-1`（`:847`）、`B-503-2`（`:848`）、`B-503-3`（`:849`）、`B-503-4`（`:850`）、`B-503-7`（`:853`）、`B-504-1`（`:854`）、`B-504-2`（`:855`）。同一件「R6/R7 P3 余项」被写了三行：`B-502-3`（`:842`）、`B-502-4`（`:843`）、`B-503-6`（`:852`）；`B-504-3`（`:856`）又第三次指向 R10 P3 文案。可无引用直接退出的 8 行为 `:832,839,846,847,849,850,853,855`。
