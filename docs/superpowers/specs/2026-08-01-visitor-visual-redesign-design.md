# 普通参与者界面视觉重设计（打样）— 设计文档

> 日期：2026-08-01
> 状态：书记已批准设计，进入实施
> 任务：普通参与者（visitor）界面视觉重设计——系统最大使用者不应"满目灰色"；本设计为其他角色界面"打样"。

---

## 一、背景与问题

1. 系统最大使用者是普通参与者，但 `participant` 的整个主题色为灰色 `#6B7280`（`docs/src/core/constants.js` ROLE_COLORS.participant）。灰色同时承担"身份色"与"中性色"两个角色，导致参与者界面只剩结构性灰色，视觉压抑。
2. 其他角色均有特定主题色 + 右上角角色 div 标记；参与者没有独立标记（灰色 div 即其标记）。
3. 书记核心洞察：**"没有标记就是普通参与者的标记"**——用"缺席"表达"默认"。参与者是系统的默认态、最大基数，不需要被强调。

## 二、设计决策

### 决策 1：四层完整色板（书记已确认"两个品牌色够用，需补状态语义色"）

| 层 | 色值 | 用途 |
|----|------|------|
| 品牌·党建红 | `#CE1126`（不变） | 主题色：tab 高亮、标题装饰条、主按钮、党务标签 |
| 品牌·党徽金 | `#FFD700`（原 #D4AF37，书记要求"再亮一些"） | 辅助色：主题党日/活动/考察成长元素，用量上调（徽章、进度、数字强调、装饰） |
| 状态·语义 | 完成绿 `#16A34A` / 提醒琥珀 `#D97706` / 告警红 `#EF4444` | 考勤、待办、通知的状态表达；与品牌红 #CE1126 区分（品牌红=标签语境，告警红=数字/图标语境） |
| 底色·暖白 | `#FAFAF5` | 页面背景替代纯白，衬托红金暖色系 |
| 中性·灰 | `#6B7280`（降级） | 仅文字层级、边框、分割线 |

金色微调配套值：深文字 `#B45309`（琥珀棕，用于亮金背景上的文字）、亮金浅背景 `rgba(255,215,0,0.12)`、亮金边框 `rgba(255,215,0,0.35)`。

### 决策 2：右上角无标记 + 全局不出现「普通参与者」字样

- `header.js` `_roleLabelHTML`：`role === 'participant'` 时不渲染 role-label div（无标记=默认）。
- 主要界面（visitor 工作台、首页）不出现「普通参与者」字样；帮助页等说明性页面可保留解释性描述。
- 身份表达替代：欢迎语（"欢迎回来，{姓名}"）。

### 决策 3：页面映射（visitor 5 tab）

- 全局：暖白底、tab 高亮红、卡片装饰条红、主按钮红。
- 待办：党务待办红标签 + 状态色（完成绿/过期告警红）。
- 项目分工：金色系（分工标签、进度条）。
- 活动动态：活动标签沿用红/金分类（三会一课红、主题党日金）。
- 考勤概况：状态色主导（出勤率、请假琥珀、缺勤告警红）。
- 我的考察：金色成长轨迹（徽章、时间线）。

### 决策 4：可复用规则（打样产出，写入 DESIGN_SYSTEM.md）

> **给定主体主题色 X 的配色规则**：X 做主视觉（高亮/按钮/装饰）→ 辅助强调色做功能点缀（参与者=金）→ 状态色全局统一（绿/琥珀/红）→ 暖白底全局统一 → 灰只做中性。
> 此规则即其他角色改版的"样板"。

### 决策 5：范围

仅 visitor 工作台打样（`workspace/visitor.html`）。首页、其他角色页不在此次范围，规则沉淀后另轮推广。

## 四、验证标准

1. visitor 工作台：无灰色主视觉元素（灰仅文字/边框/分割线）；红主金辅；暖白底。
2. 右上角无 role-label div；visitor 工作台与首页无「普通参与者」字样。
3. 金色活动标签显示为明亮金黄，不脏不闷。
4. 其他角色页面不受影响（回归验证）。
5. GetDiagnostics 零错误；浏览器实测通过。

## 五、修复轮补充（2026-08-01，书记反馈"红色太多"+"角色/活动色要区分"）

> 实施后书记实测反馈：visitor 工作台"几乎只要是彩色就是红色，颜色没有这么多样，且意义不明确"。经 AskUserQuestion 两轮确认后修正。

### 修正 1：角色色系与活动色系彻底分离

- **角色维度 = 冷色系**（统一来自 `constants.js → ROLE_COLORS`）：组织者=天蓝 `#0369A1`、深度参与=紫 `#7C3AED`、参与者=中性灰 `#6B7280`、发起人=靛蓝 `#4F46E5`。
  - participant 角色色**回归中性灰**（默认身份，"没有标记就是标记"），红色不再充当参与者角色色。
  - visitor 项目分工人员 chips、我的考察等级标签均改用 ROLE_COLORS 内联三件套（bg/text/border）。
- **活动类型维度 = 暖色系**（统一来自 `getActivityTypeColors()`）：三会一课=党建红 `#CE1126`、主题党日系=党徽金 `#FFD700`。
- 工作台 chrome（tab 高亮、主按钮）保持品牌红，不参与角色/活动语义。

### 修正 2：金色可辨性（金点描边 + 深金文字）

- 亮金 `#FFD700` 圆点 on 白底对比度约 1.4:1 不可辨 → `_ACTIVITY_TYPE_BASE` 金系条目增加 `text:'#B45309'` 与 `dotBorder:'rgba(180,83,9,0.35)'`。
- 所有金点渲染处（首页列表/画廊、archive 详情、visitor 列表/查询）加 1px 描边；日历视图日期数字用 `text`（深金）而非 `dot`。

### 修正 3：全站旧金统一 + 待办区去红

- `--party-gold` 全局提亮为 `#FFD700`（原 `#D4AF37` 偏灰），15 个 HTML 的 tailwind `gold`/`gold-light` 全量替换；`decision-tree.js`/`ws-secretary-entry.js` 旧金同步。
- 反馈页"增强"标签 `#D4AF37` on 浅金底 2:1 对比度不足 → 深金 `#B45309`。
- visitor 待办：卡片左缘色条改 `var(--party-gold)`、"标记完成"改状态绿 `#16A34A`，红色收敛到品牌语义。
- 查询视图 `accentColor` 为死参数，移除。

### 修正 4：版本化防缓存

- `CODE_VERSION` 1→3，15 个 HTML 模块参数 `?v=20260801`→`?v=20260803`，确保旧会话强制刷新加载新模块。
