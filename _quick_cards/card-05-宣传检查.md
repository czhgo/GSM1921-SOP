# 📢 宣传材料发布前检查清单 - 速查卡

> ⏱️ 阅读时间：2分钟

## ✅ 发布前必查 5 项

### 1️⃣ 内容完整性
- [ ] 时间、地点、参与人员
- [ ] 活动主要内容
- [ ] 活动亮点和成果
- [ ] 必要的背景说明

### 2️⃣ 格式规范性
- [ ] 标题清晰（活动名称 + 日期）
- [ ] 段落结构合理
- [ ] 字体大小统一
- [ ] 无明显格式错误

### 3️⃣ 照片质量
- [ ] 数量：至少10张
- [ ] 质量：分辨率不低于1920x1080
- [ ] 内容：全景 + 讨论 + 重点环节
- [ ] 构图：清晰、主题明确
- [ ] 命名：日期-活动名称-序号

### 4️⃣ 文字准确性
- [ ] 无错别字
- [ ] 人名、职务正确
- [ ] 时间、地点准确
- [ ] 数据真实可靠

### 5️⃣ 政治正确性
- [ ] 符合党的方针政策
- [ ] 无敏感信息泄露
- [ ] 表述规范得体

## 📋 材料提交标准

### 照片材料
| 项目 | 要求 |
|------|------|
| 数量 | 至少10张 |
| 质量 | ≥1920x1080 |
| 格式 | JPG或PNG |
| 命名 | 日期-活动名称-序号 |

### 文字材料
| 项目 | 要求 |
|------|------|
| 简要版 | 800-1000字 |
| 标准版 | 1200-1500字 |
| 详细版 | 1500-2000字 |

## 🔄 审核流程

```
宣传负责人提交 → 宣传委员初审 → 提出修改意见 → 修改完善 → 最终审核 → 发布/归档
```

### 时间节点
- 活动后 **3天内**：宣传负责人提交材料
- 活动后 **5天内**：宣传委员审核材料
- 活动后 **7天内**：完成修改
- 活动后 **10天内**：归档

## ⚠️ 常见问题

### 不合格的宣传材料
- ❌ 照片模糊或数量不足
- ❌ 内容空洞，缺乏实质
- ❌ 格式混乱，排版不规范
- ❌ 有错别字或事实错误
- ❌ 拖延不交或敷衍了事

### 如何提高质量？
1. 使用模板（活动总结模板）
2. 参考优秀案例
3. 提前与宣传委员沟通
4. 及时提交，留出修改时间
