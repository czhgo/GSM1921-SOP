## 审核流程

```
内容创作 → 初稿完成 → 宣传委员审核 → 修改完善 → 
支部书记审批 → 对外发布 → 效果评估
```

**审核要点：**
1. **政治性审核**：确保立场正确、用语规范
2. **准确性审核**：核实数据、时间、人名等信息
3. **合规性审核**：符合宣传规定和保密要求
4. **质量审核**：文字通顺、图片清晰、排版美观

## 注意事项

⚠️ **风险防控：**
- 涉及敏感内容必须上报审批
- 不得发布未经核实的信息
- 不得使用未授权的图片素材
- 不得泄露涉密或个人隐私信息
- 发布前必须经过规定审核流程

✅ **质量标准：**
- 主题明确、重点突出
- 文字准确、表述清晰
- 图文并茂、版式美观
- 符合党的宣传工作要求
- 传播正能量、弘扬主旋律
