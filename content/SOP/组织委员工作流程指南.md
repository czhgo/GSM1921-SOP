# 组织委员工作流程指南

> **一句话**: 统筹专班招募与党员发展全程管理。

## 适用角色

**组织委员**

在双域管理框架下，组织委员是 **「专班协调者」**：
- **党建域**：专班招募唯一统筹者（发起≠招募——书记/组长/支委均可发起，但只有组织委员能统一招募）
- **党务域**：党员发展全流程管理（考察档案 + 思想汇报 + 发展协助）
- **数据共享**：考察档案与纪检委员的考勤数据通用同源

---

## 党建工作台 — 专班协调视图（最高优先级）

> 在网页系统中，组织委员进入党建工作台·管理模式后看到的不是日历，是 **专班协调看板**。

### 信息流

```
专班发起者（书记/组长/支委）→ 发起专班
    │
    ▼
专班协调看板（组织委员可见）
    ├── 待启动列：已发起未开始招募的专班卡片
    └── 进行中列：正在执行中的专班卡片（展开可见子任务）
```

### 任务流

| 步骤 | 动作 | 时机 |
|------|------|------|
| 1 | 审查待启动列中的新专班需求 | 每周至少检查一次 |
| 2 | 点击「发布招募」→ 填写招募表单（名称/人数/技能/周期/说明） | 确定需求后 |
| 3 | 监控进行中列的子任务进展 | 持续跟踪 |
| 4 | 专班全部子任务完成 → 归档 | 完成后 |

### 验收成果

- [ ] 待启动列无超过 7 天未处理的专班需求
- [ ] 每个进行中专班有明确的招募计划
- [ ] 全部完成专班已在归档库中可查

> **⚠️ 网页待实现**：「发布招募」按钮当前仅弹出提示，招募表单填写功能尚未实现。

## 党务工作 — 三项核心业务

### 一、考察档案维护

**信息流**：
```
发展对象名单（支委会确定）
    │
    ▼
组织委员建立/维护考察档案
    │
    ▼
发展对象个人档案（含思想汇报 → 转正材料）
```

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 获取发展对象名单 | 支委会会议纪要 |
| 2 | 建立考察档案 → 存入 `content/references/模板库/` | 档案目录完整 |
| 3 | 每季度更新考察意见 | 有书记签字的考察表 |
| 4 | 转正前汇总全周期档案 | 完整档案包移交支委会 |

> **数据同源提醒**：考察档案中的「活动出勤」「思想汇报提交」数据，直接使用纪检委员维护的考勤系统数据，不与考勤表重复录入。

### 二、思想汇报归档

**信息流**：
```
党员/发展对象提交思想汇报
    │
    ▼
组织委员归档 → 更新提交状态表
    │
    ▼
状态表同步反馈 → 纪检委员（配合考勤监督）
```

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 收齐各党小组思想汇报（季度） | 数量 = 应提交人数 |
| 2 | 归档至对应个人档案目录 | 每份有日期标记 |
| 3 | 更新提交状态表 → 共享纪检委员 | 状态表最新 |

### 三、党员发展协助

**信息流**：
```
支委会确定发展计划
    │
    ▼
组织委员启动材料准备
    │
    ▼
公示 → 支部大会 → 上级审批
```

**关键动作**（按发展节点）：

| 节点 | 必须交付 |
|------|----------|
| 确定发展对象 | 发展对象登记表 + 考察档案初稿 |
| 接收预备党员 | 入党志愿书 + 公示材料 + 支部大会记录 |
| 预备党员转正 | 转正申请书 + 全年考察档案 + 支部大会决议 |

> 完整材料清单和格式化模板见 `content/references/模板库/党员发展材料清单.md`。

## 检查清单

### 每日
- [ ] 无固定每日任务

### 每周
- [ ] 审查专班看板待启动列
- [ ] 更新思想汇报归档进度

### 每季度
- [ ] 考察档案更新（所有发展对象）
- [ ] 思想汇报全量归档

### 每学期
- [ ] 发展对象全周期档案汇总
- [ ] 专班归档审核
