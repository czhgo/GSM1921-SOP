# content/references/

本目录存放原始官方文件、会议记录与可复用模板。

> ⚠️ `官方文件/`、`党小组会/`、`支部委员会/` 下所有文件均为**只读参考资料**，禁止修改。

## 目录结构

| 子目录/文件 | 内容 | type |
|-------------|------|------|
| `官方文件/` | 党章、党支部工作规范、党员教育管理条例等官方文件 | reference |
| `党小组会/` | 党小组会议相关记录与参考材料 | reference |
| `支部委员会/` | 支委工作手册等参考文件 | reference |
| `模板库/` | 可复用工作模板（活动复盘/申报材料等） | template |
| `模板库/FEEDBACK_FORM.md` | SOP 优化提案反馈卡——支委提交规则修改的唯一接口 | template |
