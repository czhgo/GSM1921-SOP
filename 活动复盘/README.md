# 活动复盘指南

> **💡 简单说：活动结束后，花30分钟总结一下"什么做得好、什么要改进"**

---

## 👤 谁来负责复盘？

**根据11月支部大会精神：**
- ✅ **活动复盘必须由【组织者】完成**（党员/预备党员）
- ✅ **宣传工作可以下放给【深度参与者】**
- ❌ 复盘不能委托给宣传委员

**明确分工：**
- **党小组活动复盘** → 党小组组长（条条组长）或指定的组织者
- **支部活动复盘** → 支部活动的主要组织者
- **宣传材料制作** → 可由深度参与者负责，宣传委员指导监督

---

## 🎯 什么是复盘？为什么要复盘？

**复盘 = 活动后的反思总结**

**3个理由告诉你为什么要复盘：**
1. 记住好的做法，下次继续用
2. 发现问题，避免下次重复犯错
3. 把个人经验变成组织经验，新人也能学到

---

## ⚡ 什么时候复盘？

| 活动类型 | 需要复盘吗 |
|---------|----------|
| 党小组活动 | ✅ 需要 |
| 创新性/品牌性活动 | ✅ 需要 |
| 党团班一体化活动 | ✅ 需要 |
| 三会一课 | ❌ 不需要（用工作记录模板） |
| 常规例行活动 | 看情况（有新收获就复盘） |

## 📝 怎么复盘？

### 方式1：填写复盘模板（推荐）

使用 [活动复盘模板.md](./活动复盘模板.md)，回答这几个问题：
1. 这次活动想达成什么目标？达成了吗？
2. 什么做得好？（亮点）
3. 什么做得不好？（问题）
4. 下次怎么改进？（具体措施）
5. 有什么经验可以分享？

**复盘文件命名：** `YYYYMMDD-活动名称-复盘.md`  
**示例：** `20260203-第一党小组学习活动-复盘.md`

### 方式2：GitHub Issues讨论

1. 创建一个Issue，标题写活动名称
2. 大家在Issue里讨论、补充
3. 讨论完整理成Markdown文件归档

### 方式3：混合方式（最佳）

1. 先在Issue里讨论（3-5天）
2. 讨论成熟后整理成Markdown文件
3. 在Issue里贴上文件链接，关闭Issue

## ✅ 复盘的3个原则

1. **客观真实** - 不回避问题，不粉饰太平
2. **具体可行** - 改进措施要具体，不要空谈
3. **及时完成** - 趁记忆清晰时做，不要拖太久

---

## ❌ 复盘要避免的3个误区

1. **走形式** - 敷衍了事，走过场
2. **互相指责** - 把复盘变成批斗会
3. **不了了之** - 复盘完了没有后续行动

---

## 💡 使用建议

1. **活动结束后1周内完成复盘**
2. **活动组织者主导，参与者共同讨论**
3. **复盘要具体：不说"做得不好"，说"X环节Y问题"**
4. **改进要可行：不说"下次做好"，说"下次提前Z天准备"**
5. **下次活动前，翻一翻之前的复盘**

## 📌 复盘 vs 宣传的区别

| 工作内容 | 负责人 | 目的 | 可否下放 |
|---------|--------|------|---------|
| **活动复盘** | 组织者（党员/预备党员） | 总结经验教训，改进工作 | ❌ 不可下放 |
| **宣传材料** | 深度参与者 | 对外展示，档案记录 | ✅ 可由深度参与者完成 |
| **宣传指导** | 宣传委员 | 监督指导，确保质量 | - |

**重要提醒：**
- 复盘的价值在于组织者的深度思考，不能简单委托
- 宣传委员负责指导宣传材料的制作，但不替代组织者的复盘工作
