# 纪检委员工作流程指南

## 文档说明

本文档详细说明纪检委员（韩思宁）的工作流程、职责范围和操作规范，是纪检委员开展日常工作的核心参考文件。

**核心定位：** 纪检委员作为块块委员，横跨三个党小组，负责考勤管理、活动参与记录、活动复盘监督、补课制度执行。

**特别说明：** 
- 纪检委员的工作重点是**考勤管理**和**活动监督**。
- **2026年2月工作优化：** 考察档案管理和意见反馈平台已转交组织委员，纪检委员专注于记录和监督职能。

**术语说明：**
- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- 不使用"普通党员"等具有层级性的表述

## 一、工作职责总览

### 1.1 核心职责

| 职责类别 | 工作内容 | 对象 | 说明 |
|---------|---------|------|------|
| 📋 **考勤管理** | 记录三会一课出勤情况 | 党员、预备党员 | 二元记录（出勤/请假/缺勤），提交宣传委员备案 |
| 📝 **参与记录** | 记录活动参与情况 | 所有支部成员 | 分三层记录（组织/深度参与/出勤），提交组织委员 |
| 👁️ **活动监督** | 监督活动复盘完成 | 活动组织者 | 确保组织者亲自完成复盘 |
| 📋 **补课管理** | 执行补课制度 | 请假/缺勤人员 | 安排补课，跟踪完成 |

**职责调整说明（2026年2月）：**
- ✅ 保留：考勤管理、参与记录、活动监督、补课管理
- ➡️ 转移：考察档案管理 → 组织委员（纪检委员只记录，不建档）
- ➡️ 转移：意见反馈平台 → 组织委员（纳入支部信息平台）

### 1.2 考勤与参与记录的核心区别

| 维度 | 考勤（0-1变量） | 参与记录（三层记录） |
|------|----------------|---------------------|
| **对象** | 党员、预备党员 | 所有支部成员 |
| **适用** | 三会一课 | 所有支部工作 |
| **记录** | 出勤/请假/缺勤 | 组织/深度参与/出勤 |
| **方式** | 实时记录 | 实时记录 |
| **提交** | 宣传委员备案 | 组织委员建档（每月提交） |

## 二、考勤管理（三会一课）

### 2.1 考勤范围与记录标准

| 活动类型 | 考勤对象 | 记录状态 |
|---------|---------|---------|
| 支部委员会 | 支委会成员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 支部党员大会 | 党员、预备党员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 党小组会 | 本组党员、预备党员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 党课 | 党员、预备党员、发展对象、积极分子 | ✅出勤 / 🏥请假 / ❌缺勤 |

**说明：** 考勤是0-1记录，只记录客观出勤事实，不考虑质量。其他党小组活动根据性质决定是否记考勤或转入考察系统。

### 2.2 请假与补课

| 类型 | 申请时间 | 处理方式 |
|------|---------|---------|
| **事假** | 提前1天 | 联系纪检委员，说明原因 |
| **病假** | 事后补假 | 提供就医证明 |
| **缺勤** | 事后说明 | 及时联系，无故缺勤影响考察 |

**补课要求：** 请假/缺勤后1周内完成（特殊情况2周），形式包括：阅读材料、观看录像、提交心得等。完成后标注"已补"。

### 2.3 考勤工作流程

```
活动前：准备考勤表 → 活动中：签到记录 → 活动后：整理汇总 → 定期提交给宣传委员
```

| 阶段 | 工作内容 | 时间 |
|------|----------|------|
| **活动前** | ① 准备考勤表<br>② 收集请假信息 | 活动前1天 |
| **活动中** | ③ 组织签到<br>④ 核对人数 | 活动开始时 |
| **活动后** | ⑤ 整理考勤（标注状态）<br>⑥ 联系缺勤人员<br>⑦ 安排补课<br>⑧ 提交宣传委员 | 1-5天内 |

**考勤表模板：**
```
【活动名称】考勤表
时间：____  地点：____  类型：□支委会 □大会 □党小组会 □党课

序号 | 姓名 | 身份 | 状态 | 备注
----|------|------|------|-----
1   |      |      | □出勤 □请假 □缺勤 | 

应到/实到/请假/缺勤：__/__/__/__人
记录人：韩思宁  日期：____
```

## 三、活动参与记录

### 3.1 记录目的与分工

**为什么记录活动参与？**
- 为党员发展提供客观依据
- 鼓励党员【组织】或【深度参与】活动
- 考察积极分子和发展对象的能力

**纪检委员与组织委员的分工（2026年2月调整）：**

| 工作内容 | 责任人 | 说明 |
|---------|--------|------|
| 活动参与记录 | 纪检委员 | 在活动中观察记录参与情况 |
| 每月汇总提交 | 纪检委员 | 每月提交给组织委员 |
| 档案建设管理 | 组织委员 | 建立考察档案系统 |
| 倒查验证 | 组织委员 | 申请时查询验证 |
| 出具考察意见 | 组织委员 | 根据档案出具意见 |

**工作原则：**
- 纪检委员专注于记录，不负责建档和出具意见
- 记录要客观、准确、及时
- 每月月底前提交给组织委员

### 3.2 三层参与记录

| 参与层次 | 定义 | 记录内容 | 判断标准 |
|---------|------|---------|---------|
| **【组织】** | 活动策划组织者 | 活动名称、组织工作 | 主导策划和实施 |
| **【深度参与】** | 承担具体工作 | 宣传/现场统筹/技术支持等 | 有明确分工，实际完成 |
| **【出勤】** | 参加但无具体工作 | 仅记录出勤 | 参加活动 |

**记录要求：**
- 活动前了解分工
- 活动中观察确认
- 活动后与组织者确认
- 记录真实可验证

### 3.3 记录与提交流程

```
活动前：了解分工 → 活动中：观察记录 → 活动后：确认记录 → 每月：提交组织委员
```

| 阶段 | 工作内容 | 时间 |
|------|----------|------|
| **活动前** | 与组织者沟通，了解分工 | 活动前3-5天 |
| **活动中** | 观察实际参与情况 | 活动期间 |
| **活动后** | 与组织者确认角色，记录档案 | 活动后3-5天 |
| **月底** | 汇总本月记录，提交组织委员 | 每月最后一周 |

**记录表模板：**
```
【月份】活动参与记录汇总表

| 时间 | 活动名称 | 姓名 | 参与角色 | 具体工作 | 备注 |
|------|---------|------|---------|---------|------|
| 02-10 | XX学习会 | 张三 | 【组织】 | 活动策划实施 | |
| 02-10 | XX学习会 | 李四 | 【深度参与-宣传】 | 推文撰写 | |
| 02-15 | XX实践 | 王五 | 【出勤】 | 参与活动 | |

记录人：韩思宁（纪检委员）
记录时间：2026-02-28
提交对象：侯嘉嵘（组织委员）
```

**提交方式：**
- 纸质版：双方签字确认
- 电子版：发送邮件或上传平台
- 存档：纪检委员保留备份

## 四、活动监督

### 4.1 监督活动复盘

**要求：** 活动复盘必须由【组织者】亲自完成，不能委托。

| 步骤 | 工作 | 时间 |
|------|------|------|
| ① 活动后提醒 | 提醒组织者完成复盘 | 活动后1天 |
| ② 跟进检查 | 检查是否由组织者完成、内容是否充实 | 活动后5-7天 |
| ③ 记录反馈 | 记录完成情况，定期向支委会汇报 | 活动后1周、每月支委会 |

**合格复盘标准：** ☑ 组织者本人完成 ☑ 内容具体有建议 ☑ 及时（1周内） ☑ 使用模板结构

## 六、常见问题（FAQ）

**Q1: 考勤vs参与记录？**
- 考勤：三会一课，出勤/请假/缺勤，提交宣传委员
- 参与记录：所有工作，组织/深度参与/出勤，提交组织委员（每月）

**Q2: 参与记录提交给谁？**
- 2026年2月起，活动参与记录每月提交给组织委员侯嘉嵘
- 组织委员负责建档管理和出具考察意见
- 纪检委员专注于现场记录

**Q3: 组织者不完成复盘？**
1周提醒→2周再提醒→报支委会→影响考察（由组织委员记录）

**Q4: 如何判断"深度参与"？**
☑ 明确分工 ☑ 实际完成 ☑ 可验证 ☑ 有贡献
❌ 挂名无实 ❌ 无法验证

**Q5: 请假vs缺勤？**
- 请假：提前申请或事后说明，正常，需补课
- 缺勤：未请假，需了解原因，影响考察，需补课

**Q6: 意见反馈找谁？**
- 2026年2月起，意见反馈平台由组织委员侯嘉嵘管理
- 纪检委员专注于考勤和活动监督工作
