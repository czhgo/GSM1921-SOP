# Knowledge Layer

This directory contains the institutional knowledge of the system.

Structure:
- `content/SOP/`: canonical institutional procedures (绝对制度母本)
- `content/POLICY/`: governance rules (future)
- `content/DECISION/`: architecture decisions (future)

All system logic, schemas, and UI behavior must derive from the SOP documents.
