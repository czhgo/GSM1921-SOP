## 💡 本仓库的演进哲学与协作须知

### 一、这是一个活的系统，不是静态文件夹

本仓库不是传统意义上的"文件存放点"。它是光华管理学院本科生党支部的**动态演进的党务标准运行系统（SOP Engine）**。每一份流程指南、每一张速查卡，都是经过多轮支委讨论、基于真实工作痛点提炼出来的标准，并随着支部工作的推进持续迭代更新。

### 二、双轨协作：你看到的部分，与背后的逻辑是分离的

本仓库运行"双轨制"：

- **人工面板（你现在看到的部分）**：流程指南、速查卡、申报模板——这是全体支委的工作手册，用简洁的中文写成，照着做就行。
- **后台控制逻辑（`.vibe_context/` 文件夹）**：AI协同工作引擎的状态机和规则文件，供书记和AI代理维护使用，普通使用者无需关心。

**重要的一点是：大家只需要阅读指南、执行标准流程。如果发现某个流程描述不准确、某个场景没有覆盖、或者有新的工作需求，请不要自行在文档里零散改字。**

### 三、反馈驱动迭代：正确的协作姿势

正确的迭代路径是：

```
发现痛点 → 汇总给书记/统筹人 → 书记统一调整后台状态机指令 → AI 引擎在几分钟内完成全局、无死角的重构与更新
```

这样做的好处：
- **全局一致**：一次调整，所有相关文档同步更新，不会出现"A文件改了、B文件没改"的信息冲突。
- **减负增效**：委员们从繁琐的"对齐文档、检查格式"中解放出来，只需专注于实质性工作。
- **可追溯**：每一次修改都有完整的执行日志，历史决策有据可查。
