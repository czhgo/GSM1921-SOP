# 工作记录类模板

## 概述

本目录包含用于**日常上报给上级组织备案审查**的工作记录模板。这些模板用于正式记录三会一课、主题党日等党务活动，需要严格按照规范填写。

**特点：**
- ✅ 正式、规范
- ✅ 用于上级备案审查
- ✅ 必须按照标准格式填写

**维护者：** 宣传委员 闫鑫岳

---

## 模板清单

### 1. 党支部工作记录模板

**文件名：** [党支部工作记录.docx](./党支部工作记录.docx)

**用途：** 记录三会一课（支部委员会、支部党员大会、党小组会、党课）和主题党日活动

**适用场景：**
- 支部委员会会议
- 支部党员大会
- 党小组会
- 党课
- 主题党日活动

**填写要求：**
- 会议基本信息（时间、地点、主持人、记录人）
- 参加人员名单和签到情况
- 会议主要内容和讨论要点
- 决议事项和表决结果
- 工作部署和分工安排

**使用规范：**
- 按照模板格式填写，不要随意修改结构
- 使用规范的党务用语
- 内容真实、完整、准确
- 会后3天内完成填写
- 及时归档并上报

**指导者：** 宣传委员负责指导使用此模板，监督填写质量和提交时效

---

## 使用流程

```
会议/活动开始 → 指定记录人员 → 使用模板记录 → 会后整理完善 → 
宣传委员审核 → 归档存档 → 上报上级组织
```

---

## 注意事项

⚠️ **重要提醒：**
- 工作记录用于上级备案审查，必须保证质量
- 不得随意修改模板格式
- 填写内容必须真实、准确、完整
- 涉密内容需按保密规定处理
- 按时提交，不得拖延

✅ **质量标准：**
- 信息完整无遗漏
- 格式规范符合要求
- 文字准确无错别字
- 时间节点清晰
- 决议事项明确
