# UI 审查清单——改界面时按任务组逐条过

> **本文件是温层：改对应任务时读，不是每次会话必读。**
> 入口：`CLAUDE.md H40.2`（只写「何时读 / 去哪读 / 答不出怎么办」）。规范正文在设计系统各编；本文件只做「按任务组组织的检查单」，不新造 SD 编号，也不复述整节条文。
> **怎么用**：先按本批改动类型选组（可多选），逐条给出「通过 / 不通过 / 不适用＋理由」；出现「不通过」先补证据再动笔，不得凭手感加色块 / 加边框。
> **答不出怎么办**：先补真机截图、读数或现有判据；证据补齐前不动笔。

## ① 版式 / 密度

| 检查 | 判据 | 依据（DS 节 / SD） | 何时读 |
|---|---|---|---|
| 1. 单页顶层区块数 | 单页顶层区块 ≤4（页头不计）；同类同源合并进同一块；空态与列表二选一 | DS_06 §二 · SD-57 | 新增 / 合并页签区块、首屏排版时 |
| 2. 筛选条行数 | 第 1 行「范围 / 时间 ＋ 搜索」，第 2 行「分面 ＋ 清除」；不得竖排；清除不得独占一行 | DS_06 §二 · SD-58 | 改筛选条、加筛选维度时 |
| 3. 容器宽度 | 只用五档容器宽度，不写第三套 `max-width` | DS_02 §3.4 | 改页面外壳、加栅格列时 |
| 4. 间距取值 | 组件内边距 ∈{4,8,12,16,24}；标题→次级→描述 8px | DS_03 §12.7 · SD-18 | 调卡片内距、段落间距时 |
| 5. 卡头构成 | 一 tab 内卡片恰 1 个 H2；卡头 H3 带范围、不复述页签名；标题左、计数与动作右 | DS_03 §12.15 · SD-35 | 改卡片头、拆并卡片时 |

## ② 排版 / 字号

| 检查 | 判据 | 依据（DS 节 / SD） | 何时读 |
|---|---|---|---|
| 1. 字号档 | 标题 / 正文 / 次级 / 标签只落在规定字号档，不新增档外字号 | DS_02 §3.2 | 任何可见文字改动 |
| 2. 标题层级 | 页面 H1 → tab H2 → 卡 H3 → 块 H4，不跳级；交互元素内不放标题 | DS_03 §4.25 · SD-39 | 加卡片、加分区时 |
| 3. 控件高度 | 行内按钮 28 / 卡片 32 / 页面与弹窗 36，高度不得靠 `min-height` 脱离文字行高 | DS_03 §12.1 · SD-14 | 改按钮、输入、弹窗时 |
| 4. 文字折行 | 长标题与表格首列不溢出；窄屏允许换行但不截断关键词 | DS_02 §3.3 | 改长文案、宽表时 |

## ③ 颜色 / 对比

| 检查 | 判据 | 依据（DS 节 / SD） | 何时读 |
|---|---|---|---|
| 1. 颜色分层 | 每个颜色先归属导航 / 动作 / 选择 / 展示 / 主从之一；功能色只表状态 | DS_01 §2.10 | 加任何颜色时 |
| 2. 正文对比 | 正文与浅底对比度 4.5–9:1；状态文字取 `--status-*-text`，填充档不得作文字色 | DS_01 §2.5 · DS_03 §12.9 · SD-20 | 改指标、状态、徽章时 |
| 3. 选中态 | 选中态只用主题 soft 三件套（底 / 字 / 左条）；浅灰不表达 selected | DS_03 §12.11 · SD-25 | 改列表选中、页签选中时 |
| 4. 硬编码色 | 渲染层不出现内联 hex / rgba；颜色只经 token | DS_01 §2.9 | 改样式、复制旧样式时 |
| 5. 深色模式 | 亮 / 暗两套 token 都有对应；深色下功能色仍可分辨 | DS_01 §7.2 / §7.3 | 新增颜色或组件时 |

## ④ 交互 / 无障碍

| 检查 | 判据 | 依据（DS 节 / SD） | 何时读 |
|---|---|---|---|
| 1. 焦点 | 焦点只出一个信号：按钮 / 链接族 `:focus-visible` 单环；输入族只把边框切主题色，不叠加 `outline` | DS_04 §5.7 / §5.8 · SD-27 | 改任何可点控件时 |
| 2. 三态 | hover 只在 `@media (hover:hover)` 内；按压只经 `--press-shadow`；禁用 / 只读两态可辨 | DS_03 §12.8 · SD-23 / SD-24 / SD-28 | 加悬停、按压、禁用态时 |
| 3. 键盘可达 | 可点行与自定义控件可 Tab 聚焦、可 Enter / Space 触发；折叠状态可由 `open` / `aria-expanded` 回读 | DS_03 §12.5 · SD-38 | 加折叠、菜单、自定义控件时 |
| 4. 触控热区 | 390 下可点目标命中区 ≥44×44，相邻热区不重叠 | DS_04 §6.3 | 改移动端操作行时 |
| 5. 语义标签 | `section` 有可访问名称且不嵌套；布局容器用 `div` | DS_03 §12.15 · SD-55 | 加页面分区时 |

## ⑤ 文案 / 空态

| 检查 | 判据 | 依据（DS 节 / SD） | 何时读 |
|---|---|---|---|
| 1. 空态三件 | 空态 / 加载 / 错误各有一句话与一个下一步；错误串不暴露文件名，不写「请刷新」 | DS_03 §4.18 · DS_04 §5.9 | 加列表、加异步加载时 |
| 2. 卡头副题 | 卡头副题只写范围与约束，不写操作指令 | DS_03 §12.15 · SD-54 | 改卡头文案时 |
| 3. 零值与空行 | 零值不显示为空白；空行不占位渲染骨架 | DS_03 §4.26 | 改数字卡、表格时 |
| 4. 确认文案 | 危险动作进确认面，含「做什么 / 影响范围 / 可否恢复」三段 | DS_03 §4.27 · SD-53 | 加删除、作废、覆盖操作时 |
| 5. 帮助注释 | 帮助注释只在需要解释「为什么」处出现，不解释显而易见的结构 | DS_03 §4.24 | 加帮助文案时 |
