# 光华管理学院本科生党支部工作规范与流程（GSM1921-SOP）

## 项目概述

本仓库是光华管理学院本科生党支部的标准操作程序（SOP）文档库，旨在规范支部工作流程、明确组织架构、推进党建创新。本仓库坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届二中、三中、四中全会精神，以"改革"作为支部建设的方法关键，以"敢当"作为支部建设的内容核心。

### 组织意图

围绕"学习贯彻二十届四中全会精神""传承抗战精神，勇担复兴使命""赓续敢当精神"主题，开展以**学科建设**为中心的**组织进步**和**个人成长**辩证统一的活动，发挥学生工作协同作用。

## 党小组架构与职能

根据2025年5月党小组制度建立和11月支部大会精神，本科生党支部划分为**三个党小组**，把党支部能出彩的地方交由党小组来建设：

### 第一组：学术组

**定位：** 面向有志于学术的同志，包括要读博士的党员同志

**建设方向：**
- "二十届四中全会"：习近平经济思想与理论传承创新专题立项
- 探索"党建+科研"的组织优势、适用范围、管理模式、成果转化
- 与教师支部、博士支部探索共建模式

### 第二、三组：就业组

**定位：** 面向市场化就业、金融硕士等发展路径的党员同志

**建设方向：**
- 推动与MBA功能型党支部共建
- 探索生涯发展建设，发挥组织协同效应
- 助力支部成员持续成长

### 党小组组织原则

- **组长制度：** 每个党小组设1名组长（党员担任）+ 1-2名副组长
- **活动频次：** 每月至少开展一次活动
- **三大职能：**
  1. **培养职能** - 在党性修养、政治理论、党务工作等方面积极探索
  2. **考察职能** - 落实对积极分子的考勤，推选优秀分子参与支部大会
  3. **服务职能** - 做好支部成员之间、与支部大会、与支委会之间的纽带

## 11月支部大会核心精神（2025.11.30）

### 一、党团班一体化建设

**目的：**
- **主要：** 服务党组织意图，加强党组织对团、班的领导，宣传党的理论政策
- **次要：** 加强对支部成员的考察，降低参与支部建设的边际成本

**制度保障：**
- 党支部：落实支委工作牵头制度建设，把党小组作为承接非组织程序性活动的重要窗口
- 团班学：以党组织布置的主题为中心，联系所在或对应功能党小组
- 原则：活动性质事先认定、过程分工充分沟通、材料产出清晰高效

**重要提醒：**
- 不要为了活动堆砌数量，一个团队共同做好一个项目更重要
- 发挥协同效应 ≠ 党团班学组织边界模糊，本职之外的**边际贡献**才是参与一体化建设本身

### 二、品牌活动建设

**什么是品牌活动：**
- 【必要条件】符合组织意图、有明确活动目标、持续跟进

**为什么品牌压在党小组：**
- 更小的活动体量
- 更少的身份制约
- 更大的互动空间
- 更确定的服务对象

### 三、党员责任与要求

**每学期党员、预备党员要求：**
- 承担至少**两次**支部具体工作，或
- 组织至少**一次**创新性/品牌性支部活动/党小组活动

**支部具体工作包括但不限于：**
- 文稿撰写、材料整理、制度建设（提案、落实）、学习分享
- 注：机械性的工作不予计入

**创新性/品牌性活动包括但不限于：**
- 构想新活动并实施
- 对既有活动提出批判性意见建议并落实

### 四、积极分子发展要求

**两个必要条件：态度和能力**

- 对于培养考察满一年的积极分子，学期末支部会统一请大家填报申请成为发展对象
- 支部根据填报结果倒查考察考勤结果，并充分背调
- 积极分子可通过创新性活动组织、工作参与证明自己，与党小组组长取得联系

### 五、核心信息

> "我们党建的资源、制度、氛围比过去任何时候都更好" —— 2025/11/30

## 工作流建设方向

根据支委工作手册，支部建设延续**三条主线**：

### 1. 组织建设
- 构建支部成员档案（姓名、年级、专业、学生工作履历、奖励荣誉、活动参与）
- 着力关注对支部建设有期待、有想法、有作为的同志
- 党员发展考察突出积极分子主动性

### 2. 制度建设
- **学习与考察制度：** 固定月度支部大会时间、强化考勤约束、增设通报制度和补课制度
- **宣传与档案制度：** 强化宣传与档案队伍建设
- **监督与议事制度：** 保障党员知情权、参与权、表决权

### 3. 学科建设
- 深入论证"党建+科研"的着力点
- 探索与教师支部、博士支部、硕士支部、MBA支部共建模式
- 以深入贯彻学习党的二十届四中全会精神为契机积极作为

## 三会一课制度

依照《中国共产党支部工作条例（试行）》：

- **支部委员会：** 一般每月召开1次
- **支部党员大会：** 一般每季度召开1次，每月固定在**最后一个完整周的周日晚**召开
- **党小组会：** 按照支委会或支部大会部署每月至少开展一次
- **党课：** 定期开展

**出勤要求：**
- 准时认真参与三会一课
- 事假必须提前1天申请，病假可以事后补假
- 无故缺勤者予以相应处理
- 及时查收支部通知，对要求确认的信息须在12小时内确认

## 使用指南

1. **新支委或党员：** 先阅读`官方文件/`了解规范底线，再阅读`支部委员会/支委工作手册26春.docx`了解职责分工
2. **党小组组长：** 重点学习`党小组会/`目录下的党小组说明文档和11月支部大会精神
3. **积极分子/发展对象：** 了解党小组架构，主动联系党小组组长参与活动
4. **开展新活动前：** 参考11月大会精神，确保活动符合组织意图、有明确目标、可持续跟进
