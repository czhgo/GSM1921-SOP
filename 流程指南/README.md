## 🔑 核心概念速查

### 条条与块块双线管理体系

**条条（纵向业务线）：** 党小组组长
- 储子禾（第一党小组-学术组）
- 王峥旭（第二党小组-就业组）
- 辛长乐（第三党小组-就业组）
- **职责：** 具体活动组织和品牌建设
  
**块块（横向职能线）：** 支委委员
- 侯嘉嵘（组织委员）- 党员发展、考察档案、信息平台
- 闫鑫岳（宣传委员）- 宣传档案、材料模板、活动记录
- 韩思宁（纪检委员）- 考勤管理、活动监督、参与记录
- **职责：** 制度建设和职能保障

### 协作原则

- **条条主导活动组织**，块块提供职能支撑
- **支委决策为先**，党小组落实为主
- **定人定责定岗**，避免职责交叉混乱

### 术语说明

- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- **三会一课** = 支部委员会 + 支部党员大会 + 党小组会 + 党课
