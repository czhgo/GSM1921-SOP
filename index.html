我要组织一次党小组活动

核心原则：除发展党员、转正、换届等需严肃投票的事项外，其他都可以往党小组压。

类型性质参与者考勤
场景 1A：组织生活会民主评议、批评与自我批评仅限党员和预备党员刚性（三会一课）
场景 1B：主题党日活动学习会、分享会、参访、调研、联学共建全体支部成员，可跨组弹性

点击左侧角色标签，查看你在场景 1A / 1B 中的具体工作节点。

2

我要制定一个新制度

块块委员

起草初稿 → 本组试点 → 征求意见 → 修改完善 → 支委会审议 → 党员大会表决 → 监督落实

重大制度必须经支部党员大会表决；制度实施后要及时总结经验，适时调整完善。

3

我要考察一位积极分子

日常观察 → 记录考察档案 → 归档汇报 → 反馈意见 → 支委会讨论 → 党员大会表决

考察重点：态度和能力两个必要条件。培养考察期至少 1 年。

4

团支部想和党支部合办活动

团班发起 → 条条评估 → 共同策划 → 块块支持 → 活动实施 → 分层归档

原则：活动性质事先认定、过程分工充分沟通、材料产出清晰高效。

7

支部要讨论重要事项

事项类型决策机制主导者
党小组日常活动组长负责制条条组长
制度建设支委会审议 + 党员大会表决块块委员起草
党员发展 / 重大事项支委会讨论 + 党员大会表决支部书记牵头

支委会每月 1 次；党员大会每季度 1 次（每月最后完整周周日晚）。

8

党小组品牌活动建设

支持项目制，鼓励支部党员、发展对象、积极分子担任活动组织者；这是考察积极分子的重点场域。

明确定位 → 设计方案 → 试点实施 → 迭代优化 → 持续跟进 → 总结推广

品牌活动必要条件：① 符合党支部组织意图 ② 有明确活动目标 ③ 持续跟进。

9

纪检委员

意见类型反馈时间
制度建设建议下次支委会后
活动组织建议1 周内
工作流程建议2 周内
其他建议1 个月内
