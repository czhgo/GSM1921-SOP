## 3. [骨架 I] 组织生活会标准工作流

> **适用范围：** 三会一课范畴的组织生活会（含民主生活会、批评与自我批评会）。  
> **参与者：** 中共党员与预备党员。  
> **考勤：** 刚性（三会一课），必须记录归档。  
> **主导：** 书记/支委会部署主题，条条组长主持。

```mermaid
flowchart TD
    S([组织生活会 启动])

    A1["书记/支委会：部署主题"]
    A2["条条组长：会前逐一谈心"]
    A3["党员：撰写对照检查材料"]
    A4["组织委员 侯嘉嵘：公邮+大群发通知<br/>提前≥3天，不入活动小群"]
    A5["纪检委员 韩思宁：刚性签到<br/>事假提前1天，病假事后补"]
    A6["开会：自评 → 互评 → 总结<br/>条条组长主持"]
    A7["记录人：会议记录归档<br/>使用工作记录类模板"]
    A8["宣传委员 闫鑫岳：宣传产出<br/>摘要+配图，无需预热"]
    A9["纪检委员 韩思宁：考勤记录归档"]
    A10["宣传委员 闫鑫岳：档案归档<br/>全部会议材料"]

    E([完成])

    S --> A1 --> A2 --> A3 --> A4 --> A5 --> A6 --> A7 --> A8 --> A9 --> A10 --> E

    style S fill:#e1ffe1
    style A1 fill:#e1f5ff
    style A2 fill:#e1f5ff
    style A3 fill:#e1f5ff
    style A4 fill:#ffe1e1
    style A5 fill:#ffe1e1
    style A6 fill:#e1f5ff
    style A7 fill:#e1f5ff
    style A8 fill:#ffe1e1
    style A9 fill:#ffe1e1
    style A10 fill:#ffe1e1

```

**重要说明：**
- 🔴 红色节点为块块委员职能动作；🔵 蓝色节点为条条/党员动作
- 组织生活会**不需要**活动复盘，使用「工作记录类」模板归档即可
- 纪检委员考勤为刚性，必须记录并归档以证明会议召开

## 4. [骨架 II] 党小组主题党日活动标准工作流

> **适用范围：** 三会一课以外的学习型、交流型、实践型活动（学习会、分享会、参访、联学共建等）。  
> **参与者：** 全体支部成员，可跨组。  
> **考勤：** 弹性（组织者/深度参与者必须，一般参与者以鼓励为主）。  
> **主导：** 条条组长审批，组织者主导执行。  
> **合并说明：** 原"党团班一体化活动流程"已整合入本骨架 **分支 2（联学共建/跨组）**，不单独成图。

```mermaid
flowchart TD
    S([党小组主题党日活动 启动])

    P1["组织者：策划活动方案<br/>路径a（品牌活动）或路径b（临时发起）"]
    P2{"是否联学共建<br/>或跨组参与?"}
    P3["确认合作方/跨组人员<br/>核实与本组定位契合度<br/>对外协调须由条条组长背书"]
    P4["条条组长：审批活动方案<br/>联学共建须组长确认对外口径"]

    Q1["组织委员 侯嘉嵘：公邮+大群发通知<br/>不加入活动小群"]
    Q2{"是否外出参访?"}
    Q3["外出子流程：<br/>① 交通方式确认<br/>② 安全须知与人员清点方案<br/>③ 经费统筹（H4待议）"]
    Q4["室内：确认场地安排"]

    R1["纪检委员 韩思宁：入群发微信备忘录<br/>弹性考勤说明+复盘底线<br/>无活动小群则私信组织者确认"]
    R2["宣传委员 闫鑫岳：指导宣传负责人<br/>不直接执行，无需预热"]

    T1["组织者：活动实施<br/>纪检委员群内提醒签到"]

    U1["组织者：活动复盘，1周内完成<br/>条条组长指导，不可委托"]
    U2["宣传负责人：摘要+配图<br/>闫鑫岳指导，纳入月度推送"]
    U3["组织者：材料主动交宣传委员归档<br/>侯嘉嵘建档（参与记录）"]
    U4["纪检委员 韩思宁：弹性考勤记录<br/>提交组织委员建档"]
```
