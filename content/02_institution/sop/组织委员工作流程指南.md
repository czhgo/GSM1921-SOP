# 组织委员工作流程指南

> **一句话**: 统筹专班招募与发展党员全程管理。

**术语与党建/党务工作定义**：见 [INDEX.md](./INDEX.md#术语与党建党务工作定义)

## 适用角色

**组织委员**

- **党建工作**：专班招募唯一统筹者（发起≠招募——书记/党小组组长/支委均可发起，但只有组织委员能统一招募）
- **党务工作**：发展党员全流程管理（考察档案 + 思想汇报 + 发展协助）
- **数据共享**：考察档案与纪检委员的考勤数据通用同源

### 为什么这么做

- **两个动作**：发起是"提出需求"——书记、党小组组长、支委都可以提；招募是"赋权+记账"——只有组织委员能做
- **如果不分离**：发起者自己招募（如宣传委员自己招募宣传专班），赋权记录散落在各委员手里，工作量记账和解散评议没有统一流程
- **统一招募的价值**：所有专班走同一套赋权→记账→解散流程

母本引用：[COMMISSIONER_FRAMEWORK.md] §A.6 条块衔接规则 + §A.7 专班生命周期

## 党建工作台 — 专班协调视图（最高优先级）

> 在系统中，组织委员进入党建工作台·管理模式后看到的不是日历，是 **专班协调看板**。

> **设计考量**：专班是时效性最强的攻坚任务——三项适用场景要求窗口少于 2 周，待启动列停留超过 7 天可能错过时效窗口；发展党员和考察档案是周期性工作有缓冲空间。专班协调看板设为最高优先级，确保攻坚任务不被常规事务淹没。
> 母本引用：[FLAT_DESIGN.md] §三 三重启动判据 + [COMMISSIONER_FRAMEWORK.md] §A.4 专班核心定义

### 信息流

```
专班发起者（书记/党小组组长/支委）→ 发起专班
    │
    ▼
专班协调看板（组织委员可见）
    ├── 待启动列：已发起未开始招募的专班卡片
    └── 进行中列：正在执行中的专班卡片（展开可见子任务）
```

### 任务流

| 步骤 | 动作 | 时机 |
|------|------|------|
| 1 | 审查待启动列中的新专班需求 | 每周至少检查一次 |
| 2 | 点击「发布招募」→ 填写招募表单（名称/人数/技能/周期/说明） | 确定需求后 |
| 3 | 监控进行中列的子任务进展 | 持续跟踪 |
| 4 | 专班全部子任务完成 → 归档 | 完成后 |

### 验收成果

- [ ] 待启动列无超过 7 天未处理的专班需求
- [ ] 每个进行中专班有明确的招募计划
- [ ] 全部完成专班已在归档库中可查

> **✅ 系统已实现**：「发布招募」按钮点击后弹出招募表单（含专班名称/任务描述/人数/截止日期/技能/周期/关联活动/初始成员/说明 9 字段），支持招募状态跟踪（recruiting → active → archived）。

## 党务工作 — 三项核心业务

### 一、考察档案维护

**信息流**：
```
发展对象名单（支委会确定）
    │
    ▼
组织委员建立/维护考察档案
    │
    ▼
发展对象个人档案（含思想汇报 → 转正材料）
```

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 获取发展对象名单 | 支委会会议纪要 |
| 2 | 建立考察档案 → 存入 `content/03_doc_system/工作模板/` | 档案目录完整 |
| 3 | 每季度更新考察意见 | 有书记签字的考察表 |
| 4 | 转正前汇总全周期档案 | 完整档案包移交支委会 |

> **数据同源提醒**：考察档案中的「活动出勤」数据，直接使用纪检委员维护的考勤系统数据，不与考勤表重复录入。「思想汇报提交」状态由组织委员在归档时自行维护。

> **考察档案记录结构**（系统已实现）：每条考察记录包含以下信息——来源类型（活动/专班）、关联活动名称、参与等级（组织者/深度参与者/普通参与者）、具体角色描述、记录人、记录时间。组织委员可直接从纪检委员的考勤系统中读取活动出勤数据，无需重复录入。

> **设计考量**：考勤同源而思想汇报不同源——考勤由纪检委员在活动现场记录（唯一写入方），组织委员直接读取避免数据冲突；思想汇报是党员直接提交给组织委员归档（纪检委员不介入），提交状态只能由组织委员维护。两者写入方不同，数据流也不同。
> 母本引用：[DATA_ARCHITECTURE.md] §2.2.4 数据共享规则

### 二、思想汇报归档

**信息流**：
```
党员/发展对象提交思想汇报
    │
    ▼
组织委员归档 → 更新提交状态表
```

> **流向说明**：思想汇报由党员/发展对象直接提交组织委员归档，纪检委员不介入思想汇报流程，仅负责考勤考察。

### 为什么这么做

- **职能内聚**：组织委员管发展党员全流程，考察档案和思想汇报都是发展党员的核心材料，归口同一人确保材料衔接不断裂
- **内控隔离**：纪检委员因内控要求不生长专班（审查权力不可转授），同理不介入思想汇报——纪律审查与思想表达分属不同职能

母本引用：[支委与党小组定人定责定岗说明.md] §2.1 条条支委职责 + [COMMISSIONER_FRAMEWORK.md] §A.6 条块衔接规则

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 收齐各党小组思想汇报（季度） | 数量 = 应提交人数 |
| 2 | 归档至对应个人档案目录 | 每份有日期标记 |
| 3 | 更新提交状态表 | 状态表最新 |

### 三、发展党员协助

**信息流**：
```
支委会确定发展计划
    │
    ▼
组织委员启动材料准备
    │
    ▼
公示 → 支部大会 → 上级审批
```

**关键动作**（按发展节点）：

| 节点 | 必须交付 |
|------|----------|
| 确定发展对象 | 发展对象登记表 + 考察档案初稿 |
| 接收预备党员 | 入党志愿书 + 公示材料 + 支部大会记录 |
| 预备党员转正 | 转正申请书 + 全年考察档案 + 支部大会决议 |

> 完整材料清单见附录 A「发展党员时间轴与材料清单」。

## 附录 A：发展党员时间轴与材料清单

> 从入党申请人到正式党员的完整路径，每一步需交付的材料由系统自动提示。

### 发展阶段与交付物

| 阶段 | 关键动作 | 必须交付 | 系统提示 |
|------|---------|---------|---------|
| 入党申请人 | 提交入党申请 | 入党申请书 | — |
| 积极分子 | 支委会确定 + 培养考察期一年以上 | 积极分子登记表 + 培养联系人考察记录 | 培养考察期满提醒 |
| 发展对象 | 支委会讨论确定 | 发展对象登记表 + 考察档案初稿 + 政审材料 | 确定后自动建档 |
| 预备党员 | 接收大会 + 公示 + 上级审批 | 入党志愿书 + 公示材料 + 支部大会记录 | 公示期提醒 |
| 预备期 | 一年预备期考察 | 季度考察意见 + 思想汇报 | 季度考察提醒 |
| 正式党员 | 转正申请 + 支部大会 + 上级审批 | 转正申请书 + 全年考察档案 + 支部大会决议 | 预备期满提醒 |

### 各阶段材料清单

**积极分子阶段**：
- 积极分子登记表（姓名/班级/申请日期/培养联系人）
- 培养联系人考察记录（每季度一次，含考察意见和培养建议）
- 思想汇报（每季度至少一篇）

**发展对象阶段**：
- 发展对象登记表（含支委会确定日期）
- 考察档案初稿（含培养考察期全程记录）
- 政审材料（本人及直系亲属政治审查）
- 群众意见征求记录

**预备党员阶段**：
- 入党志愿书（本人填写）
- 公示材料（公示期不少于 7 天）
- 支部大会记录（含表决结果）
- 上级党组织审批意见

**转正阶段**：
- 转正申请书（预备期满前提交）
- 全年考察档案（含季度考察意见）
- 支部大会决议（含无记名投票结果）
- 上级党组织审批意见
