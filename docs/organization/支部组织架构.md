# GSM1921党支部组织架构

## 支部概况

GSM1921党支部是本科生党支部，隶属于学院党委领导。

## 组织架构

### 支部委员会

根据《中国共产党支部工作条例（试行）》和《中国共产党普通高等学校基层组织工作条例》，本支部设立支部委员会：

- **支部书记**（1名）
  - 主持党支部全面工作
  - 督促党支部其他委员履行职责
  - 向上级党组织报告工作
  
- **组织委员**（1名）
  - 负责党员管理和组织发展工作
  - 维护党员档案
  - 协助做好党费收缴工作
  - 负责"三会一课"组织安排
  
- **宣传委员**（1名）
  - 负责党的理论学习和宣传工作
  - 组织主题党日活动
  - 负责支部宣传阵地建设
  
- **纪检委员**（1名）
  - 负责党风廉政建设
  - 协助开展民主评议党员工作
  - 受理党员群众意见和建议

## 工作分工

### 支部书记职责

1. 主持召开支部委员会和党员大会
2. 研究安排支部工作，检查支部工作计划、决议的执行情况
3. 了解掌握党员的思想、工作和学习情况
4. 抓好支部委员会的学习，按时召开民主生活会
5. 协调支部与行政、群团组织的关系

### 组织委员职责

1. 了解和掌握支部的组织状况，做好党员的管理工作
2. 做好发展党员工作，了解入党积极分子情况
3. 做好党员教育培训工作
4. 收缴党费，定期向党员公布党费收缴情况
5. 做好党员统计工作

### 宣传委员职责

1. 了解掌握党员和群众的思想状况
2. 提出宣传教育工作的意见，制定学习计划
3. 组织党员学习党的基本理论、基本路线、基本知识
4. 组织开展主题党日、党课等活动
5. 做好支部宣传工作

### 纪检委员职责

1. 维护党的纪律，经常对党员进行纪律教育
2. 检查党员执行党的纪律的情况
3. 受理党员的控告和申诉
4. 协助支部开展民主评议党员工作
5. 对违纪党员提出处理意见

## 运行机制

### 党员大会

- 频次：每季度至少1次
- 职权：
  - 听取和审查支部委员会工作报告
  - 讨论决定重要事项
  - 讨论接收预备党员和预备党员转正
  - 选举支部委员会

### 支部委员会会议

- 频次：每月至少1次
- 议题：
  - 研究贯彻上级党组织的指示和决定
  - 讨论制定完成工作任务的办法
  - 研究党员的教育、管理和监督
  - 研究发展党员和预备党员转正

### 党小组会

- 频次：每月至少1次
- 内容：
  - 组织党员学习
  - 研究如何贯彻执行支部决议
  - 汇报思想和工作情况
  - 开展批评和自我批评

### 党课

- 频次：每季度至少1次
- 形式：
  - 专题讲座
  - 学习研讨
  - 先进事迹报告
