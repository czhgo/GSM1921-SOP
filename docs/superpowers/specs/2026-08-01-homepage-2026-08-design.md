## 背景与问题

书记 2026-08-01 四项指令：

1. **日期倒序规则**：任何带【时间】字段的数据，列示一律按时间倒序（最新在前）。已进入 8 月，首页日历 `select` 不得停留在 7 月。
2. **首页日历太窄长**：`div` 日历上下高度过大，应缩小为正方形格子（按最多放 3 个活动标签的空间设计）。
3. **书记工作台样式**：`span` 颜色不对、风格不对；待办卡片颜色有问题。禁止 hover 嵌套形式，卡片最外层只能有一个竖线（左边界线）。
4. **补 8 月 mock 活动数据**。

## 根因分析

- **月份选择器停留在 7 月**：`calendar.js populateMonthSelector` 是**数据驱动**——月份列表完全从非归档、有日期活动推导生成，默认选中优先级为「已有值 → 当前年月 → displayMonth → 最近月份」。8 月无活动数据，故 8 月不可选，首页停留在 7 月。**补齐 8 月 mock 数据后零代码修复**。
- **日历格子过高**：`.cal-cell-large` 默认 `min-height:8rem`（128px），紧凑视图沿用导致长条。
- **resize 回归**：`calendar.js` 全局 resize 监听无条件调用普通渲染器，覆盖首页紧凑方形视图。

## 设计方案（书记已批准）

### 1. 首页月份定位 2026-08

- 补齐 8 月活动数据后，`populateMonthSelector` 自动包含 2026-08，并按 `currentYearMonth()`（当前为 2026-08）优先默认选中——数据驱动、零代码修复。
- 兜底注释：`populateMonthSelector` 默认选中逻辑标注「书记 2026-08-01：已进入8月，不得停留在旧月」。

### 2. 首页紧凑方格日历

```css
/* 首页 compact 日历格子：正方形（高=宽），只容纳最多3个活动标签，压缩上下留白 */
.cal-cell-large.cal-cell-compact {
  min-height: 0;
  aspect-ratio: 1 / 1;
  padding: 4px;
  overflow: hidden;
}
```

- 浏览器实测 66×66px（原 128px，约减半），可容纳日期 + 最多 3 个活动标签。
- **resize 回归修复**：`calendar.js` resize 回调检测 `#activity-calendar-view` 存在（首页恒真）则复用 `renderCalendarForDashboard` 紧凑渲染器。

### 3. 书记工作台配色/嵌套修复

- **统计条圆点颜色**：4 个统计项（待赋权活动/活跃活动/本月活动/已赋权记录）由 4 种不同颜色统一为 accent `#B91C1C`（书记强调色，与 `ws-secretary-entry.js:28` 的 `const accent = '#B91C1C'` 一致）。
- **待办卡片去嵌套**：`todo-list.js` 分组项容器移除 `border border-gray-100 border-t-0` 内嵌边框（消除「卡片内再嵌卡片」双边框）；待办项仅最外层 `border-l-4` 红左边框，内部零竖线。
- **hover 嵌套禁令**：分组头移除 `border`（不再出现卡片内竖线 + hover 嵌套）。
