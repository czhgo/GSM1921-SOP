# 立项④：换组织向导（Org Setup Wizard）设计

日期：2026-09-06 · 状态：书记多轮裁定完成 → 阶段一实现
定位：开源「模板型」交付的核心体验——**换壳不换骨**，让新组织 30 分钟跑起来。

## Why

- 开源化评估（2026-09-06 v4）：组合/换壳是模板型的主价值；现有「党委台·支部配置」为裸开关清单，缺乏引导；「30 分钟换壳指南」是文档，未进产品。
- 书记裁定：向导吸收合并 party-config（单一界面），独立 URL 页可直达，书记与党委都有对应配置权力。

## 产品定义

一句话：**把「支部配置」升级为 5 步引导式换组织向导**，能即时改的即时改（支部名/主题可调令牌/模块块组合/角色分工），改不了仓库文件的（数据/制度/术语）生成「换壳工作单」下载，最后衔接验证与重置。

### 五步（书记已批口径）

1. **①组织信息**：支部名（必填）、自述/口号（文本）；主题色=**可调令牌预设**（党建红 party-red 与党徽金 party-gold 固定、锁定不可选，仅提供可调 accent 预设并说明固定/可调口径，见 COLOR_SYSTEM）。
2. **②模块/块组合**：业务 tab 启停与顺序 + 活动产出块开关（复用 branch 服务既有写口；核心组固定不可关）——即原 party-config 主体，收进步骤条。
3. **③角色分工**：workforce（模块负责人归属）编辑入口，指向既有 workforce 数据/UI 语义。
4. **④术语/制度/数据指引 + 工作单**：只读指引（替换入口总表要点）+ **生成并下载「换壳工作单」**（Markdown：已完成配置摘要 + 待手动替换文件清单 + 验证点）。
5. **⑤验证与重置**：应到名单口径核对（roster stats 现读数）、?reset=1 演示重置说明、npm test 提醒。

### 权限双轨（书记 R4 裁定）

- **现任书记**：独立 URL（`?branch=<自己的支部>` 自动限定）进入向导，仅可改本支部；不新增书记台常驻 tab。
- **党委（party-staff）**：党委台 party-config 页=向导式主体，可选任意支部 + 恢复默认。
- 写口沿用 branch 服务既有校验（party-staff / 本支部现任书记）；**配置变更即时生效 + 留痕**（谁/何时/改哪），不设审批闸。

### 入口形态

- 党委台 party-config 页主体改为向导（选支部头 + 步骤条）。
- 独立页面 `docs/wizard.html`（登录态感知：书记→本支部；党委→可切支部；无权限提示）——开源用户可把向导当首屏引导。

### 草稿与完成

- 每步改动即时落库（branch config/org 字段）；向导进度草稿存 localStorage（按 branch），中断可续。
- 完成报告页：摘要 + 下载工作单 + 去验证/重置。

## 阶段划分

- **阶段一（本批）**：5 步向导壳 + 可改即改（支部名/自述/主题可调预设/模块块/角色分工入口）+ 工作单下载(md) + 完成报告 + 草稿保存 + party-config 改造 + wizard.html 独立页 + 权限双轨 + 留痕 + 单测（报告生成/roster 衔接）。
- **阶段二（后续）**：JSON 覆盖件本地预览应用、多支部批量、引导语/样式打磨、党委对「默认模板」的全局默认。

## 技术要点（AI 层，不上升书记）

- 共享向导渲染器 `components/org-setup-wizard.js`（mount 到 party-config 内容区与 wizard.html）；写口走 branch 服务（config.modules/blocks/org 字段）；branch 服务增 `configChangeHistory`（追加 {by,at,what,from,to}）与 org 字段（name/desc/themePreset）。
- 主题 preset 运行时写 CSS 变量（仅可调集），固定令牌不改。
- 工作单生成放纯函数 `services/org-wizard-report.js`（可 node 单测）。
- 验证：纯 node（report 单测/导入冒烟）+ GetDiagnostics 零；浏览器交互目视待常规终端。

## Out of Scope（阶段一不做）

- 改仓库文件（mock/制度/术语）的在线编辑——只出工作单。
- 拖拽编排、审批闸、完整「党委默认模板」抽象（待多支部场景成形，先以复制到支部替代）、数据层（people/activities）覆盖预览。
- 已完：阶段一（5 步向导+工作单）＋阶段二（JSON 导出/本地预览导入、复制配置到支部、顺手打磨）。
