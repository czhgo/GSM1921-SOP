# About 页面设计系统——超参数设定原则

> **定位**：about 页设计的权威依据（保留「叙事册」风格）。**每个超参数的设定原则显式化**——任何一个数值（字号/倾斜/字距/高度/间距/透明度/停留时长）都必须能回答「为什么这样设定」。后续改动有据可依、可审（2026-08-19 T-272 确立：「对于每一个超参数，设定的原则是什么？要有自觉」）。
> **受众**：[工程师]+[AI]（任何修改 about 页的开发者）
> **关联**：[DESIGN_SYSTEM.md](../design-system/DESIGN_SYSTEM.md)（全站设计系统）→ 本文档为 about 页专项细则。

---

## 一、设计哲学

1. **叙事册风**：暖纸印刷质感 + 油墨宋题眼 + 党建红点睛——「好看的界面对于观者很重要，是推广宣传」（2026-08-19 确立）。
2. **超参数自觉**：每个数值都有设定原则；无原则的随机即「随意复制其他模块」，是反复强调要防止的。
3. **防风格疲劳**：变化靠**内容与结构**自然形成（时间轴/环形/SVG/竖排/错落散放），禁止装饰性错落堆叠、禁止各章同构排布。
4. **叙事章文字优先**：长文本正文（第一章落点、第二章机会卡）直排、左对齐、不倾斜——倾斜是海报语言，不适用于长文本。
5. **全页禁止「竖线」**：左侧红边线 / blockquote 左竖线 / 书签线等一切竖向线条——「掉价」（2026-08-19 红线）。层级区分改用**底色/字距**。

## 二、色板 tokens（设定原则）

| token | 值 | 设定原则 |
|-------|-----|---------|
| `--ab-paper-0` | #FAF8F4 | 页面底色：暖纸白，阅读底 |
| `--ab-paper-1` | #F6F2EB | 层级底：原话/引文淡底区分（**替代竖线**） |
| `--ab-paper-2` | #F0EBE2 | 深一级辅助底 |
| `--ab-paper-line` | #E6DFD2 | 极浅线：卡片完整边框/横向分隔，不抢内容 |
| `--ab-ink` | #3B3226 | 正文墨色：可读性主色 |
| `--ab-ink-sub` | #6C6254 | 次级文字（副题/说明） |
| `--ab-ink-faint` | #94897A | 弱化（页码/辅助小字） |
| `--ab-red` | #CE1126 | 党建红：**标题点睛 + 强调**，克制使用 |
| `--ab-red-deep` | #A80F1C | 深红强调（tag/重点短语） |
| `--ab-gold` | #C9A227 | 金色：**仅 hero 分隔线点缀**（孤立元素，全页仅此一处） |

**红色使用边界**：章题、关键词、强调短语可用红；正文、原话、说明一律墨色系——红色是「点睛」不是「底色」。

## 三、字体体系（分工原则）

| 字体 | 用途 | 原则 |
|------|------|------|
| 油墨宋 `NanxiYoumosong`（1063 字 woff2 子集） | 章题 / 关键词 / 题眼短语 | 「点题」用，**不用于长正文**；新增文案汉字须重建子集（`docs/scripts/rebuild-nanxi-subset.py`） |
| Noto Serif SC | 正文 / 引述原话 | 阅读主体，衬线叙事感 |
| Noto Sans SC | 辅助小字（眉线 / 页脚 / 说明） | 功能性弱化 |

**字距原则**：正文不设大字距；`letter-spacing ≥ 0.2em` 仅限封面副题、眉线等「印章/标语」型短文本（中文大字距会使字与字脱开，观感怪异）。

### 第一章「组织性」的展开

| 超参数 | 值 | 设定原则 |
|--------|-----|---------|
| 布局 | **左右分栏**：左 sticky 定格词区 + 右期待卡滚动驱动 | 书记 2026-08-28：「几个标题都不动，定格在左边，而右侧的卡片随着滚动移动」——`.ab-cognition-layout` grid（左 `minmax(220px,1fr)` / 右 `minmax(0,1.25fr)`）+ 左 `.ab-cognition-sticky` sticky |

| 属性词动画 | **无动画——左栏纯静态定格**（2026-08-28 T-300 改：去 view() 升起，见 about.css L525-526 注释「书记『左侧应当不动』：去 view() 升起动画，左栏纯静态定格」） | 2026-08-28 T-300 书记「左侧应当不动」——左侧词区 sticky 定格，滚动动画只保留给右侧期待卡（JS 驱动，T-299）；原 `ab-rise-in` 纯升起（全清歪斜后统一升起渐显）仅适用于右侧入场元素 |
| 章节 lead | **删去** | 书记 2026-08-28：「我不喜欢这句话」（原「一个正在建设中的组织，先向你介绍自己。」） |

### 第二章 三个成长机会

| 超参数 | 值 | 设定原则 |
|--------|-----|---------|
| 卡高 | `min-height: auto` | **文字优先**：内容决定高度（T-272 去 58vh 空洞留白） |
| 倾斜 | 0°（三卡垂直对齐） | 长文本正文不倾斜（倾斜=海报语言） |
| 卡宽 | `max-width: 100%`（满宽） | 阅读连续 |
| 对齐 | 左对齐 | 正文习惯 |
| 卡间距 | `gap: clamp(56px, 9vh, 120px)` | 三卡纵向呼吸 |
| 入场动画 | `ab-rise-in`（纯升起无旋转） | 无倾斜则动画不旋转 |
| 原话引用 | 16px 墨色 + `--ab-paper-1` 淡底（无竖线） | 无竖线红线 |

### 第六章 行百里者半九十（对话环形）

| 超参数 | 值 | 设定原则 |
|--------|-----|---------|
| `PLATEAU`（正午停留占比） | 0.55 | 停留仍可感知（「这是一步阶段」）但转动不拖——T-272 由 0.7 降至 0.55，转速约降 1/3（「转动太快」） |
| 角速度 `ROT_RATE` | `90° / ((1-PLATEAU)/4)` ≈ 800°/unit | **三段角速度统一**（进入/退出/正常转动同速率），滚动观感连续不突兀（T-272 反馈「三段速度不一样」） |
| 轨迹 | 椭圆：长轴 `rx = 1.2R` / 短轴 `ry = R` | 「长轴稍微长一点」——横向扫过范围 +20% 更舒展 |
| 半径 `R` | `min(S*0.56, S/2 - maxCardH/2 + 121)` | 环贴近舞台边缘；正午卡升起不遮章头 |
| 卡宽 | 192px | 略窄更舒展（T-248） |
| 亮度 | `b = angleH^1.5` | 正午 1 全亮、侧卡 ≈0.35 半透明、地下 <0.35 → 0 隐去（3 太阳模型） |
| 比例 | `scale = lerp(0.92, 1.05, b)` | 正午放大近看、侧卡收缩 |
| 进入/退出旋转 | 45° 线性，`θ = progress × ROT_RATE` | 旋转着进出（设计选择） |

### 收束（终章）

| 超参数 | 值 | 设定原则 |
|--------|-----|---------|
| 三层小字 | 36px 墨色感谢 / 26px 红期待 / 16px 淡灰小字 | 由大到小自然收尾，去口号（T-271） |

## 五、防风格疲劳规则

1. 视觉变化靠**内容与结构**自然形成：时间轴（第三章）/ SVG 网络（第五章）/ 环形公转（第六章）/ 关键词散落（第一章）/ 并列卡（第二章/第四章）。
2. **叙事章文字优先**：第一章落点、第二章机会卡——直排、左对齐、无装饰性倾斜、无空洞超高。
3. **错落=位移散落，禁止旋转歪斜（2026-08-28 书记裁定）**：错落是高低左右散落（scatter），不是歪斜旋转——第一章关键词用位移散落表达「方兴未艾」，旋转倾斜一律清理（含原「语义性错落」的 -1.5° 等）；为错落而错落同样禁止。
4. 一页一处视觉重点为限，不堆叠。

## 六、动/静自觉清单（全页）

| 类别 | 元素 | 自觉性说明 |
|------|------|-----------|
| 静 | 视窗（.ab-dialogue-flow/stage 容器） | 固定不缩放不平移 |
| 静 | 卡片文字 | 不 rotate，文字始终正立 |
| 静 | 地平线（即视窗底边） | 无视觉元素，界定消失线 |
| 动 | 卡片公转（第六章） | θ 驱动 opacity/scale/border/zIndex |
| 动 | 滚动行程（spacer 垫片） | 仅提供行程 |
| 动 | 章节标题镜头动画（ab-cam） | 进入驶入/滚出后拉压暗 |
| 动 | 升起渐显（ab-rise-in/ab-rise-scatter） | 进入视口升起，可逆滚出不反向 |
| 稳态 | 正午停留（PLATEAU）+ 卡①正午锚点 | 观看者感知「这是一步阶段」 |
| 非稳态 | 进入/退出段线性旋转 | 流畅过渡，无阶梯停顿 |

## 七、维护约定

- 修改 about 页任何超参数：**同步更新本登记表**（表四），并标注日期与理由。
- 新增文案汉字：重建油墨宋子集并 bump 版本号（禁止以其他字体冒充）。
- 违反无竖线红线 / 装饰性错落堆叠 / 叙事章非文字优先，视为设计事故（2026-08-19 红线）。
