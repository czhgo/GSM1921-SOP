# Checklist

## 运行时正确性（对应支书「点了 tab 渲染不出来」）

- [x] renderCtx 每次点击取最新 state；「切月 → 切走 → 切回」显示最新月份，不显示旧快照
- [x] `_safeRender` 与 `_renderCurrentTab` 使用同一套 seq/去重/清标记/await/错误可见
- [x] 陈旧 render 不得覆盖新 tab 内容；失败时显示可见错误与重试，不静默空白
- [x] 动态 import 与节点缺失均有可见失败态（不再只有 unhandledrejection）
- [x] loading 占位有超时（≤8s）并恢复可点；promise 永不落定不会永久灰化
- [x] 活动管理筛选（关键词/类别/品牌/清除）离开再回来仍生效
- [x] 隐藏/回退页签有提示，不出现「点 A 亮 B」无说明

## 关键性能（对应支书「加载慢、鼠标卡帧」）

- [x] 首屏不再有固定 600ms 硬等待；延迟可配置且默认 ≤120ms
- [x] 每页 `loadDB` 只执行一次；种子修复与派生只执行一次
- [x] `IssueStore/MilestoneStore.loadAll` 不再阻塞 tab 壳
- [x] 日历 hover 浮窗不再「写 DOM→读布局」同帧交替；浮窗阴影面积受控
- [x] 全局 MutationObserver 不再每次 DOM 变更扫描全文档 select
- [x] 三条实测基线已记录：首屏模块请求数 / 内容出现时间 / hover 帧间隔 p95；数值较改前有改善或如实说明

## 视觉基础（对应支书 1、2、3、5 条）

- [x] 同一 class 不再同时承载可交互与只读语义；`metric-band` 拆 `--static` / `--interactive`
- [x] `section` 只用于有 `aria-label` 的分区；其余统一 `div`
- [x] 卡内分组 8px 组内 / 16px 组间；`metric-band` 项间 8–12px，不再 0 间距+1px 线
- [x] 竖条与文字间距为 8px（不再被 `gap:4px !important` 压掉）
- [x] `neutral-400` 只用于装饰；数据零值/可点箭头/状态点提高到 `neutral-600` 或主题 soft-text，正文对比 ≥4.5:1
- [x] 分组胶囊在**所有宽度**可见（含 390/768/1024/1280/1440），高度 ≥24px，形状与页面底对比 ≥1.5:1；窄屏只缩小不隐藏
- [x] 链接全站单色（`--color-link`）：帮助链接、速查链接、角色色链接、about/help 蓝链全部并入；链接有下划线或箭头，箭头非 `neutral-400`
- [x] 关键表 `table-layout: fixed` + 列宽模板；末列不再吃掉全部余量；≤640 动作列 `flex-start`

## 色彩分工（对应支书 6 条）

- [x] 主题色层写成可复用标准（7 主题 × 亮/暗 × 9 token 的适用范围与禁止借用项），色盘值不改

- [x] 状态色只出现在徽章/点/提示条；类别色只用于活动类别；身份色只小面积；主题色只用于主行动/选中/链接
- [x] 链接全站单色（`--color-link`），帮助链接与角色色链接已并入（与视觉基础同一检查点）
- [x] 暗色下三会一课红/金与 danger/warning 可区分，不再逐值相同
- [x] `--accent-<role>` 与 `ROLE_COLORS` 合并为单一源；help/inspector 不再各写一套

- [x] 小面积功能色恢复（状态 4 / 类别 3），大面积仍中性；未恢复渐变卡头与彩色按压
