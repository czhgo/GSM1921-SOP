## 3. 党小组活动组织流程

```mermaid
flowchart TD
    Start([党小组活动启动])
    
    A[活动组织者: 发起活动策划]
    B{是否需要职能支持}
    
    C1[联系组织委员<br/>确认信息平台和通知]
    C2[联系宣传委员<br/>准备宣传材料]
    C3[联系纪检委员<br/>明确考勤要求和深度参与者]
    
    D[组织实施活动]
    
    E1[组织者: 完成活动复盘]
    E2[宣传委员: 归档材料]
    E3[纪检委员: 记录考勤/考察]
    
    End([活动完成])
    
    Start --> A
    A --> B
    B -->|是| C1
    B -->|否| D
    C1 --> C2
    C2 --> C3
    C3 --> D
    D --> E1
    E1 --> E2
    E2 --> E3
    E3 --> End
    
    style Start fill:#e1ffe1
    style A fill:#e1f5ff
    style C1 fill:#ffe1e1
    style C2 fill:#ffe1e1
    style C3 fill:#ffe1e1
    style D fill:#e1f5ff
    style E1 fill:#e1f5ff
    style E2 fill:#ffe1e1
    style E3 fill:#ffe1e1
    style End fill:#e1ffe1
```

**重要说明：**
- 活动组织者不一定是党小组组长或支委
- 组织者一般为支部党员（党员或预备党员）
- 支持项目制，鼓励灵活组织
- 这是考察积极分子和发展对象的重点场域

## 使用说明

### 图例说明
- **🔵 蓝色**：支部书记、副书记及其相关工作（条条组长）
- **🔴 红色**：组织委员、宣传委员、纪检委员及其职能工作（块块委员）
- **🟢 绿色**：党小组活动和成果
- **🟡 黄色**：职能支撑工作
- **⚪ 灰色**：教师指导或特殊情况

### 适用场景
1. **新支委学习**：从组织架构图开始，了解双重身份体系
2. **党小组组长**：重点查看党小组活动流程和党团班一体化流程
3. **块块委员**：重点查看制度建设流程和职能指导关系
4. **积极分子**：查看积极分子考察与发展流程

### 工作原则
1. **条条主导活动，块块提供支撑**
2. **支委决策为先，党小组落实为主**
3. **制度建设归块块，具体执行看条条**
4. **民主集中制贯穿始终**
