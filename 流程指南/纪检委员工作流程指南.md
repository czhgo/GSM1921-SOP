# 纪检委员工作流程指南

## 文档说明

本文档详细说明纪检委员（韩思宁）的工作流程、职责范围和操作规范，是纪检委员开展日常工作的核心参考文件。

**核心定位：** 纪检委员作为块块委员，横跨三个党小组，负责学习与考察制度建设、监督与议事制度建设、党员出勤与补课规范、意见建议反馈平台建设。

**特别说明：** 根据11月支部大会精神，学生支部不涉及特别多的"纪律问题"，因此纪检委员的工作重点包括**活动组织监督**和**考勤考察管理**。

**术语说明：**
- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- 不使用"普通党员"等具有层级性的表述

## 一、工作职责总览

### 1.1 核心职责（块块职能）

| 职责类别 | 具体内容 | 工作性质 |
|---------|----------|----------|
| 📋 学习与考察制度建设 | 制定考勤规范、考察标准、补课制度 | 制度建设 |
| 👁️ 监督与议事制度建设 | 建立意见反馈机制、监督工作落实 | 制度建设 |
| ✅ 党员出勤与补课规范 | 记录考勤、管理请假、安排补课 | 日常执行 |
| 💬 意见建议反馈平台建设 | 收集反馈、处理建议、跟踪落实 | 平台建设 |
| 🔍 活动组织监督 | 监督活动复盘、深度参与记录 | 监督执行 |

### 1.2 根据11月支部大会精神的特别职责

#### 职责一：活动组织与复盘监督

**11月支部大会要求：** 支部党员（党员/预备党员）须要【组织】或者【深度参与】支部活动。

**纪检委员职责：**
1. **监督活动复盘由组织者完成** - 活动复盘必须由组织者（支部党员）完成，不能委托给宣传委员
2. **记录深度参与情况** - 记录谁在活动中担任了宣传、现场统筹等具体工作
3. **建立活动参与档案** - 为党员发展提供依据

**重要说明：**
- 党小组活动的组织者不一定是党小组组长或支委
- 但组织者一般应该是支部党员（党员或预备党员）
- 这是考察积极分子和发展对象的重点场域

#### 职责二：考勤与考察分离管理

**必须明确：考勤和考察是两个分离的体系**

**考勤（0-1变量）：**
- 针对对象：支部党员（党员/预备党员）
- 适用活动：三会一课（支部委员会、支部党员大会、党小组会、党课）
- 记录内容：是否出勤、是否请假、是否补课
- 特点：二元变量，来了就是来了，没来就是没来，不考虑质量
- 汇总流向：考勤记录汇总给宣传委员进行汇总记录备案

**考察（复杂变量）：**
- 针对对象：所有支部成员（包括党员、预备党员、发展对象、积极分子）
- 适用活动：所有支部工作
- 记录内容：
  - **组织者** → 记录"组织"
  - **深度参与者** → 记录具体工作（宣传、现场统筹、其他工作）
  - **一般参与者** → 记录"出勤"
- 特点：复杂变量，记录参与的具体工作和贡献
- 使用方式：采用倒查法，通过个人申请后倒查其自述的参与情况

## 二、考勤管理（三会一课）

### 2.1 考勤范围与对象

#### 必须记录考勤的活动（三会一课）

| 活动类型 | 考勤对象 | 考勤要求 |
|---------|---------|---------|
| 支部委员会 | 支委会成员 | 必须出勤，特殊情况可请假 |
| 支部党员大会 | 支部党员（党员、预备党员） | 必须出勤，特殊情况可请假 |
| 党小组会 | 本党小组支部党员 | 必须出勤，特殊情况可请假 |
| 党课 | 支部党员、发展对象、积极分子 | 必须出勤，特殊情况可请假 |

**特点：** 这些是正式活动，不以追求创新性为第一目标，考勤是硬性要求。

#### 其他活动的考勤记录

对于党小组组织的其他学习活动、实践活动等，考勤记录方式如下：
- 如果是支部党员的必修活动，记录考勤
- 如果是自愿参加的活动，记录到考察系统（见第三节）

### 2.2 考勤记录标准

#### 三种考勤状态

| 状态 | 定义 | 记录方式 | 后续处理 |
|------|------|---------|---------|
| ✅ 出勤 | 按时参加，全程参与 | 在考勤表上打"√" | 无需处理 |
| 🏥 请假 | 事前申请（事假）或事后说明（病假） | 在考勤表上标注"假" | 需安排补课 |
| ❌ 缺勤 | 未到场且未请假 | 在考勤表上标注"缺" | 需了解原因并安排补课 |

**考勤的0-1特性：**
- 来了就是来了，没来就是没来
- 不考虑参与质量，不考虑是否开会时开小差
- 只记录客观的出勤事实

### 2.3 请假与补课制度

#### 请假规范

**事假：**
- 提前1天申请
- 说明请假原因
- 联系纪检委员韩思宁

**病假：**
- 可以事后补假
- 提供相关证明（如就医记录）
- 尽快联系纪检委员说明情况

**缺勤处理：**
- 未请假缺勤需及时联系说明原因
- 无故缺勤将影响考察意见
- 连续缺勤需与支部书记沟通

#### 补课制度

**补课安排原则：**
1. 请假或缺勤后，必须补课
2. 补课形式：
   - 阅读会议材料、学习资料
   - 观看会议录像（如有）
   - 向参会同志了解会议内容
   - 提交学习心得或总结
3. 补课完成后，纪检委员在考勤记录上标注"已补"

**补课时限：**
- 一般在请假/缺勤后1周内完成补课
- 特殊情况可延长至2周

### 2.4 考勤记录与汇总流程

```
活动前：准备考勤表 → 活动中：现场记录 → 活动后：整理汇总 → 定期：提交给宣传委员备案
```

#### 详细流程

| 阶段 | 工作内容 | 责任人 | 时间要求 |
|------|----------|--------|----------|
| **活动前** | | | |
| 1️⃣ 准备考勤表 | 根据活动类型准备考勤表，列出应到人员名单 | 纪检委员 | 活动前1天 |
| 2️⃣ 了解请假情况 | 收集事前请假申请，标注在考勤表上 | 纪检委员 | 活动前 |
| **活动中** | | | |
| 3️⃣ 现场签到 | 组织签到，记录出勤情况 | 纪检委员 | 活动开始时 |
| 4️⃣ 核对人数 | 核对实到人数与应到人数 | 纪检委员 | 活动开始后 |
| **活动后** | | | |
| 5️⃣ 整理考勤 | 整理考勤表，标注出勤、请假、缺勤 | 纪检委员 | 活动后1天内 |
| 6️⃣ 处理缺勤 | 联系缺勤人员了解原因 | 纪检委员 | 活动后2天内 |
| 7️⃣ 安排补课 | 为请假和缺勤人员安排补课 | 纪检委员 | 活动后3天内 |
| 8️⃣ 提交备案 | 将考勤记录汇总给宣传委员备案 | 纪检委员 | 活动后5天内 |

## 三、考察管理（支部工作参与）

### 3.1 考察的目的与原则

**考察目的：**
1. 记录所有支部成员参与支部工作的具体情况
2. 为党员发展提供客观依据
3. 鼓励支部党员【组织】或【深度参与】支部活动
4. **重点考察积极分子和发展对象的政治能力、工作能力、创造能力**

**考察原则：采用倒查法**
- 不是主动追踪每个人的每个行为
- 而是在个人申请（如发展党员、评优评先）时，对其自述进行倒查
- 如果自己都忘记了参与了什么工作，也没有追认的必要
- **工作量是重要的考察因素**

### 3.2 考察对象与记录内容

#### 考察对象

| 对象类别 | 考察重点 | 考察用途 |
|---------|---------|---------|
| 支部党员（党员） | 是否【组织】或【深度参与】活动 | 党员责任履行评估 |
| 支部党员（预备党员） | 是否【组织】或【深度参与】活动 | 预备党员转正考察 |
| 发展对象 | 组织和深度参与的政治能力、工作能力、创造能力 | 发展为预备党员的重点考察 |
| 积极分子 | 参与支部工作的态度和能力 | 发展为预备党员的考察 |

#### 记录内容（三个层次）

**1. 组织者（最高层次）**
- 定义：活动的主要策划者和组织者
- 适用对象：一般为支部党员（党员、预备党员），也可考察发展对象和积极分子的组织能力
- 记录内容：
  - 活动名称、时间、规模
  - 组织工作的具体内容
  - 活动效果和影响
- 记录形式：在考察档案中标注"【组织】XX活动"
- **特别说明**：组织者不一定是党小组组长或支委，体现项目制灵活性

**2. 深度参与者（中间层次）**
- 定义：在活动中承担具体工作的参与者
- 适用对象：支部党员、发展对象、积极分子
- 具体工作类型：
  - **宣传工作**：负责推文撰写、海报设计、照片拍摄等
  - **现场统筹**：负责场地布置、人员协调、流程管理等
  - **技术支持**：负责设备调试、直播技术、资料准备等
  - **其他工作**：其他可明确的具体贡献
- 记录形式：在考察档案中标注"【深度参与-宣传】XX活动"
- **特别说明**：这是考察积极分子和发展对象协调力、执行力的重要途径

**3. 一般参与者（基础层次）**
- 定义：参加活动但未承担具体工作
- 适用对象：所有成员
- 记录内容：出勤情况
- 记录形式：在考察档案中标注"【出勤】XX活动"

### 3.3 考察记录流程

```
活动策划时：明确分工 → 活动进行中：观察记录 → 活动结束后：确认角色 → 归档：建立考察档案 → 申请时：倒查验证
```

#### 详细流程

| 阶段 | 工作内容 | 责任人 | 时间要求 |
|------|----------|--------|----------|
| **活动策划时** | | | |
| 1️⃣ 了解活动分工 | 与活动组织者沟通，了解谁负责什么工作 | 纪检委员+条条组长 | 活动前5天 |
| 2️⃣ 记录预期角色 | 记录活动的组织者、深度参与者名单 | 纪检委员 | 活动前3天 |
| **活动进行中** | | | |
| 3️⃣ 观察实际参与 | 观察活动现场，记录实际参与情况 | 纪检委员 | 活动期间 |
| 4️⃣ 核对工作内容 | 确认深度参与者是否实际完成了承担的工作 | 纪检委员 | 活动期间 |
| **活动结束后** | | | |
| 5️⃣ 确认最终角色 | 与活动组织者确认最终的角色分工 | 纪检委员+条条组长 | 活动后3天内 |
| 6️⃣ 记录考察档案 | 在考察系统中记录每个人的参与情况 | 纪检委员 | 活动后5天内 |
| 7️⃣ 监督活动复盘 | 确认组织者完成活动复盘 | 纪检委员 | 活动后1周内 |
| **申请时** | | | |
| 8️⃣ 倒查验证 | 个人申请时，根据其自述倒查档案 | 纪检委员 | 申请提交后 |
| 9️⃣ 出具考察意见 | 根据档案记录出具考察意见 | 纪检委员 | 申请审查时 |

### 3.5 倒查法的应用

#### 倒查场景

| 申请场景 | 倒查内容 | 考察重点 |
|---------|---------|---------|
| 积极分子申请发展为预备党员 | 倒查参与支部工作情况 | 是否积极参与，是否有深度参与或组织经历 |
| 预备党员申请转正 | 倒查是否【组织】或【深度参与】活动 | 是否满足11月支部大会要求 |
| 评优评先申请 | 倒查对支部工作的贡献 | 参与次数、工作质量、影响力 |

#### 倒查流程

```
个人提交申请 → 提交自述（参与了哪些工作） → 纪检委员倒查档案 → 核对自述与档案 → 出具考察意见
```

**倒查原则：**
1. 以个人自述为起点
2. 在考察档案中查找验证
3. 如果自述准确，出具正面意见
4. 如果自述有出入，核实后出具客观意见
5. 如果自己都忘记了参与了什么，说明参与度不够，无需追认

## 四、活动组织监督

### 4.1 监督活动复盘完成情况

**根据11月支部大会精神：** 活动复盘必须由【组织者】完成，不能委托给宣传委员。

#### 监督流程

| 步骤 | 工作内容 | 责任人 | 时间要求 |
|------|----------|--------|----------|
| 1️⃣ 活动结束后提醒 | 提醒活动组织者完成活动复盘 | 纪检委员 | 活动后1天内 |
| 2️⃣ 跟进复盘进度 | 询问复盘完成情况 | 纪检委员 | 活动后5天 |
| 3️⃣ 检查复盘质量 | 检查复盘是否由组织者完成，内容是否充实 | 纪检委员 | 活动后1周内 |
| 4️⃣ 记录完成情况 | 在考察档案中记录是否完成复盘 | 纪检委员 | 活动后1周内 |
| 5️⃣ 反馈到支委会 | 定期向支委会汇报复盘完成情况 | 纪检委员 | 每月支委会 |

#### 复盘质量标准

**合格的复盘应满足：**
- [ ] 由活动组织者本人完成（不是委托他人）
- [ ] 内容具体，有实际的经验总结和改进建议
- [ ] 及时完成（活动后1周内）
- [ ] 使用活动复盘模板或类似结构

**不合格的复盘：**
- ❌ 委托给宣传委员或其他人完成
- ❌ 内容敷衍，走形式
- ❌ 拖延不完成

### 4.2 监督深度参与者的工作记录

**目的：** 确保【深度参与者】的贡献得到记录和认可。

#### 监督内容

| 监督对象 | 监督内容 | 记录要求 |
|---------|---------|---------|
| 宣传负责人 | 是否完成宣传材料制作 | 记录在考察档案中 |
| 现场统筹人 | 是否完成现场组织工作 | 记录在考察档案中 |
| 技术支持人 | 是否完成技术保障工作 | 记录在考察档案中 |
| 其他具体工作 | 是否完成承担的工作 | 记录在考察档案中 |

## 五、意见建议反馈平台

### 5.1 平台建设与维护

**平台目标：** 为支部成员提供意见建议反馈渠道，促进支部工作改进。

#### 反馈渠道

| 渠道类型 | 使用方式 | 适用场景 |
|---------|---------|---------|
| 直接反馈 | 直接向纪检委员韩思宁反馈 | 紧急或敏感问题 |
| 书面反馈 | 通过邮件或表单提交 | 需要详细说明的问题 |
| 会议反馈 | 在支部大会上提出 | 公开讨论的问题 |
| 匿名反馈 | 通过匿名渠道提交（如问卷） | 不便公开的问题 |

### 5.2 意见建议处理流程

```
收集意见 → 分类整理 → 提交支委会 → 讨论处理 → 反馈结果 → 跟踪落实
```

#### 详细流程

| 步骤 | 工作内容 | 责任人 | 时间要求 |
|------|----------|--------|----------|
| 1️⃣ 收集意见 | 通过各种渠道收集意见建议 | 纪检委员 | 持续 |
| 2️⃣ 分类整理 | 将意见建议分类（制度、活动、流程、其他） | 纪检委员 | 收到后1天内 |
| 3️⃣ 提交支委会 | 将意见建议提交支委会讨论 | 纪检委员 | 下次支委会 |
| 4️⃣ 讨论处理 | 支委会讨论处理方案 | 支委会 | 支委会上 |
| 5️⃣ 反馈结果 | 向提出者反馈处理结果 | 纪检委员 | 讨论后1周内 |
| 6️⃣ 跟踪落实 | 跟踪处理措施的落实情况 | 纪检委员 | 后续持续 |

#### 处理时限

| 问题类型 | 反馈时间 | 处理方式 |
|---------|---------|---------|
| 制度建设建议 | 下次支委会后 | 提交支委会讨论 |
| 活动组织建议 | 1周内 | 转相关条条组长处理 |
| 工作流程建议 | 2周内 | 提交相关块块委员研究 |
| 其他建议 | 1个月内 | 提交支委会研究 |

## 六、工作协调机制

### 6.1 与条条组长的协调

**协调原则：**
- 条条组长负责活动组织，纪检委员监督活动复盘和参与记录
- 条条组长需告知活动的分工情况，纪检委员需及时记录

**协调流程：**
```
条条组长组织活动 → 告知纪检委员分工 → 纪检委员记录考察档案 → 
活动后监督复盘 → 定期向条条组长反馈考察情况
```

### 6.2 与宣传委员的协调

**协调内容：**
- 考勤记录的定期提交（纪检委员 → 宣传委员）
- 活动档案的协同建设
- 复盘与宣传的职责明确

**提交内容：**
- 三会一课的考勤记录
- 请假、补课情况统计
- 定期提交（每月或每季度）

### 6.3 与组织委员的协调

**协调内容：**
- 积极分子考察信息的交流
- 思想汇报提交情况的核对
- 党员发展工作的配合

### 6.4 与支部书记的协调

**汇报机制：**
- 定期向支部书记汇报考勤考察工作
- 重大问题及时请示
- 支委会上汇报阶段性工作

**汇报内容：**
- 考勤情况统计
- 考察档案建设进展
- 意见建议处理情况
- 活动复盘完成情况

## 七、常见问题解答（FAQ）

### Q1: 考勤和考察有什么区别？

**考勤（0-1变量）：**
- 针对三会一课
- 只记录出勤/请假/缺勤
- 来了就是来了，没来就是没来
- 汇总给宣传委员备案

**考察（复杂变量）：**
- 针对所有支部工作
- 记录组织/深度参与/普通出勤
- 记录具体工作内容和贡献
- 用于党员发展和评优评先

### Q2: 如果活动组织者没有完成复盘怎么办？

**处理流程：**
1. 活动后1周内第一次提醒
2. 活动后2周再次提醒
3. 仍未完成，向支委会报告
4. 在考察档案中记录"未完成活动复盘"
5. 影响后续考察意见

### Q3: 如何判断一个人是"深度参与者"？

**判断标准：**
- [ ] 在活动中有明确的具体工作分工
- [ ] 实际完成了承担的工作
- [ ] 工作内容可以被观察和验证
- [ ] 不是简单的参与，而是有实质贡献

**不算深度参与：**
- ❌ 只是参加活动，没有具体工作
- ❌ 挂名但实际没做什么
- ❌ 工作内容无法验证

### Q4: 倒查法如何防止造假？

**防止造假机制：**
1. 考察档案是实时记录的，不是事后补充
2. 活动组织者会确认深度参与者名单
3. 宣传委员的档案中也有宣传负责人记录
4. 多个信息源交叉验证
5. 自述与档案不符时需要说明

### Q5: 如果有人忘记自己参与了什么工作怎么办？

**按照倒查法原则：**
- 如果自己都忘记了，说明参与度不深
- 没有追认的必要
- 鼓励大家主动关注和记住自己的贡献
- 深度参与的工作不应该被轻易忘记

### Q6: 请假和缺勤有什么不同？

**请假：**
- 事前申请（事假）或事后说明（病假）
- 视为正常，不会有负面影响
- 需要补课

**缺勤：**
- 未到场且未请假
- 需要了解原因
- 无故缺勤会影响考察意见
- 需要补课

**每周检查：**
- [ ] 是否有即将召开的三会一课，是否准备好考勤表
