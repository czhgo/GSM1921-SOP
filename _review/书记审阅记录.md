## 场景1：我要组织一次党小组活动

### 书记核心决策：必须区分两类活动

当前 SOP 把所有党小组活动混为一谈，用同一套 8 步流程覆盖。**书记要求拆分为 A/B 两类：**

#### 类型A：组织生活会类（严肃政治会议）
- **性质：** 民主评议党员、批评与自我批评、组织生活会
- **为什么放在党小组：** 人少、氛围更真实、更容易讲真话
- **参与者：** 仅限中共党员和预备党员
- **考勤：** 刚性（三会一课范畴）
- **宣传：** 需要宣传（摘要性文字+配图，纳入x月推送），但不需要逐字记录每个人说了什么
- **复盘：** 不需要复盘，用工作记录模板
- **档案：** 必须归档，证明开过会

#### 类型B：灵活学习活动
- **性质：** 学习会、分享会、外出参访、调研、联学共建等
- **为什么放在党小组：** 更小体量、更少身份制约、更大互动空间、更确定的服务对象
- **参与者：** 支部成员（党员+预备党员+发展对象+积极分子），可跨组参与
- **考勤：** 弹性考勤，对党员也是鼓励；但组织者和深度参与者要起到重要作用
- **宣传：** 需要宣传（纳入推送），AB都不需要宣传预热
- **复盘：** 需要复盘，可由积极分子完成，条条组长起指导作用
- **品牌方向：** 第一党小组=学术组，第二/三党小组=就业组

#### 核心原则
> 除了发展党员、转正、换届等需要严肃重要的投票，其他都可以往党小组压。

#### 修改2：补充 A 类活动（组织生活会）的特殊程序 🔴高优

**当前问题：** SOP 完全没有组织生活会的程序说明。
**官方依据：** 《中国共产党支部工作条例（试行）》（2018）第十一条、第十四条对组织生活会有明确规定。《党员教育管理工作条例》（2019）也有相关要求。
**修改要求——A类活动的标准程序：**

```
会前准备阶段：
1. 确定主题 → 条条组长根据支部书记/支委会部署确定会议主题
2. 会前谈心谈话 → 组长与本组党员逐一谈心，了解思想状况
3. 对照检查 → 通知党员提前撰写个人对照检查材料/自我评价
4. 通知到人 → 联系组织委员通过信息平台通知（提前至少3天）

会中实施阶段：
5. 签到考勤 → 纪检委员负责（刚性考勤，三会一课范畴）
6. 个人自我评价 → 每位党员做自我批评
7. 党员互相批评 → 开展批评，要有辣味
8. 组长汇总总结 → 条条组长做总结发言

会后归档阶段：
9. 会议记录 → 使用「申报材料模板/工作记录类/党支部工作记录.docx」模板
10. 宣传产出 → 摘要性文字+配图，纳入月度推送（宣传委员负责）
11. 考勤记录 → 纪检委员记录归档
12. 档案归档 → 宣传委员归档全部会议材料
```

**产出物清单（A类）：**
- [ ] 会议记录（工作记录模板）
- [ ] 签到表
- [ ] 个人对照检查材料（如适用）
- [ ] 宣传摘要+配图

**注意：** Agent 需检查 `官方文件/【附件17】中国共产党支部工作条例（试行）（2018年10月28日）.docx` 和 `官方文件/【附件12】党支部工作规范（学生）.pdf` 中是否有更详细的程序要求或流程图，如有则以官方文件为准进行修正。

#### 修改3：补充 B 类活动的完整流程 🔴高优

**修改要求——B类活动的标准流程：**

```
策划报备阶段：
1. 活动发起 → 组织者（党员）策划活动方案
   - 如果有历史品牌活动：组长承担职责，招募人手来"组织"和"深度参与"
   - 如果没有现成活动：支书及组长与党员积极沟通，办参与成本低但有组织效应、能学到东西的活动
2. 组长审批 → 必须报条条组长审批同意
3. 联系块块 → 按需联系组织/宣传/纪检委员

准备阶段：
4. 信息通知 → 联系组织委员发送通知（室内活动提前2天，外出活动提前建群并确保2天前所有人员到位）
5. 宣传准备 → 确认宣传负责人（深度参与者），宣传委员指导
6. 考勤准备 → 联系纪检委员确认考勤方式（弹性）

实施阶段：
7. 活动实施 → 组织者负责全程
   - 室内活动check清单：签到、拍照（至少3张不同角度）、活动记录
   - 外出活动check清单：人员确认、安全须知、交通方式确认、拍照记录、活动记录

收尾阶段：
8. 活动复盘 → 组织者完成（可由积极分子完成，条条组长指导），1周内完成
   - 使用模板：活动复盘/活动复盘模板.md
9. 宣传产出 → 活动摘要+配图，纳入月度推送
10. 材料归档 → 组织者将材料主动交给宣传委员归档
11. 考勤记录 → 纪检委员记录（弹性考勤）
```
