# 组织委员工作流程指南

> 考勤与考察档案同源、思想汇报由党员系统内提交自动归档的规则，与纪检委员指南一致；公共规则见 [常见工作场景快速指南.md](./常见工作场景快速指南.md) 公共规则表。

> **一句话：** 按支部制度参数统筹专班工作组，并办理发展党员材料与考察职责。

**术语**（支部党员/支部成员/条条/块块）：见 [INDEX.md](./INDEX.md#术语)

## 适用角色

**组织委员**

- **工作组协调**：组织委员为专班工作组默认扎口角色；如支部制度参数另有规定，按配置角色分工。党委维护业务能力目录与模板，支部自主选择启用能力包。
- **事项治理**：明确工作组任务、成员分工与预期产出；只有制度或具体议程明确要求时，才提交支委会表决。工作组成员关系不自动授予系统权限。
- **发展党员的材料准备**：按制度要求办理考察档案、思想汇报与发展协助；不得把工作组成员身份自动视作必须考察。
- **数据共享**：考勤由纪检委员维护；组织委员按职责读取已登记记录，避免重复录入。

### 为什么这么做

- 工作组是任务协作载体，专班不必先经过统一表决，也不自动产生考察和工作量报告。
- 成员、任务、产出分别记录；只有需要系统写权限时，才通过独立授权记录授予并留痕。
- 全部已登记任务和产出闭合后工作组可收尾，历史保留并只读；旧记录缺少可靠任务时，由经办人核实后补录。

## 工作台 — 工作组管理视图（工作台内 tab）

> 在系统中，组织委员进入工作台后的落点为 **「今天」**；**工作组管理**是其工作台内的一个 tab，可在专班工作组和活动工作组间切换。专班仍是与活动并列的业务概念：活动工作组随活动创建，专班工作组围绕自身任务存在。

> **设计考量**：以工作组为主对象，成员分工、权限、任务和产出作为关联信息；活动与专班的业务语义和流程各自保留。专班可承载材料申报/审查、刊物制作等跨时间任务，也可按具体任务关联活动或能力包。
> 母本引用：[COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.4–§A.7 与 [DATA_MODEL.md](../../04_web_design/data/DATA_MODEL.md) §2.3.1

### 任务流

| 步骤 | 动作 | 时机 |
|------|------|------|
| 1 | 明确工作组任务、适用能力包（如有）、负责人和预期产出 | 建立前 |
| 2 | 建立专班工作组并登记组织者、深度参与者；需要系统写权限时另行授予 | 人员确定后 |
| 3 | 维护任务、进度与产出；需要关联活动时，在具体任务或产出上建立同支部关联 | 执行中 |
| 4 | 核对所有已登记任务和产出均已闭合；明确要求的考察或表决须完成 | 收尾前 |
| 5 | 办理收尾；历史记录保留并只读 | 闭合后 |

### 工作组建档与治理条件

- **记录字段**：名称、所属支部、工作组类别（活动/专班）、来源业务记录、成员及角色、任务、产出、状态，以及必要的能力包/活动关联。工作组成员与任务产出分层记录。
- **边界**：跨支部关联由服务端拒绝；成员关系不自动授予系统权限；活动承办范围不限制参与资格。能力包关闭后停止新开，在办事项可完成，历史只读保留。
- **表决**：只有制度或具体议程明确要求时，才登记依据并提交表决，不因建立专班而一律表决。
- **结束**：所有已登记任务和产出闭合即可收尾。纪检考察只在事项明确要求时办理；旧记录缺少主任务时，经办人核实后补录，系统不推断业务含义。

> 母本引用：[COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.4–§A.7 与 [DATA_MODEL.md](../../04_web_design/data/DATA_MODEL.md) §2.3.1

### 验收成果

- [ ] 每个新工作组都有明确任务、成员职责和支部归属
- [ ] 登记任务与产出闭合后可收尾，历史可查且只读
- [ ] 明确要求的考察或表决有对应记录；未要求的事项不会被流程强加

> **系统承载**：工作组主记录、成员、授权、任务和产出经语义化接口分别保存。旧专班状态保留兼容展示；实际收尾条件以工作组任务和产出记录为准。

## 发展党员的考察与材料准备

### 一、考察档案维护

**信息流**：
```
发展对象名单（支委会确定）
    │
    ▼
组织委员建立/维护考察档案
    │
    ▼
发展对象个人档案（含思想汇报 → 转正材料）
```

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 获取发展对象名单 | 支委会会议纪要 |
| 2 | 建立考察档案（系统内为「数据交接·考察建档」确认接收；档案文本存 `content/03_doc_system/工作模板/`） | 档案目录完整 |
| 3 | 每半年更新考察意见（线下文本） | 有支书签字的考察表 |
| 4 | 转正前汇总全周期档案（线下移交） | 完整档案包移交支委会 |

> **数据同源提醒**：考察档案中的「活动出勤」数据，直接使用纪检委员维护的考勤系统数据，不与考勤表重复录入。「思想汇报」由党员在系统内提交，算法自动归档归集，组织委员查看调用。

> **考察档案记录结构**：每条考察记录包含以下信息——来源类型（活动/专班）、关联活动名称、参与类型（组织者/深度参与者/普通参与者）、具体角色描述、**记录人**；记录时间一并留存。

> **设计考量**：考勤同源而思想汇报不同源——考勤由组织者上传、纪检委员打包确认，组织委员直接读取避免数据冲突；思想汇报由党员在系统内直接提交、算法自动归档（纪检委员不介入），组织委员查看调用。两者写入方不同，数据流也不同。
> 母本引用：[SYSTEM_ROLE_PERMISSION.md](../SYSTEM_ROLE_PERMISSION.md)（系统角色权限矩阵）

### 二、思想汇报归档（算法归档）

**信息流**：
```
党员/发展对象在系统提交思想汇报（文本直接提交）
    │
    ▼
系统自动归档至对应个人档案（算法归集，无需人工归档环节）
    │
    ▼
组织委员查看/调用（考察时直接调用思想汇报记录）
```

> **流向说明**：思想汇报由党员/发展对象在系统内直接提交，提交即入库即归档——算法自动归集到对应个人档案，组织委员只做查看与调用，不再有「收齐→归档」的人工环节。纪检委员不介入思想汇报流程，仅负责考勤考察。

### 为什么这么做

- **职能归口**：组织委员承担发展党员的考察与材料准备，考察档案和思想汇报都是发展党员的核心材料，归口同一人确保材料衔接不断裂
- **权责分离**：纪检委员因权责分离要求不组建专班（审查权限不可转授），同理不介入思想汇报——纪律审查与思想表达分属不同职能

母本引用：[支委与党小组定人定责定岗说明.md](./支委与党小组定人定责定岗说明.md) §2.1 条条支委职责 + [COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.6 条块衔接规则

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 掌握各党小组思想汇报的提交情况（按系统「人 × 期次」台账） | 与系统归档记录一致 |
| 2 | 查看系统自动归集的思想汇报（系统已归档至个人档案） | 每份有日期标记 |
| 3 | 考察时调用思想汇报记录 | 记录完整可调用 |

### 三、发展党员协助

**信息流**：
```
支委会确定发展计划
    │
    ▼
组织委员启动材料准备
    │
    ▼
公示（线下） → 支部党员大会 → 上级审批（线下）
```

**关键动作**（按发展节点）：

| 节点 | 必须交付 |
|------|----------|
| 确定发展对象 | 发展对象登记表 + 考察档案初稿 |
| 接收预备党员 | 入党志愿书 + 公示材料 + 支部大会记录 |
| 预备党员转正 | 转正申请书 + 全年考察档案 + 支部大会决议 |

> 完整材料清单见附录 A「发展党员时间轴与材料清单」；材料文本在系统外办理，系统只做数据归集与提醒（见附录 A「系统提示」栏）。

## 附录 A：发展党员时间轴与材料清单

> 从入党申请人到正式党员的完整路径；除「思想汇报」在系统内提交外，材料与环节均线下办理，系统只对两个期满节点给出提醒（见「系统提示」栏）。

### 发展阶段与交付物

| 阶段 | 关键动作 | 必须交付 | 系统提示 |
|------|---------|---------|---------|
| 入党申请人 | 提交入党申请 | 入党申请书 | — |
| 积极分子 | 支委会确定 + 培养考察期一年以上 | 积极分子登记表 + 培养联系人考察记录（纸质） | 培养考察期满提醒 |
| 发展对象 | 支委会讨论确定 | 发展对象登记表 + 考察档案初稿 + 政审材料 | — |
| 预备党员 | 接收大会 + 公示 + 上级审批 | 入党志愿书 + 公示材料 + 支部大会记录 | — |
| 预备期 | 一年预备期考察 | 半年考察意见 + 思想汇报 | — |
| 正式党员 | 转正申请 + 支部大会 + 上级审批 | 转正申请书 + 全年考察档案 + 支部大会决议 | 预备期满提醒 |

### 各阶段材料清单

**积极分子阶段**：
- 积极分子登记表（姓名/班级/申请日期/培养联系人）——纸质材料，系统内不设该表 / 该栏
- 培养联系人考察记录（每半年一次，含考察意见和培养建议）——由培养联系人以纸质材料撰写（有专门的纸质材料要求），系统内不设该栏 / 该功能
- 思想汇报（积极分子不作硬性要求，按实际培养与需要安排）

**发展对象阶段**：
- 发展对象登记表（含支委会确定日期）
- 考察档案初稿（含培养考察期全程记录）
- 政审材料（本人及直系亲属政治审查）
- 群众意见征求记录

**预备党员阶段**：
- 入党志愿书（本人填写）
- 公示材料（公示期不少于五个工作日——上级《中国共产党发展党员工作细则（2026年）》第十三条）
- 支部大会记录（含表决结果）
- 上级党组织审批意见

**转正阶段**：
- 转正申请书（预备期满前提交）
- 全年考察档案（含半年考察意见）
- 支部大会决议（含无记名投票结果）
- 上级党组织审批意见

## 检查清单

> 自查随任务产生，不按固定频次——任务走到哪一步就勾哪些项，做完即闭环。

### 专班管理
- [ ] 核对工作组任务、成员、产出和关联范围
- [ ] 收尾时确认所有已登记任务与产出已闭合
- [ ] 仅对制度/议程明确要求的事项检查表决或纪检考察记录

### 发展党员
- [ ] 考察档案更新（所有发展对象）
- [ ] 查看思想汇报提交情况（系统自动归集）
- [ ] 核对思想汇报提交完整（系统按人归集，查缺补漏）
- [ ] 发展对象全周期档案汇总
