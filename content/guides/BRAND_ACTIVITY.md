# 品牌活动规划 — 知识留存摘要

> ⏸️ **本轮搁置（2026-05-03）**：当前优先搭建短期/长期双轨工作流。品牌维度为叠加层，待双轨稳定后再上。完整设计文档已归档至 `.ctx/logs/DECISION_LOG.md` §BRAND。

---

## 一、核心定义与定位

品牌活动是支部长期培育、持续迭代的**动态工作项目**，非一次性事件。

### 1.1 四属性

| 属性 | 说明 |
|------|------|
| 持续性 | 跨学期/年度运营，非单次收场 |
| 成长性 | 萌芽 → 培育 → 成熟 → 标杆 四阶段 |
| 迭代性 | 执行 → 复盘 → 优化 → 再执行 |
| 体系性 | 方法论 + 资源库 + 人才梯队 |

### 1.2 在四维度框架中的位置

品牌活动作为活动管理**四维度框架**中的"品牌"维度（`brand` vs `non-brand`），与时长、发起方向、子类型正交：

- 一个品牌活动可以是短期（单次品牌发布）或长期（跨学期运营）
- 品牌活动可以是自上而下（支委发起培育）或自下而上（党员自发→支委认定）
- 品牌活动的子类型不限于单一类别——宣讲团可能包含"学习+座谈+共建"等多子类型

> **重要纠正（2026-05-03）**：品牌活动是**直接认定**而非靠复杂评分算法计算。原有设计中的"认定与评分框架"（硬性门槛、加权评分、量化维度）是 AI 对业务逻辑的误解，已删除。实际操作中，支部根据活动的持续性、影响力、培育价值直接判断是否列入品牌活动。

## 二、典型锚点案例

以下两个真实案例是品牌活动概念的**经验锚点**——通过长期观察这些案例的运营特征，可以非监督地发现活动分类的更多维度。

### 案例一：宣讲团

| 维度 | 内容 |
|------|------|
| **类型** | 对外输出型 |
| **培育路径** | 自组织萌芽 → 支委识别价值 → 给予资源扶持 |
| **核心特征** | 从零搭建、持续壮大、对外展示、可复制推广 |
| **运营模式** | 成员自主选题→备课→试讲→对外输出→复盘迭代 |
| **对四维度框架的启示** | 宣讲团的活动可以在不同子类型间切换：学习会（内部打磨）、座谈会（对外交流）、参访（走进班级/社区），说明品牌活动天然是**跨子类型**的 |
| **关键经验** | 自下而上的生命力 + 支委的资源匹配 = 品牌孵化的最优路径 |

### 案例二：人生回望录

| 维度 | 内容 |
|------|------|
| **类型** | 内容生产型 |
| **培育路径** | 个人发起 → 团队扩展 → 制度化运营 |
| **核心特征** | 老教授深度访谈、跨学期滚动播出、形成内容资产库 |
| **运营模式** | 选题策划→联系访谈对象→采访录制→后期剪辑→分期发布→读者反馈 |
| **对四维度框架的启示** | 这是一个"长期"品牌活动，但每期产出又是独立可追踪的"短期"单元。品牌维度天然需要**长/短期双轨支持**——这正是品牌搁置、优先搭建双轨的技术理由 |
| **关键经验** | 内容型品牌活动产生**可累积的知识资产**，其价值随时间递增——这与一次性活动有本质区别 |

### 案例启示总结

从两个案例提炼的品牌活动共性特征：

1. **自发性 > 指派性**：最成功的品牌活动来自党员自发的兴趣和热情
2. **支委的角色是赋能而非指挥**：识别→扶持→制度化，而非设计→分配→检查
3. **跨类型融合是品牌活动的天然属性**：一个品牌活动往往跨越多个子类型
4. **品牌活动的"资产性"**：产生可复用、可传承的产出物（方法论文档、内容库、人才技能）
