# 全栈工程与经验沉淀学习入口

> 目录定位见 [DOC_MAP.md §五 目录作用表](../03_doc_system/DOC_MAP.md#五目录作用表2026-10-24-立)。

## 作用

本目录是**面向人的跨层经验串讲与学习入口**，回答「这些规范怎么连起来、按什么顺序学、遇到问题时先想什么」。

## 不负责什么

- 不承担规范效力——规范唯一权威源在 `03_doc_system/`、`04_web_design/`、`05_ai_coding/`。
- 不复写规范条文——文章只解释与串联，细节一律回链权威源。
- 不写逐批过程与证据——归 `.ctx/logs/`、`.ctx/evidence/`。
- 不写支部制度与 SOP 正文——归 `02_institution/`。

## 权威源与派生

- **本目录无权威源**：文章均为派生性解释，冲突时以 `03_doc_system/OPERATIONS_GUIDE.md`、`04_web_design/` 各唯一权威源、`05_ai_coding/` 五个分篇为准。
- **入库标准**：文章写「别的语境也能成立的通用表述」，项目判例只作支撑；不复制规范条文，不保留改写痕迹。
- **跨目录引用**：每篇末尾与正文中的规范细节必须带相对路径回链；工程评分与残项以 [`.ctx/ENGINEERING_ASSESSMENT.md`](../../.ctx/ENGINEERING_ASSESSMENT.md) 为准。

## 知识流向

`03_doc_system/` / `04_web_design/` / `05_ai_coding/` 的规范 → 结合 `.ctx/logs/` 的真实判例 → 在此去语境化写成「原则 + 条件 + 判例」的学习文章 → 读者按文末回链进入权威源；**结论不在此新立**。
