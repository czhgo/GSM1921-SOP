# 流程指南文档目录

本目录包含支部工作的核心流程指南文档，帮助支委和党小组成员快速了解工作流程和操作规范。

## 📚 文档导航

### 🌟 推荐首次阅读顺序

1. **[常见工作场景快速指南.md](./常见工作场景快速指南.md)** ⭐ **最实用**
   - **适合：** 首次使用者、需要快速查询的同志
   - **内容：** 9个常见工作场景的快速操作指南
   - **特点：** 按场景组织，一站式查询

2. **[支委与党小组定人定责定岗说明.md](./支委与党小组定人定责定岗说明.md)** ⭐ **最全面**
   - **适合：** 新任支委、党小组组长
   - **内容：** 详细的人员身份、职责划分和岗位说明
   - **特点：** 系统全面，完整的条条块块体系

3. **[工作流程图-定人定责定岗.md](./工作流程图-定人定责定岗.md)** ⭐ **最直观**
   - **适合：** 需要了解具体流程的同志
   - **内容：** 10个可视化Mermaid流程图
   - **特点：** 图文并茂，直观易懂

4. **[组织委员工作流程指南.md](./组织委员工作流程指南.md)** ⭐ **组织委员必读**
   - **适合：** 组织委员及组织工作相关人员
   - **内容：** 信息平台建设、思想汇报归档、党员发展协助
   - **特点：** 专项详细，操作性强

5. **[宣传委员工作流程指南.md](./宣传委员工作流程指南.md)** ⭐ **宣传委员必读**
   - **适合：** 宣传委员及宣传工作相关人员
   - **内容：** 宣传委员专项工作流程（支部大会、党小组会、申报材料）
   - **特点：** 专项详细，操作性强

6. **[纪检委员工作流程指南.md](./纪检委员工作流程指南.md)** ⭐ **纪检委员必读**
   - **适合：** 纪检委员及考勤考察相关人员
   - **内容：** 考勤考察分离管理、活动复盘监督、倒查法应用
   - **特点：** 明确考勤（0-1变量）与考察（复杂变量）的区别

## 🔑 核心概念速查

### 条条与块块双线管理体系

**条条（纵向业务线）：** 党小组组长
- 储子禾（第一党小组-学术组）
- 王峥旭（第二党小组-就业组）
- 辛长乐（第三党小组-就业组）
- **职责：** 具体活动组织和品牌建设
  
**块块（横向职能线）：** 支委委员
- 侯嘉嵘（组织委员）- 党员发展、考察档案、信息平台
- 闫鑫岳（宣传委员）- 宣传档案、材料模板、活动记录
- 韩思宁（纪检委员）- 考勤管理、活动监督、参与记录
- **职责：** 制度建设和职能保障

### 协作原则

- **条条主导活动组织**，块块提供职能支撑
- **支委决策为先**，党小组落实为主
- **定人定责定岗**，避免职责交叉混乱

### 术语说明

- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- **三会一课** = 支部委员会 + 支部党员大会 + 党小组会 + 党课
