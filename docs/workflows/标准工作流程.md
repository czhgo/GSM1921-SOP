# 党支部标准工作流程

## 一、"三会一课"制度

### 1. 党员大会

**目的**：党支部的议事决策机构，讨论决定支部重大事项。

**频次**：每季度至少召开1次

**流程**：
1. **会前准备**（提前1周）
   - [ ] 支部书记确定会议议题
   - [ ] 组织委员通知全体党员
   - [ ] 准备相关材料和文件
   - [ ] 确定会议时间、地点

2. **会议召开**
   - [ ] 清点到会人数（须有半数以上党员到会）
   - [ ] 支部书记主持会议
   - [ ] 传达上级精神和要求
   - [ ] 讨论决定支部重要事项
   - [ ] 进行表决（需要时）
   - [ ] 做好会议记录

3. **会后工作**
   - [ ] 整理会议记录
   - [ ] 向上级党组织报告（必要时）
   - [ ] 督促决议事项落实
   - [ ] 归档会议材料

### 2. 支部委员会会议

**目的**：研究支部日常工作，贯彻上级指示。

**频次**：每月至少召开1次

**流程**：
1. **会前准备**
   - [ ] 确定会议议题
   - [ ] 通知支部委员
   - [ ] 准备相关材料

2. **会议召开**
   - [ ] 支部书记主持
   - [ ] 研究讨论议题
   - [ ] 做出决定
   - [ ] 记录会议内容

3. **会后落实**
   - [ ] 分工负责执行
   - [ ] 跟踪落实情况

### 3. 党小组会

**目的**：落实支部决议，开展党员日常教育管理。

**频次**：每月至少召开1次

**流程**：
1. **会前准备**
   - [ ] 党小组长确定议题
   - [ ] 通知小组党员
   - [ ] 准备学习材料

2. **会议召开**
   - [ ] 组织学习讨论
   - [ ] 汇报思想工作
   - [ ] 开展批评和自我批评
   - [ ] 做好会议记录

3. **会后总结**
   - [ ] 向支部汇报情况
   - [ ] 落实会议要求

### 4. 党课

**目的**：对党员进行系统教育。

**频次**：每季度至少1次

**流程**：
1. **课前准备**（提前2周）
   - [ ] 确定党课主题
   - [ ] 选定授课人
   - [ ] 准备课件材料
   - [ ] 通知参加人员

2. **党课实施**
   - [ ] 签到
   - [ ] 授课
   - [ ] 互动讨论
   - [ ] 总结点评

3. **课后工作**
   - [ ] 收集学习心得
   - [ ] 整理存档
   - [ ] 评估学习效果

## 二、组织生活会

**目的**：开展批评和自我批评，增强党性。

**频次**：每年至少召开1次

**流程**：

### 1. 会前准备（提前1个月）
- [ ] 制定工作方案
- [ ] 学习规定文件
- [ ] 广泛征求意见
- [ ] 开展谈心谈话
- [ ] 撰写对照检查材料
- [ ] 上级审核材料

### 2. 会议召开
- [ ] 通报上年度组织生活会整改落实情况
- [ ] 通报本次组织生活会征求意见情况
- [ ] 支部班子及成员进行对照检查
- [ ] 开展批评和自我批评
- [ ] 民主评议党员
- [ ] 上级党组织点评

### 3. 会后整改
- [ ] 制定整改措施
- [ ] 明确整改时限
- [ ] 落实整改责任
- [ ] 向党员群众公开整改承诺
- [ ] 定期报告整改进展

## 三、民主评议党员

**目的**：评价党员履行义务情况。

**频次**：每年至少开展1次

**流程**：

### 1. 学习教育
- [ ] 组织学习党章
- [ ] 学习习近平新时代中国特色社会主义思想
- [ ] 学习党的路线方针政策

### 2. 自我评价
- [ ] 党员对照标准自评
- [ ] 撰写自评材料
- [ ] 在党员大会上述职

### 3. 民主评议
- [ ] 党员互评
- [ ] 群众参与评议
- [ ] 支部班子评议

### 4. 确定等次
- [ ] 综合评议意见
- [ ] 提出评定等次建议
- [ ] 支部委员会研究确定
- [ ] 向本人反馈评议结果

### 5. 表彰和处置
- [ ] 表彰优秀党员
- [ ] 帮助教育后进党员
- [ ] 处置不合格党员

## 四、主题党日

**目的**：开展党员活动，强化党员意识。

**频次**：每月固定1天

**流程**：

### 1. 活动策划（提前1周）
- [ ] 确定活动主题
- [ ] 设计活动方案
- [ ] 准备活动材料
- [ ] 通知党员参加

### 2. 活动实施
- [ ] 重温入党誓词
- [ ] 交纳党费
- [ ] 学习政治理论
- [ ] 开展特色活动
- [ ] 做好活动记录

### 3. 活动总结
- [ ] 收集活动照片
- [ ] 撰写活动总结
- [ ] 宣传活动成效
- [ ] 归档活动材料

## 五、谈心谈话

**目的**：了解党员思想动态，解决实际问题。

**要求**：
- 支部书记与支部委员每年谈心谈话不少于1次
- 支部委员与党员每年谈心谈话不少于1次
- 党员相互之间经常谈心谈话

**流程**：
1. **谈话准备**
   - [ ] 了解谈话对象基本情况
   - [ ] 确定谈话内容
   - [ ] 选择合适的时间地点

2. **谈话进行**
   - [ ] 创造轻松氛围
   - [ ] 坦诚交流思想
   - [ ] 指出存在问题
   - [ ] 提出改进建议

3. **谈话记录**
   - [ ] 做好谈话记录
   - [ ] 整理谈话要点
   - [ ] 跟踪落实情况

## 注意事项

1. 所有会议和活动必须做好记录，留存资料
2. 重要决议须经规定程序表决通过
3. 涉及党员个人的事项须本人回避
4. 会议记录要真实、完整、规范
5. 定期向上级党组织报告工作
