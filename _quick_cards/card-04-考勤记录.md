# ✅ 考勤记录规范 - 速查卡

> ⏱️ 阅读时间：2分钟

## 📊 考勤 vs 考察

### 考勤（0-1变量）
- **针对对象：** 支部党员（党员/预备党员）
- **适用活动：** 三会一课（支部委员会、支部党员大会、党小组会、党课）
- **记录内容：** 出勤/请假/缺勤
- **特点：** 来了就是来了，没来就是没来

### 考察（复杂变量）
- **针对对象：** 所有支部成员
- **适用活动：** 所有支部工作
- **记录内容：** 组织/深度参与/出勤
- **特点：** 记录具体贡献

## 📝 考勤流程（三会一课）

### 活动前
- [ ] 准备考勤表，列出应到人员名单
- [ ] 收集请假申请

### 活动中
- [ ] 组织签到
- [ ] 核对实到人数

### 活动后（5天内完成）
- [ ] 整理考勤表（标注出勤、请假、缺勤）
- [ ] 联系缺勤人员了解原因
- [ ] 安排补课
- [ ] 将考勤记录提交给宣传委员备案

## 📋 考勤表模板

```
【活动名称】考勤表
活动时间：YYYY年MM月DD日 HH:MM
活动地点：【地点】
活动类型：□支部委员会 □支部党员大会 □党小组会 □党课

序号 | 姓名 | 身份 | 出勤状态 | 备注
----|------|------|---------|------
1   |      |      | □出勤 □请假 □缺勤 | 
2   |      |      | □出勤 □请假 □缺勤 | 

应到：____ 人  实到：____ 人  请假：____ 人  缺勤：____ 人
```

## ⚠️ 请假规定

- **事假：** 提前1天申请
- **病假：** 可事后补假
- **缺勤：** 需及时联系说明原因

## 📌 补课制度

**补课形式：**
- 阅读会议材料、学习资料
- 观看会议录像（如有）
- 向参会同志了解内容
- 提交学习心得

**补课时限：**
- 一般1周内完成
- 特殊情况可延长至2周
