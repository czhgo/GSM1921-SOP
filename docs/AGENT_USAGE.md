# Org OS 智能体操作指南（系统管理员 Cheat Sheet）

## 一、部门分工

| 部门/角色 | 核心职责 | 常用 Skill |
|---|---|---|
| 中书省（规划） | 任务拆解、蓝图编排、执行顺序规划 | term-cleaner / yaml-slim / anchor-fixer / sop-sync 的计划编排 |
| 吏部（执行） | 文档术语、结构、锚点、SOP 同步落地 | term-cleaner / yaml-slim / anchor-fixer / sop-sync |
| 兵部（验证） | 数据与界面闭环验证，输出只读报告 | data-inspector / ui-verifier |
| 都察院（审计） | 全局扫描与风险分级，形成治理视图 | audit-report |
| 起居院（记录） | 月度日志建档、追加记录、标签强制 | log-recorder |
| 修史院（沉淀） | 从日志提炼经验并回写知识资产 | experience-distiller |

## 二、调用模板

- 规划：`@中书省 帮我梳理清理数字序号的计划`
- 执行：`@吏部 按计划执行术语清洗`
- 记录：`@起居院 确认记录日志`

## 三、治理闭环标准流程

1. 规划：中书省输出蓝图与执行顺序。
2. 执行：吏部按蓝图完成修改。
3. 验证：兵部只读核验数据与交互闭环。
4. 审计：都察院给出分级表与风险清单。
5. 记录：起居院按月自动建档并追加执行日志。
6. 沉淀：修史院提炼经验，确认后回写《经验沉淀》。

## 四、值班口令示例

- `@兵部 对本次 SOP 数据变更执行只读核验并出报告`
- `@都察院 扫描当前工作区并输出 S/A/B/C 重要性分级表`
- `@修史院 扫描 [经验蒸馏: 否] 日志并先给我提炼矩阵，待我确认后再回写`
