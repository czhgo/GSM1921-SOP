# 📋 组织党小组活动 - 速查卡

> ⏱️ 阅读时间：2分钟

## 第一步：判断活动类型

```
这是"三会一课"（支部大会/党小组会/党课）吗？
  ├─ 是 → 走组织生活会流程
  └─ 否 → 走党小组主题党日活动流程
```

---

## 🅰️ 组织生活会——关键步骤

| # | 你要做的事 | 联系谁 |
|---|-----------|--------|
| 1️⃣ | 提前2周定好议题，报书记/副书记确认 | 储子禾 / 王峥旭 |
| 2️⃣ | 提前1周通知到人，说清时间地点内容 | 组织委员发通知 |
| 3️⃣ | 会前安排好记录人、拍照人 | 宣传委员指导 |
| 4️⃣ | 现场做好签到、对照检查、自评互评 | 纪检委员做考勤 |
| 5️⃣ | 会后3天内完成会议记录归档 | 宣传委员存档 |
| 6️⃣ | 会后产出**摘要+配图**纳入月度推送 | 宣传委员把关 |

**⚠️ A类别忘了：**
- [ ] 用 `党支部工作记录.docx` 模板记录（三会一课必备）
- [ ] 签到表、对照检查材料、宣传摘要+配图要完整归档
- [ ] **不需要单独做活动复盘**

---

## 🅱️ 党小组主题党日活动——关键步骤

| # | 你要做的事 | 联系谁 |
|---|-----------|--------|
| 1️⃣ | 确定主题和时间（提前7天以上） | — |
| 2️⃣ | 向书记/副书记报备，**获得组长审批** | 储子禾 / 王峥旭 |
| 3️⃣ | 联系纪检委员（说明考勤方式）、组织委员（发通知）、宣传委员（宣传负责人） | 韩思宁 / 侯嘉嵘 / 闫鑫岳 |
| 4️⃣ | 提前3天在党小组群通知：**时间+地点+主题+需准备什么** | — |
| 5️⃣ | 明确深度参与者分工（谁负责宣传、记录等） | 纪检委员备案 |
| 6️⃣ | 外出活动：提前2天建群+确认人员到位 | — |
| 7️⃣ | 活动当天：签到 ✔ 拍照≥3张 ✔ 简要记录 ✔ 材料收齐 ✔ | — |
| 8️⃣ | 活动后**1周内**完成复盘（必须组织者本人写！） | 纪检委员监督 |
| 9️⃣ | 提交宣传材料（活动摘要+配图）纳入月度推送 | 宣传委员存档 |

**⚠️ B类别忘了：**
- [ ] 组长审批是前置条件，未审批不得启动
- [ ] 复盘用 `活动复盘模板.md`，**不能委托给宣传委员**
- [ ] 弹性考勤：组织者和深度参与者必须出席；一般参与者以鼓励为主
