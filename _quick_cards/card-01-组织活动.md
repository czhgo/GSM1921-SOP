# 📋 组织党小组活动 - 速查卡

> ⏱️ 阅读时间：2分钟

## 你需要做的 5 步

```
① 确定主题和时间 → ② 通知成员 → ③ 组织活动 → ④ 做好记录 → ⑤ 复盘总结
```

### Step 1️⃣ 确定主题和时间
- 与支部书记/副书记沟通活动主题
- 确定时间地点，避免与其他活动冲突

### Step 2️⃣ 通知成员
- 提前 **3天** 在党小组群通知
- 说清楚：**时间 + 地点 + 主题 + 需要准备什么**

### Step 3️⃣ 组织活动
- 做好签到（纪检委员韩思宁负责考勤模板）
- 按计划执行

### Step 4️⃣ 做好记录
- 如果是三会一课 → 用 `党支部工作记录.docx` 模板
- 如果是其他活动 → 拍照 + 简要记录

### Step 5️⃣ 复盘总结
- **组织者**（不是宣传委员！）在 **1周内** 完成活动复盘
- 用 `活动复盘模板.md`

## ⚠️ 别忘了

- [ ] 提前通知纪检委员做考勤
- [ ] 活动照片发给宣传委员
- [ ] 如需宣传，与宣传委员沟通谁来做
