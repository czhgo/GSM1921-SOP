## 📖 这个仓库是什么？

支部工作的标准操作程序（SOP）文档库 - 告诉你遇到各种情况该怎么做，提供各种现成模板。

**如果你是：**
- 🆕 **新任支委** → 看 [START_HERE.md](./START_HERE.md)
- 📋 **需要快速查某个东西** → 看 [CHEATSHEET.md](./CHEATSHEET.md)
- 👨‍💼 **老手只是来找文件** → 直接去对应文件夹

## 🗂️ 文件夹用途（一句话版）

| 文件夹 | 一句话说明 |
|--------|-----------|
| **流程指南/** | 教你怎么做事（流程、职责、场景指南） |
| **_quick_cards/** | WPS友好的2分钟速查卡（可复制到微信/WPS） |
| **申报材料模板/** | 现成模板直接用（三会一课记录、活动总结等） |
| **活动复盘/** | 记录经验教训，避免重复犯错 |
| **官方文件/** | 党和国家的正式文件（查合规性） |
| **党小组会/** | 党小组制度和11月大会精神 |
| **支部委员会/** | 支委工作手册 |
