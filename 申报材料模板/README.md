## 📖 详细说明

### 1. 工作记录类 📝

**用途：** 上报给上级组织备案审查的正式记录

**特点：**
- 格式固定，必须按模板填写
- 用于三会一课、主题党日等正式活动
- 填完后需上报

**包含模板：**
- 党支部工作记录.docx - 三会一课统一记录模板

### 2. 宣传材料类 📢

**用途：** 对外发布的宣传内容

**特点：**
- 需要审核，确保内容准确无风险
- 用于公众号、海报等宣传渠道
- 表述要清晰、准确

**包含模板：** （待补充）
- 宣传推文模板
- 海报设计规范

### 3. 其他模板 📄

**用途：** 日常工作中常用的各类模板

**特点：**
- 可以根据实际情况调整
- 提高工作效率
- 保证材料质量

**包含模板：**
- 支部基本信息模板 - 支部介绍、组织架构等可复用内容
- 活动总结模板 - 标准化的活动总结格式
