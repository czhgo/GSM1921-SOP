1.2 权限体系

系统权限不是"给你一个账号就什么都能做"，而是赋权关系链——谁给你赋的权，你就在谁的赋权范围里干活。三个视图模式，界定"能看什么"：

模式谁使用能看到什么能修改什么
管理模式角色对应的管理者自己角色的工作台自己角色的数据
管理者只读赋权者查看被赋权者被赋权者的工作台无
成员只读未选择角色的参与者统一信息流面板无

写入范围界定"能改什么"：

写入范围授权人享有角色
职能写入天然权限组织委员 / 宣传委员 / 纪检委员（各自板块）
活动写入天然权限党支书 / 党小组组长
活动写入（需赋权）党小组组长组织者 / 深度参与者
专班发起天然权限党支书 / 党小组组长 / 三委员
专班招募统筹天然权限组织委员（唯一节点）

关键约束：

  • 创建活动仅限党支书和党小组组长；党小组组长可独立创建，须报书记知情同意；组织委员协调的是专班（招募统筹），不是活动
  • 纪检委员考勤数据与组织委员通用同源
  • 宣传委员不可自行招募宣传专班，赋权操作统一归口组织委员
  • 三委员之间可相互查看（只读），但不可修改彼此的工作
  • 从首页进入管理页面时自动设为只读模式

二这个系统在干什么

这个系统是北京大学光华管理学院本科生党支部的数字化管理工具。它要解决的核心问题是：党支部工作如何从"人治"走向"制度治理"？支委换届频繁，经验随人走、制度随人变；新支委上任后需要数月摸索才能上手；同一种工作在不同人手里做法完全不同——本系统通过制度即代码、角色即视图、经验可传承三大设计理念，将党支部制度文本转化为可执行的代码工作流。

系统现有 14 个页面：首页、资料查询、意见反馈、归档库等公共页面，以及六类角色各自的工作台（党支书、党小组组长、组织委员、宣传委员、纪检委员、普通成员）。每个角色打开自己的工作台，就是该角色的全部工作视图——各项功能按 Tab 分组，无需在页面之间来回跳转；所有角色共享同一套数据，看到的是同一数据的不同视角。

三分工中的制度设计

3.1 角色总览

系统中的 8 种角色，按管理层级排列。支委是纵线（职能线），党小组组长是横线（小组线）——条块双线管理。其中六类角色有专属工作台（党支书、党小组组长、组织委员、宣传委员、纪检委员、普通成员）；组织者与深度参与者是扁平化执行角色，由党小组组长或组织委员在具体工作中赋权产生。

3.2 支委会

党支书 全局统筹

管理所有工作，是唯一的最终决策者。创建活动须经书记知情同意，专班发起和赋权均需书记授权或默认。

各委员的职责集中在各自的角色工作台页面呈现：

3.3 党小组组长

党小组组长 横线 · 小组线

按就业/学术方向划分，横向统筹党小组活动。负责组织学习、开展活动，是活动的天然写入者。党小组组长可以独立创建活动，但须报书记知情同意。党小组组长有权向组织者和深度参与者赋权。

3.4 专班参与者

组织者 牵头策划 深度参与者 推进执行

组织者和深度参与者是推动支部工作扁平化的两种角色。两者之间没有上下级关系，只是分工不同。核心比喻：组织者是项目的脑子，深度参与者是项目的手。

注意：组织者和深度参与者同时服务活动和专班——两者是党建工作下的并列工作内容，归不同人管理。在活动中，由党小组组长赋权；在专班中，由组织委员赋权。

3.5 普通成员

普通成员 参与 + 监督

普通成员以只读模式查看活动动态、专班进展和考勤概况。成员不参与管理工作，但拥有知情权和监督权。

四为什么这样设计

4.1 为什么分纵线和横线？

支委是纵线（职能线），管的是某一类专业事务——组织委员管发展、宣传委员管档案、纪检委员管考勤。党小组组长是横线（小组线），管的是一组人——按就业/学术方向划分的党小组。这两条线不是上下级关系，而是条块双线管理：条管功能决策，块管信息触达——纵线决定"做什么、怎么做"（功能决策），横线负责"传到谁、怎么传达"（信息触达），两条线交汇于具体工作。书记是条块之间的协调节点，确保功能决策和信息执行不脱节。这样的好处是：专业的事有人把关（委员），人的事有人管（党小组组长），不会出现"谁都管又谁都不管"的真空地带。

4.2 活动和专班为什么是并列的？

活动和专班虽然都属于党建工作，但归不同人管理、走不同的赋权流程——它们不是"活动包含专班"或"专班属于活动"的从属关系，而是两条独立的线。

维度活动专班
管辖党小组组长组织委员
赋权范围activitytaskforce
时间固定时间地点无严格限制
组织者来源党小组组长赋权组织委员招募

4.3 权限从哪来？

这个系统里的权限不是"给你一个账号就什么都能做"，而是赋权关系链——谁给你赋的权，你就在谁的赋权范围里干活。党支书天然拥有所有权限；支委和党小组组长的管理权限也是天然的；但组织者和深度参与者的写入权限，必须由党小组组长（活动）或组织委员（专班）显式赋权。赋权者可以查看被赋权者的工作视图（只读），但不可修改。宣传委员和纪检委员没有赋权能力——这是内控要求，与职能性质相关。

4.4 专班是什么？

专班是活动之外考察积极分子的载体——赋权是专班运行的支撑机制，工作量记录是专班运行的保障机制。组织委员是唯一专班管理节点——所有专班的组建与解散必须经由组织委员统一管理，防止专班泛滥。专班有明确的解散条件：任务完成或截止时间到达即解散，不得转为常设机构。

专班里的组织者和深度参与者之间没有上下级关系——组织者负责分工协调、进度同步、打包提交工作成果，深度参与者负责执行具体工作、提交交付物。核心比喻：组织者是项目的脑子，深度参与者是项目的手。身份不是最重要的，年级和政治面貌不决定是否胜任。

4.5 战略认知是什么？

"管理事，服务人"不是一句口号，背后有一套战略认知：服务人的核心要义，是理解真实的组织和管理——不是想象中的等级森严，而是有管理的科学、有既往的经验。从这个认知出发，展开四个维度：

  • 理解真实——真实的组织靠流程和经验，不是谁坐在哪个位置上。成长在办事中体悟，不在抽象培训中。
  • 善用经验——有先例的工作，先从既有工作流开始，理解流程为什么这样设计，再考虑要不要改。
  • 创新沉淀——创新性的工作没有权威，每个人的意见和实践选择都很重要，组织要充分吸收个体经验，沉淀为新的工作流。
  • 框架内对话——不要怕"说错话"，特别怕大家因为认为是"党支部"而自我审查。框架内表达不是不许批评，而是批评要找准对象、找准时机。
延伸·恢复对话能力：党建和经管学科科研的交叉点在于恢复和马克思主义的对话能力，恢复理论研究和现实治理之间的对话能力。

层位置职责
