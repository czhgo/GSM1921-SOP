# content/references/

本目录存放官方合规文件、历史会议材料与可复用工作模板。

> ⚠️ `合规文件/` 下所有文件均为**只读参考资料**，以官方原文为准，禁止修改。

## 目录结构

| 子目录/文件 | 内容 | type | 只读 |
|-------------|------|------|------|
| `合规文件/` | 党章、党支部工作规范、党员教育管理条例等官方文件 | reference | 是 |
| `历史会议材料/` | 历次党小组会议记录、支委工作手册等存档材料 | reference | 是 |
| `党支部工作记录.docx` | 宣传委员合规审查核心文件——迎接档案审查 | record | 否 |
| `工作模板/` | 可复用工作模板 | template | 否 |
| `工作模板/FEEDBACK_FORM.md` | SOP优化提案反馈卡——支委提交规则修改的唯一接口 | template | 否 |
| `工作模板/经验沉淀辅助提示词.md` | AI辅助经验提炼提示词——深度参与者从工作材料中沉淀经验 | template | 否 |
