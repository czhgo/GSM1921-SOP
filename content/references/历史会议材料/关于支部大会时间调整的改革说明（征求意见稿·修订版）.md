# 关于支部大会时间调整的改革说明（征求意见稿）

各位党员同志、预备党员同志：

为进一步优化支部组织生活安排，回应同志们对会议时间设置的合理关切，推动支部大会职能转型升级，现就支部大会时间调整方案作出如下说明，并面向全体党员征求意见。

---

## 一、现状与成因说明

当前支部大会时间为**每月最后一个完整周的周日晚间**。这一安排的形成有其历史背景和实际考量，现向同志们作统一说明：

1. **民主投票结果**  
   现行时间是支部成立初期经全体党员投票选定的。当时多数同志反映，周中晚间存在各类课程安排，若占用上课时间召开会议，既不符合学生党员“学业为本”的原则，也易导致参会率不足。

2. **避免学业冲突**  
   支部始终坚持“不鼓励、不赞成因支部活动影响正常教学秩序”的原则。周中会议将不可避免地与课程、考试等教学安排冲突，因此周日晚间成为相对稳妥的“最大公约数”。

3. **月末信息同步需要**  
   支部大会传统上承担着**总结本月支部建设成果、执行党务职能、布置下月工作要点**的任务。  
   *（注：此处“党务职能”特指涉及投票表决的事项，包括发展预备党员、预备党员转正、换届选举。）*  
   选择最后一个完整周，能确保本月主要活动基本完结，信息完整度较高。

上述安排在执行初期有效保障了会议的出勤率和信息完整性，但随时间推移，其局限性逐渐显现。

---

## 二、当前主要矛盾与改革动因

近期部分同志通过正式或非正式渠道反映了如下具体困难：

- **私人时间挤占**：周日晚间属于私人休整时段，频繁占用易引发疲劳和抵触情绪。
- **法定假期与考试冲突**：月末常逢法定节假日调休（如国庆、劳动节），同志们已提前规划行程；同时，部分月份月末与期中、期末备考周期重叠，学习压力较大。
- **领导参会不便**：上级指导领导周日晚上通常难以安排时间出席，影响指导深度与会议规格。

与此同时，支部大会的**职能重心正在发生结构性变化**：

- **过去**：重“信息同步”，会程中大量时间用于罗列本月已完成事项。
- **现在与未来**：更突出**党务核心职能**（发展、转正、换届等投票程序），辅以必要的工作部署。

职能转变要求会议安排更加**精准、高效、人性化**，且能兼顾多方参与需求。

---

## 三、改革原则与调整规则

### 1. 核心原则：默认不动，例外才调

改革遵循 **“最小修改原则”** ，不推翻既有习惯，只在必要时触发调整：

- **默认时间**：每月**最后一个完整周周日晚上**。
- **触发调整的条件**（满足其一即可移动至前一周或另行协商）：
    1. 当月月末与法定节假日、学校考试周重叠——**移动至前一周周日晚**；
    2. 涉及必须由领导出席的重要会议（换届、上级精神传达、重大部署）。**协商的优先级以领导时间为准**。

若当月无上述例外情形，会议时间**维持默认不变**，无需任何额外协调动作。

### 2. 时间收集：一学期一次，只报“不行”的时间

为最大限度降低协调负担，时间冲突信息采用 **“排除法”收集**：

| 项目           | 安排                                                         |
| :------------- | :----------------------------------------------------------- |
| **收集频率**   | **每学期初一次**（与选课结果同步）。                         |
| **收集内容**   | 仅需填报**确定无法参会的固定时段**（如周中课程、固定实习日）。 |
| **收集方式**   | 小程序，勾选“不可用时段”。                                   |
| **未填报处理** | 视为**无固定冲突**，后续协调以默认时间为准。                 |
| **底线方案**   | 若出现极端情况，启用**21:30后**时段作为保底选项（此时段全员无课）。 |

### 3. 会议分类：只需区分“必须领导出席”一种例外

| 情形                                                       | 时间确定方式                                                 |
| :--------------------------------------------------------- | :----------------------------------------------------------- |
| **必须领导出席的会议**（换届、上级重要精神传达、重大部署） | **以领导可行时间为准**。支委提前协调，确认后第一时间通知。如遇领导临时变动，支委即时同步并调整。 |
| **其余所有会议**（含发展、转正、常规总结）                 | 按默认规则执行；若触发法定假期/考试例外，顺延至前一周周日。  |

### 4. 月度操作流程（极简版）

| 时间           | 谁做     | 做什么                                                       |
| :------------- | :------- | :----------------------------------------------------------- |
| **学期初**     | 全体党员 | 填报一次“不可用时段”。                                       |
| **每月15日前** | 支委     | **仅当涉及“必须领导出席”或法定假期/考试冲突时**，发布调整通知。 |
| **无通知时**   | 全体     | 按默认时间（最后一个完整周周日晚上）预留日程。               |

### 5. 参会与列席

| 对象                   | 要求                                           |
| :--------------------- | :--------------------------------------------- |
| **正式党员、预备党员** | 出勤率须达100%。因故无法参会须提前按规则请假。 |
| **发展对象、积极分子** | 鼓励列席，会议时间将尽量避让考试等学业活动。   |

## 附录：时间协调工作标准操作程序（SOP）

### 支委会责任

| 事项                         | 时限/要求           |
| :--------------------------- | :------------------ |
| 学期初发布“不可用时段”收集表 | 选课结果确定后3日内 |
| 每月研判是否触发调整例外     | 每月10日前          |
| 涉及领导出席时确认领导时间   | 每月20日前          |

### 党员/预备党员责任

| 事项                       | 要求                                         |
| :------------------------- | :------------------------------------------- |
| 学期初填报“不可用时段”     | 如实填写，逾期视为无冲突                     |
| 每月15日后查看有无调整通知 | 无通知即按默认时间预留                       |
| 时间调整协商               | 及时响应，协商通知发布**24小时内**填写小程序 |
| 无法参会时请假             | 按照制度提交请假                             |
