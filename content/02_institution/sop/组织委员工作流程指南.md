# 组织委员工作流程指南

> 考勤与考察档案同源、思想汇报由党员系统内提交自动归档的规则，与纪检委员指南一致（2026-08-30 数字化决策）；公共规则见 [常见工作场景快速指南.md](./常见工作场景快速指南.md) 公共规则表。

> **一句话：** 统筹专班招募与发展党员全程管理。

**术语**（支部党员/支部成员/条条/块块）：见 [INDEX.md](./INDEX.md#术语)

## 适用角色

**组织委员**

- **专班招募**：唯一统筹者（提出需求与招募统筹分离——书记/党小组组长/支委均可提出需求，经支委会审议立项后，只有组织委员能统一招募）
- **发展党员**：全流程管理（考察档案 + 思想汇报 + 发展协助）
- **数据共享**：考察档案与纪检委员的考勤数据通用同源

### 为什么这么做

- **两个动作**：发起是"提出需求"——书记、党小组组长、支委都可以提，立项由支委会审议（线上或线下）；招募是"赋权+记账"——只有组织委员能做
- **如果不分离**：发起者自己招募（如宣传委员自己招募宣传专班），赋权记录散落在各委员手里，工作量记账和解散评议没有统一流程
- **统一招募的价值**：所有专班走同一套赋权→记账→解散流程

## 工作台 — 专班协调视图（最高优先级）

> 在系统中，组织委员进入工作台后看到的是 **专班协调看板**。

> **设计考量**：专班不限时间、不限地点，涉及跨角色、不可拆分的任务需要集中跟踪协调——专班协调看板设为最高优先级，确保专班任务不被常规事务淹没。
> **协调观（书记 2026-08-30 确认）**：书记把「协调」看作**最小三成本原则的具体实现**——协调看板降低成员寻找专班信息的信息成本、操作成本与适应学习成本，是「管理事、服务人」在专班场景的落地。专班协调看板最高优先级由此获得原则级依据。
> 母本引用：[FLAT_ORGANIZATION_DESIGN.md](../FLAT_ORGANIZATION_DESIGN.md) §三 专班启动的适用条件 + [COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.4 专班核心定义

### 任务流

| 步骤 | 动作 | 时机 |
|------|------|------|
| 1 | 审查待启动列中的新专班需求（放行/打回判定见下节） | 每周至少检查一次 |
| 2 | 点击「发布招募」→ 填写招募表单（专班名称/任务描述/人数/截止日期/技能/周期/关联活动/初始成员/说明） | 确定需求后 |
| 3 | 招募确认后，将专班成员名单同步给纪检委员（纪检委员据此进行专班考察确认；名单统一由组织委员同步，见[纪检委员工作流程指南 §2.2](./纪检委员工作流程指南.md)） | 名单确定后 |
| 4 | 监控进行中列的子任务进展 | 持续跟踪 |
| 5 | 专班全部子任务完成 → 归档 | 完成后 |

### 专班需求审查——放行/打回判定依据

组织委员是唯一专班管理节点（CF §A.6），对进入「待启动」列的新专班需求作放行（发布招募）或打回（退回发起人补充/重新提交）判定：

**放行（发布招募）须同时满足**：
- 已立项：需求已通过支委会审议立项（线上或线下）——赋权范围限于已通过审批的专班，组织委员不得在未获批专班中赋权
- 要素齐全：名称、人数、周期、考核标准等需求要素完整（CF §A.7），可填齐招募表单 9 字段
- 必要性成立：专班不限时间、不限地点、跨职能又跨小组、目标导向，是活动之外考察积极分子的载体（CF §A.3/A.4）；满足「跨角色、不可拆分」两项适用条件（[FLAT_ORGANIZATION_DESIGN.md §三](../FLAT_ORGANIZATION_DESIGN.md)）
- 负责人就位：专班组织者（专班负责人）人选明确，由组织委员赋权后承接分工记录职责与专班考察上传（专班考察由专班负责人/组织委员上传，见[纪检委员工作流程指南 §2.2](./纪检委员工作流程指南.md)）

**打回（退回发起人补充或重新提交）**：
- 未经支委会审议立项，或立项被驳回（驳回则调整方案重新提交）
- 需求要素缺失（未写明人数/周期/考核标准等）
- 拟参与人数与招募范围不清晰——专班成员来自任意党小组、不改变其党小组归属，同一同志可同时加入多个专班、工作量分别记账（CF §A.6），招募前须明确范围

> 处理时限：按验收标准，待启动列需求不超过 7 天未处理；组织委员每周至少检查一次（任务流步骤 1）。
> 母本引用：[COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.3/A.4/A.6/A.7 + §审批流程规范 二、三.1 + [FLAT_ORGANIZATION_DESIGN.md](../FLAT_ORGANIZATION_DESIGN.md) §三 + [SECRETARY_DIRECTIVES.md](../../01_strategy/SECRETARY_DIRECTIVES.md) P-013

### 验收成果

- [ ] 待启动列无超过 7 天未处理的专班需求
- [ ] 每个进行中专班有明确的招募计划
- [ ] 全部完成专班已在归档库中可查
- [ ] 招募确认的专班名单已同步纪检委员

> **✅ 系统已实现**：「发布招募」按钮点击后弹出招募表单（含专班名称/任务描述/人数/截止日期/技能/周期/关联活动/初始成员/说明 9 字段），支持招募状态跟踪（recruiting → active → archived）。

## 发展党员全流程业务

### 一、考察档案维护

**信息流**：
```
发展对象名单（支委会确定）
    │
    ▼
组织委员建立/维护考察档案
    │
    ▼
发展对象个人档案（含思想汇报 → 转正材料）
```

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 获取发展对象名单 | 支委会会议纪要 |
| 2 | 建立考察档案 → 存入 `content/03_doc_system/工作模板/` | 档案目录完整 |
| 3 | 每季度更新考察意见 | 有书记签字的考察表 |
| 4 | 转正前汇总全周期档案 | 完整档案包移交支委会 |

> **数据同源提醒**：考察档案中的「活动出勤」数据，直接使用纪检委员维护的考勤系统数据，不与考勤表重复录入。「思想汇报」由党员在系统内提交，算法自动归档归集，组织委员查看调用。

> **考察档案记录结构**（系统已实现）：每条考察记录包含以下信息——来源类型（活动/专班）、关联活动名称、参与类型（组织者/深度参与者/普通参与者）、具体角色描述、记录人、记录时间。

> **设计考量**：考勤同源而思想汇报不同源——考勤由纪检委员在活动现场记录（唯一写入方），组织委员直接读取避免数据冲突；思想汇报由党员在系统内直接提交、算法自动归档（纪检委员不介入），组织委员查看调用。两者写入方不同，数据流也不同。
> 母本引用：[SYSTEM_ROLE_PERMISSION.md](../SYSTEM_ROLE_PERMISSION.md)（系统角色权限矩阵）

### 二、思想汇报归档（算法归档）

**信息流**：
```
党员/发展对象在系统提交思想汇报（文本直接提交）
    │
    ▼
系统自动归档至对应个人档案（算法归集，无需人工归档环节）
    │
    ▼
组织委员查看/调用（考察时直接调用思想汇报记录）
```

> **流向说明**：思想汇报由党员/发展对象在系统内直接提交，提交即入库即归档——算法自动归集到对应个人档案（2026-08-30 书记强调的算法归档原则），组织委员只做查看与调用，不再有「收齐→归档」的人工环节。纪检委员不介入思想汇报流程，仅负责考勤考察。

### 为什么这么做

- **职能归口**：组织委员管发展党员全流程，考察档案和思想汇报都是发展党员的核心材料，归口同一人确保材料衔接不断裂
- **权责分离**：纪检委员因权责分离要求不组建专班（审查权限不可转授），同理不介入思想汇报——纪律审查与思想表达分属不同职能

母本引用：[支委与党小组定人定责定岗说明.md](./支委与党小组定人定责定岗说明.md) §2.1 条条支委职责 + [COMMISSIONER_DUTY_FRAMEWORK.md](../COMMISSIONER_DUTY_FRAMEWORK.md) §A.6 条块衔接规则

**任务流**：

| 步骤 | 动作 | 验收 |
|------|------|------|
| 1 | 掌握各党小组应提交思想汇报的人数（季度） | 数量为应提交人数 |
| 2 | 查看系统自动归集的思想汇报（系统已归档至个人档案） | 每份有日期标记 |
| 3 | 考察时调用思想汇报记录 | 记录完整可调用 |

### 三、发展党员协助

**信息流**：
```
支委会确定发展计划
    │
    ▼
组织委员启动材料准备
    │
    ▼
公示 → 支部大会 → 上级审批
```

**关键动作**（按发展节点）：

| 节点 | 必须交付 |
|------|----------|
| 确定发展对象 | 发展对象登记表 + 考察档案初稿 |
| 接收预备党员 | 入党志愿书 + 公示材料 + 支部大会记录 |
| 预备党员转正 | 转正申请书 + 全年考察档案 + 支部大会决议 |

> 完整材料清单见附录 A「发展党员时间轴与材料清单」。

## 附录 A：发展党员时间轴与材料清单

> 从入党申请人到正式党员的完整路径，每一步需交付的材料由系统自动提示。

### 发展阶段与交付物

| 阶段 | 关键动作 | 必须交付 | 系统提示 |
|------|---------|---------|---------|
| 入党申请人 | 提交入党申请 | 入党申请书 | — |
| 积极分子 | 支委会确定 + 培养考察期一年以上 | 积极分子登记表 + 培养联系人考察记录 | 培养考察期满提醒 |
| 发展对象 | 支委会讨论确定 | 发展对象登记表 + 考察档案初稿 + 政审材料 | 确定后自动建档 |
| 预备党员 | 接收大会 + 公示 + 上级审批 | 入党志愿书 + 公示材料 + 支部大会记录 | 公示期提醒 |
| 预备期 | 一年预备期考察 | 季度考察意见 + 思想汇报 | 季度考察提醒 |
| 正式党员 | 转正申请 + 支部大会 + 上级审批 | 转正申请书 + 全年考察档案 + 支部大会决议 | 预备期满提醒 |

### 各阶段材料清单

**积极分子阶段**：
- 积极分子登记表（姓名/班级/申请日期/培养联系人）
- 培养联系人考察记录（每季度一次，含考察意见和培养建议）
- 思想汇报（每季度至少一篇）

**发展对象阶段**：
- 发展对象登记表（含支委会确定日期）
- 考察档案初稿（含培养考察期全程记录）
- 政审材料（本人及直系亲属政治审查）
- 群众意见征求记录

**预备党员阶段**：
- 入党志愿书（本人填写）
- 公示材料（公示期不少于 7 天）
- 支部大会记录（含表决结果）
- 上级党组织审批意见

**转正阶段**：
- 转正申请书（预备期满前提交）
- 全年考察档案（含季度考察意见）
- 支部大会决议（含无记名投票结果）
- 上级党组织审批意见
