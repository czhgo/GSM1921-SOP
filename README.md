# 🏛️ 光华管理学院本科生党支部组织操作系统

这是一个基于文档驱动的党支部组织操作系统 (Doc-Driven Org OS)。

> 🌐 **公网访问：[https://czhgo.github.io/GSM1921-SOP/](https://czhgo.github.io/GSM1921-SOP/)**

---

## 📌 项目概述

本系统将支部的**制度、流程、模板、任务分工**统一管理，书记与委员通过查阅文档、填写反馈卡与调用 AI 代理，即可完成日常全部工作——无需手动维护多份独立文件。

**三句话总结系统价值：**
1. **制度驱动**：所有工作流均来自 `knowledge/SOP/`，改一处制度，全系统同步。
2. **人机协作**：书记提需求，AI 代理几分钟内完成修改、有日志可查。
3. **零门槛上手**：委员只需看流程卡，不需要理解代码或技术架构。

## 🚀 日常操作指南

### 如何启动系统（查看交互视图）

直接在浏览器打开 → **[https://czhgo.github.io/GSM1921-SOP/](https://czhgo.github.io/GSM1921-SOP/)**

或在本地双击 `index.html`（无需服务器，无需安装任何工具）。

### 如何修改制度 / 新增工作流

1. 找到 `knowledge/SOP/` 下对应的制度文件（见 [SOP 索引](./knowledge/SOP/INDEX.md)）
2. 联系书记（储子禾），描述你要改什么
3. 书记通过 AI 代理（见下方 AI 系统入口）完成修改
4. 修改后，AI 自动同步 `src/domain.js` 与相关文档，不留死角

### 如何分配 / 追踪任务

打开 [SOP 引擎（index.html）](./index.html) → 选择角色或领域 → 查看对应的活动节点与负责人。

### 如何提交流程反馈

发现流程不准、模板难用或有更好的做法？填写：
**[SOP 优化提案反馈卡](./docs/SOP优化提案反馈卡.md)**（书记看到后，AI 几分钟内全局修复）
