# 流程指南文档目录

本目录包含支部工作的核心流程指南文档，帮助支委和党小组成员快速了解工作流程和操作规范。

## 📚 文档导航

### 🌟 推荐首次阅读顺序

1. **[常见工作场景快速指南.md](./常见工作场景快速指南.md)** ⭐ 
   - **适合：** 首次使用者、需要快速查询的同志
   - **内容：** 10个常见工作场景的快速操作指南
   - **特点：** 按场景组织，一站式查询，最实用

2. **[支委与党小组定人定责定岗说明.md](./支委与党小组定人定责定岗说明.md)**
   - **适合：** 新任支委、党小组组长
   - **内容：** 详细的人员身份、职责划分和岗位说明
   - **特点：** 系统全面，7个章节完整体系

3. **[工作流程图-定人定责定岗.md](./工作流程图-定人定责定岗.md)**
   - **适合：** 需要了解具体流程的同志
   - **内容：** 10个可视化Mermaid流程图
   - **特点：** 图文并茂，直观易懂

4. **[宣传委员工作流程指南.md](./宣传委员工作流程指南.md)**
   - **适合：** 宣传委员及宣传工作相关人员
   - **内容：** 宣传委员专项工作流程（支部大会、党小组会、申报材料）
   - **特点：** 专项详细，操作性强
