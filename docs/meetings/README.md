# 会议记录

本目录用于存放支部各类会议的实际记录。

## 目录结构建议

```
meetings/
├── 党员大会/
│   ├── 2026/
│   │   ├── 2026-Q1-党员大会记录.md
│   │   ├── 2026-Q2-党员大会记录.md
│   │   └── ...
├── 支委会/
│   ├── 2026/
│   │   ├── 2026-01-支委会记录.md
│   │   ├── 2026-02-支委会记录.md
│   │   └── ...
├── 党小组会/
│   ├── 第一党小组/
│   └── 第二党小组/
└── 党课/
    ├── 2026/
    │   ├── 2026-Q1-党课记录.md
    │   └── ...
```

## 使用说明

1. 按照时间和会议类型分类存放
2. 文件命名格式：`YYYY-MM-会议名称.md` 或 `YYYY-QX-会议名称.md`
3. 使用相应的模板进行记录
4. 及时整理归档

## 注意事项

- 会议记录应及时整理
- 保持记录的完整性和准确性
- 妥善保管涉密内容
- 定期备份重要记录
