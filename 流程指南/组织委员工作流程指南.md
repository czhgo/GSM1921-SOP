# 组织委员工作流程指南

## 文档说明

本文档详细说明组织委员（侯嘉嵘）的工作流程、职责范围和操作规范，是组织委员开展日常工作的核心参考文件。

**核心定位：** 组织委员作为块块委员，横跨三个党小组，负责党员发展全流程管理、支部信息平台建设、考察档案管理、思想汇报统计归档、意见反馈平台管理。

**特别说明：** 根据2026年2月工作优化调整，组织委员新增**考察档案管理**和**意见反馈平台管理**职责，使党员发展相关工作更加集中、系统化。

**术语说明：**
- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- 不使用"普通党员"等具有层级性的表述

## 二、党员发展流程管理

### 2.1 发展流程概览

```
申请入党 → 确定积极分子 → 培养教育(1年) → 确定发展对象 → 
政治审查 → 发展为预备党员 → 预备期考察(1年) → 转为正式党员
```

| 阶段 | 身份 | 时长 | 组织委员主要工作 |
|------|------|------|-----------------|
| 1 | 入党申请人 | - | 收集入党申请书 |
| 2 | 积极分子 | 1年以上 | 建立档案、收集思想汇报、培养教育 |
| 3 | 发展对象 | 1年后 | 审核材料、组织政审、考察意见 |
| 4 | 预备党员 | 1年 | 继续考察、收集思想汇报、组织转正 |
| 5 | 正式党员 | - | 建立正式档案 |

### 2.2 积极分子培养

#### 确定积极分子

**条件：**
- 递交入党申请书满6个月
- 经团组织推优（团员）
- 党小组推荐
- 支委会审查同意

**组织委员工作：**
1. 收集入党申请书，建立基本档案
2. 协助支部书记确定培养联系人
3. 建立积极分子考察档案
4. 制定培养计划

#### 培养教育（1年以上）

**主要工作：**

| 工作内容 | 频率 | 具体操作 |
|---------|------|---------|
| 收集思想汇报 | 每季度1篇 | 检查质量、归档管理 |
| 记录考察情况 | 持续 | 接收纪检委员参与记录，建立档案 |
| 组织培训教育 | 不定期 | 党课学习、理论培训 |
| 定期考察谈话 | 每半年 | 培养人谈话，形成书面意见 |

### 2.3 发展对象确定

**条件：**
- 积极分子培养满1年
- 完成党校学习
- 考察记录良好

**组织委员工作流程：**

| 步骤 | 工作内容 | 时间 |
|------|----------|------|
| ① 材料审核 | 检查档案完整性：申请书、思想汇报、考察记录 | 确定前1个月 |
| ② 征求意见 | 征求党内外群众意见 | 确定前2周 |
| ③ 出具意见 | 根据考察档案出具考察意见 | 确定前1周 |
| ④ 支委会审查 | 准备材料提交支委会 | 支委会前3天 |
| ⑤ 公示告知 | 支委会通过后公示 | 支委会后3天 |

### 2.4 预备党员发展

**组织委员工作流程：**

| 步骤 | 工作内容 | 时间 |
|------|----------|------|
| ① 政治审查 | 组织政审，形成政审材料 | 发展前2个月 |
| ② 集中培训 | 组织参加上级党校培训 | 发展前1个月 |
| ③ 材料准备 | 准备全套发展材料 | 发展前2周 |
| ④ 支部大会 | 协助召开支部大会表决 | 按上级要求 |
| ⑤ 上报审批 | 整理材料报上级党委 | 大会后1周 |

**必备材料清单：**
- [ ] 入党申请书
- [ ] 思想汇报（至少4篇）
- [ ] 自传
- [ ] 政审材料
- [ ] 考察档案和意见
- [ ] 党校结业证书
- [ ] 群众意见
- [ ] 支部大会决议

### 2.5 预备党员转正

**预备期考察（1年）：**

| 工作内容 | 频率 | 具体操作 |
|---------|------|---------|
| 收集思想汇报 | 每季度1篇 | 检查质量、归档 |
| 考察记录 | 持续 | 接收参与记录，特别关注【组织】或【深度参与】 |
| 转正谈话 | 转正前 | 培养人谈话，形成意见 |

**转正流程：**

| 步骤 | 工作内容 | 时间 |
|------|----------|------|
| ① 材料审核 | 检查预备期表现材料 | 转正前1个月 |
| ② 出具意见 | 根据考察档案出具考察意见 | 转正前2周 |
| ③ 支委会审查 | 准备材料提交支委会 | 转正前1周 |
| ④ 支部大会 | 协助召开支部大会表决 | 按期转正 |
| ⑤ 上报审批 | 整理材料报上级党委 | 大会后1周 |

**重要说明：** 根据11月支部大会精神，预备党员必须【组织】或【深度参与】支部活动，这是转正的重要考察内容。

## 三、考察档案管理

### 3.1 档案管理目的

**为什么由组织委员管理考察档案？**
- ✅ 考察档案直接服务于党员发展工作
- ✅ 方便在审查发展对象时直接查询
- ✅ 统一管理党员发展相关资料
- ✅ 组织委员可以全面掌握培养对象情况

**与纪检委员的分工：**
- **纪检委员**：记录活动参与情况（组织/深度参与/出勤）
- **组织委员**：接收记录、建档管理、出具考察意见

### 3.2 档案建设流程

```
纪检委员记录 → 定期提交组织委员 → 组织委员建档 → 申请时查询 → 出具意见
```

| 步骤 | 责任人 | 工作内容 | 时间 |
|------|--------|---------|------|
| ① 活动参与记录 | 纪检委员 | 记录成员在活动中的参与情况 | 活动后5天 |
| ② 提交记录 | 纪检委员 | 将参与记录提交给组织委员 | 每月月底 |
| ③ 档案录入 | 组织委员 | 录入考察档案系统，分类归档 | 收到后3天 |
| ④ 档案维护 | 组织委员 | 定期更新，确保完整准确 | 持续 |
| ⑤ 倒查验证 | 组织委员 | 申请时根据自述倒查档案 | 申请时 |
| ⑥ 出具意见 | 组织委员 | 根据档案出具考察意见 | 审查时 |

### 3.3 三层参与记录

| 参与层次 | 定义 | 记录来源 | 考察价值 |
|---------|------|---------|---------|
| **【组织】** | 活动策划组织者 | 纪检委员记录 | 最高，满足党员责任要求 |
| **【深度参与】** | 承担具体工作（宣传/统筹等） | 纪检委员记录 | 中等，考察执行力 |
| **【出勤】** | 参加但无具体工作 | 纪检委员记录 | 基础参与 |

**记录原则：**
- 由纪检委员在活动中观察记录
- 与活动组织者确认
- 每月汇总提交给组织委员
- 组织委员负责建档，不改动记录内容

### 3.4 倒查法应用

**倒查场景：**

| 申请场景 | 倒查内容 | 考察重点 |
|---------|---------|---------|
| 积极分子→发展对象 | 参与支部工作情况 | 是否积极参与，有无深度参与或组织经历 |
| 发展对象→预备党员 | 工作参与质量和数量 | 政治觉悟、工作能力、群众基础 |
| 预备党员转正 | 是否【组织】或【深度参与】 | 是否满足11月支部大会要求 |
| 评优评先 | 对支部工作的贡献 | 参与次数、工作质量、影响力 |

**倒查流程：**
```
个人提交申请 → 提交自述 → 组织委员倒查档案 → 核对验证 → 出具考察意见
```

**防止造假机制：**
- 纪检委员实时记录，不是事后补充
- 活动组织者确认
- 多个信息源交叉验证（纪检、宣传、条条组长）
- 自述与档案不符时需要说明

### 3.5 档案模板

```
【姓名】考察档案

基本信息：
- 姓名：________
- 身份：□党员 □预备党员 □发展对象 □积极分子
- 所属党小组：□第一 □第二 □第三
- 入党申请时间：____
- 确定积极分子时间：____

参与记录（由纪检委员提交）：

| 时间 | 活动 | 参与角色 | 具体工作 | 记录人 |
|------|------|---------|---------|--------|

| 2026-02 | XX活动 | 【深度参与-宣传】 | 推文撰写 | 韩思宁 |

统计汇总：

思想汇报记录：
```

## 四、思想汇报管理

### 4.1 提交要求

| 身份 | 提交频率 | 内容要求 |
|------|---------|---------|
| 积极分子 | 每季度1篇 | 思想认识、学习体会、实际行动 |
| 发展对象 | 每季度1篇 | 政治学习、工作实践、自我剖析 |
| 预备党员 | 每季度1篇 | 预备期表现、继续努力方向 |

**质量标准：**
- ☑ 字数1500字以上
- ☑ 内容真实具体
- ☑ 有思想深度
- ☑ 联系实际

### 4.2 收集归档流程

| 步骤 | 工作内容 | 时间 |
|------|----------|------|
| ① 提醒提交 | 每季度末提醒成员提交 | 季度最后一周 |
| ② 收集汇总 | 收集所有思想汇报 | 季度后1周 |
| ③ 质量检查 | 检查格式、字数、内容 | 收到后3天 |
| ④ 反馈修改 | 不合格的要求修改 | 检查后2天 |
| ⑤ 归档管理 | 录入档案系统，分类保存 | 收齐后1周 |

**归档方式：**
- 电子版：支部信息平台/云盘
- 纸质版：按人建档，按时间排序
- 记录在考察档案中

## 六、意见反馈平台管理

### 6.1 反馈渠道

| 渠道类型 | 使用方式 | 适用场景 | 责任人 |
|---------|---------|---------|--------|
| **直接反馈** | 直接向组织委员反馈 | 党员发展相关问题 | 组织委员 |
| **平台反馈** | 通过支部信息平台提交 | 一般性意见建议 | 组织委员 |
| **书面反馈** | 邮件或表单提交 | 需详细说明的问题 | 组织委员 |
| **会议反馈** | 支部大会上提出 | 公开讨论的问题 | 支部书记 |
| **匿名反馈** | 匿名渠道（如问卷） | 不便公开的问题 | 组织委员 |

**说明：** 2026年2月起，意见反馈平台管理由组织委员负责，作为支部信息平台建设的一部分。

### 6.2 处理流程

```
收集整理 → 分类汇总 → 提交支委会 → 讨论处理 → 反馈结果 → 跟踪落实
```

| 步骤 | 工作内容 | 时间 |
|------|----------|------|
| ① 收集意见 | 通过各种渠道收集 | 持续 |
| ② 分类整理 | 分类：党建/活动/制度/其他 | 收到后1天 |
| ③ 提交支委会 | 汇总提交支委会讨论 | 下次支委会 |
| ④ 讨论处理 | 支委会研究处理方案 | 支委会上 |
| ⑤ 反馈结果 | 向提出者反馈 | 讨论后1周 |
| ⑥ 跟踪落实 | 跟踪措施落实情况 | 后续持续 |

**处理时限：**

| 问题类型 | 反馈时间 | 处理方式 |
|---------|---------|---------|
| 党员发展建议 | 1周内 | 组织委员研究或提交支委会 |
| 制度建设建议 | 下次支委会后 | 提交支委会讨论 |
| 活动组织建议 | 1周内 | 转相关条条组长处理 |
| 其他建议 | 2周内 | 提交支委会研究 |

## 七、工作协调机制

### 7.1 与纪检委员的协调

**协调原则：**
- 纪检委员负责记录活动参与情况
- 组织委员负责建档管理和出具意见
- 定期交接，信息共享

**协调流程：**
```
纪检委员记录参与情况 → 每月提交组织委员 → 组织委员建档管理 → 
发展时组织委员查询 → 出具考察意见
```

**定期交接：**
- 时间：每月最后一周
- 内容：本月所有活动参与记录
- 方式：纸质+电子版
- 确认：双方签字确认

### 7.2 与宣传委员的协调

**协调内容：**
- 活动材料的归档（宣传委员→组织委员）
- 考察档案中需要的活动材料
- 发展材料中的宣传材料

**协调方式：**
- 组织委员需要活动材料时向宣传委员索取
- 宣传委员定期将重要活动材料提供给组织委员

### 7.3 与支部书记的协调

**汇报机制：**
- 定期汇报党员发展进度
- 重大事项及时请示
- 支委会上汇报工作

**汇报内容：**
- 积极分子培养情况
- 发展对象考察进度
- 预备党员转正计划
- 考察档案建设情况
- 意见反馈处理情况

## 九、常见问题（FAQ）

**Q1: 组织委员和纪检委员在考察工作中如何分工？**
- 纪检委员：记录活动中的参与情况（组织/深度参与/出勤）
- 组织委员：接收记录、建档管理、出具考察意见
- 分工清晰，避免重复劳动

**Q2: 如何确保考察档案的准确性？**
- 记录由纪检委员在活动中实时完成
- 与活动组织者确认
- 每月交接时双方确认
- 多个信息源交叉验证

**Q3: 思想汇报不合格怎么办？**
- 明确指出不合格之处
- 要求限期修改（1周内）
- 仍不合格的约谈说明
- 影响考察意见

**Q4: 意见反馈如何保密？**
- 匿名反馈不追查提出者
- 敏感问题单独处理
- 不在公开场合讨论
- 只向支委会汇报

**Q5: 考察档案谁可以查询？**
- 组织委员：随时查询
- 支部书记：随时查询
- 培养联系人：本人培养对象
- 本人：可以查询本人档案

**Q6: 如何判断预备党员是否满足转正条件？**
- 查看考察档案：是否【组织】或【深度参与】活动
- 检查思想汇报：是否按时提交，质量如何
- 征求意见：培养人、党小组、群众意见
- 综合评价：政治、思想、工作、学习、生活
