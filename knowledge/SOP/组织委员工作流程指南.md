# 组织委员工作流程指南

## 文档说明

本文档详细说明组织委员（侯嘉嵘）的工作流程、职责范围和操作规范，是组织委员开展日常工作的核心参考文件。

**核心定位：** 组织委员作为条条委员，横跨三个党小组，专注考察档案维护与材料全案复核、预备党员转正流程及思想汇报统计归档、协助党员发展工作，并担任**发展对象培训班领队**及**党委办公室助理**，掌握党员发展全链路一手信息，是所有党员发展材料与考察数据的终极归档中心（纪检委员每月提交的参与记录与积极分子思想汇报均汇聚于此）；支委会讨论新发展名单时，所需决策依据由本人负责整理提供。

**术语说明：**
- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- 不使用"普通党员"等具有层级性的表述

## 一、工作职责总览

### 1.1 核心职责（条条职能）

| 职责类别 | 具体内容 | 工作性质 |
|---------|----------|----------|
| 📂 考察档案维护 | 建立维护积极分子考察档案、活动参与统计 | 档案管理 |
| 📧 思想汇报归档 | 接收纪检委员转交的思想汇报并归档统计 | 档案管理 |
| 📋 材料催缴与审核督办 | 发展/转正流程材料催缴与督办；实际材料审核由党办进行，组织委员负责提醒与协调进度 | 质量控制 |
| 🎓 培训班领队 | 发展对象培训班前置组织协调、领队对接 | 组织发展 |
| 👥 协助党员发展工作 | 配合支部书记做好党员发展 | 组织发展 |

### 1.2 四大工作场景

组织委员的工作可以分为四大场景：

#### 场景一：考察档案维护与材料督办
- 建立并维护积极分子考察档案系统
- 党员发展/预备转正流程中的材料催缴、收集与督办（实际审核由党办执行；组织委员负责提醒与协调进度）

#### 场景二：思想汇报归档
- 接收纪检委员转交的思想汇报并归档（公邮定时查收与分发已由纪检委员负责）
- 统计思想汇报提交情况
- 归档保存思想汇报材料

#### 场景三：党小组活动工作流建设
- 与纪检委员共同建设活动工作流
- 优化活动组织流程
- 归档活动记录，提供档案查阅支持

#### 场景四：培训班领队与党员发展协助
- 协助支部书记做好党员发展工作
- 准备相关材料和档案
- 协调信息沟通

## 二、考察档案与信息平台管理

> **权限更新（2026-03-04）：** 公邮定时查收与分发职能已移交纪检委员（每周查看1次）。组织委员负责接收纪检委员转交的思想汇报与材料后归档，专注档案维护与材料催缴督办（实际材料审核由党办进行，组织委员负责提醒与协调进度）。活动通知发布职责另见2026-03-03更新。

### 2.1 信息平台的功能定位

**信息平台的作用（组织委员当前职责范围）：**
- ✅ 接收纪检委员转交的思想汇报并归档（公邮定时查收由纪检委员负责）
- ✅ 归档重要文件和材料
- ✅ 维护信息系统
- ❌ 不再负责发布活动通知或招募公告（该权限已归还支书和块块组长）

**平台维护边界：** 组织委员负责管理支部公邮（接收思想汇报、党员发展材料等来件），维护信息系统及档案，**不再负责对外发布活动通知或招募公告**。正式通知及招募公告的发布权：全支部层面由支书（储子禾）通过党支部大群/公邮发布；党小组活动通知由块块组长通过党小组群发布；跨组具体信息由全体块块组长共同决策后由支书统一发出。因同时担任第一党小组组长，本人组内活动按组长身份参与。

**支部通知发布权限矩阵（更新后）：**

| 通知范围 | 负责人 | 渠道 |
|---------|--------|------|
| 全支部重要通知/招募公告 | 支书 储子禾 | 党支部大群/公邮 |
| 党小组活动通知 | 块块组长（储子禾/王峥旭/辛长乐） | 党小组微信群 |
| 跨组具体对接信息 | 全体块块组长决策 → 支书发出 | 党小组群或活动群 |

### 2.2 公邮管理与档案维护

#### 公邮来件归档（纪检委员查收后转交）

| 工作内容 | 频率 | 具体操作 |
|---------|------|---------|
| 1️⃣ 归档思想汇报 | 收到转交即处理 | 按人员类别归档，回复确认收到 | `[角色: 组织委员]` |
| 2️⃣ 接收材料来件 | 收到即处理 | 归档发展/转正材料，更新收件台账 | `[角色: 组织委员]` |

> **注：** 公邮定时查收与分发（每周1次）由**纪检委员**负责。

### 2.3 信息系统维护

| 维护内容 | 频率 | 具体工作 |
|---------|------|---------|
| 公邮查收 | 每周（纪检委员负责） | 纪检委员查看公邮，必要时转发/提醒组织委员 |
| 文件归档 | 每周 | 将重要文件分类归档 |
| 系统更新 | 按需 | 更新信息系统功能和内容 |

## 三、思想汇报统计归档

### 3.1 思想汇报收集

#### 思想汇报对象

| 对象类别 | 汇报频率 | 提交方式 |
|---------|---------|---------|
| 积极分子 | 每季度至少1次 | 发送至支部公邮 |
| 发展对象 | 每季度至少1次 | 发送至支部公邮 |
| 预备党员 | 每季度至少1次 | 发送至支部公邮 |

#### 思想汇报要求

**格式要求：**
- 标题：思想汇报 - [姓名] - [YYYY年MM月DD日]
- 正文：**统一为1500字以上**；对积极分子不作硬性要求（按实际培养与需要安排）
- 内容要点：
  1. 近期思想状况
  2. 学习工作情况
  3. 存在的问题和不足
  4. 今后的努力方向

**提交要求：**
- 提交至支部公邮
- 按时提交，不得拖延
- 内容真实，有深度思考

### 3.2 统计与归档流程

```
纪检委员定期查收公邮 → 转交组织委员 → 登记收到的汇报 → 提醒未提交者 → 统计汇总 → 分类归档 → 反馈支部书记
```

#### 详细流程

| 阶段 | 工作内容 | 责任人 | 时间要求 |
|------|----------|--------|----------|
| **收集阶段** | | | |
| 1️⃣ 定期检查公邮 | 每周至少检查2次公邮 | 组织委员 | 每周 |
| 2️⃣ 登记汇报 | 记录收到的思想汇报及提交人 | 组织委员 | 收到后1天内 |
| 3️⃣ 确认收到 | 回复确认已收到汇报 | 组织委员 | 收到后1天内 |
| **统计阶段** | | | |
| 4️⃣ 统计提交情况 | 每季度末统计汇报提交情况 | 组织委员 | 季度末 |
| 5️⃣ 提醒未提交者 | 联系未按时提交的同志 | 组织委员 | 季度末 |
| 6️⃣ 汇总统计表 | 制作汇报统计表 | 组织委员 | 季度末 |
| **归档阶段** | | | |
| 7️⃣ 分类归档 | 按照人员类别归档汇报 | 组织委员 | 季度末 |
| 8️⃣ 电子存档 | 上传至档案系统 | 组织委员 | 季度末 |
| 9️⃣ 反馈书记 | 将统计情况反馈支部书记 | 组织委员 | 季度末 |

#### 思想汇报统计表模板

```
| 序号 | 姓名 | 身份 | 应交次数 | 实交次数 | 提交日期 | 备注 |
|------|------|------|---------|---------|---------|------|
| 1 | | 积极分子 | 1 | | | |
| 2 | | 发展对象 | 1 | | | |
| 3 | | 预备党员 | 1 | | | |
| ... | | | | | | |

统计日期：[YYYY-MM-DD]
统计人：侯嘉嵘（组织委员）

按时提交：[X]人
逾期提交：[X]人
未提交：[X]人
提交率：[X]%
```

### 3.3 思想汇报质量把关

#### 质量标准

**合格的思想汇报应满足：**
- [ ] 格式规范（标题、正文、日期）
- [ ] 字数达标（1000-1500字）
- [ ] 内容真实（有真实的思考和感悟）
- [ ] 逻辑清晰（结构合理，层次分明）
- [ ] 按时提交（不拖延）

**不合格的思想汇报：**
- ❌ 敷衍了事，内容空洞
- ❌ 字数不足，过于简短
- ❌ 抄袭网络，缺乏思考
- ❌ 格式混乱，不符合要求

#### 质量反馈机制

**对于不合格的思想汇报：**
1. 及时联系提交者说明问题
2. 要求重新提交
3. 记录在案，影响考察意见

## 四、党小组活动工作流建设

### 4.1 工作流建设目标

**目标：** 与纪检委员共同建设高效、规范的党小组活动工作流，提升活动组织质量和效率。

**工作流包含的环节：**
1. 活动策划
2. 信息通知（组织委员负责）
3. 宣传材料准备
4. 考勤考察（纪检委员负责）
5. 活动实施
6. 活动复盘
7. 材料归档

### 4.2 与纪检委员的协作

#### 协作内容

| 协作环节 | 组织委员职责 | 纪检委员职责 |
|---------|------------|------------|
| 活动前期 | 协调参与对象范围，归档活动记录；通知由块块组长（本组）/ 支书（全支部）负责 | 明确考勤要求和深度参与者 |
| 活动中期 | 协调信息沟通 | 现场考勤记录 |
| 活动后期 | 归档活动记录 | 记录考察情况，监督复盘 |

#### 协作流程

```
活动组织者发起 → 块块组长/支书发布通知 → 纪检委员明确考勤 → 
活动实施 → 纪检委员记录考勤 → 组织委员归档记录
```

### 4.3 工作流优化机制

#### 优化方向

**简化流程：**
- 减少不必要的环节
- 提高信息传递效率
- 降低组织成本

**提升质量：**
- 明确责任分工
- 强化监督机制
- 及时反馈改进

#### 优化方法

**收集问题：**
- 定期收集活动组织者的反馈
- 了解工作流中的痛点
- 分析问题产生的原因

**提出方案：**
- 制定改进措施
- 与纪检委员讨论
- 提交支委会审议

**试点实施：**
- 在个别党小组试点
- 收集试点反馈
- 调整优化方案

**全面推广：**
- 经支委会通过后全面推广
- 做好培训和指导
- 持续跟踪效果

## 五、协助党员发展工作

### 5.1 发展流程中的职责

#### 党员发展流程

```
积极分子培养 → 确定发展对象 → 接收预备党员 → 预备党员转正
```

#### 组织委员在各阶段的职责

| 发展阶段 | 组织委员职责 | 配合人员 |
|---------|------------|---------|
| 积极分子培养 | ①定期检查公邮，归档思想汇报<br>②统计思想汇报提交情况<br>③协助支部书记做好培养工作 | 支部书记、纪检委员 |
| 确定发展对象 | ①准备发展对象材料<br>②协调支委会讨论<br>③整理会议记录 | 支部书记、支委会 |
| 接收预备党员 | ①准备入党材料<br>②协调党员大会<br>③整理表决结果 | 支部书记、全体党员 |
| 预备党员转正 | ①检查转正材料<br>②协调党员大会<br>③整理转正决议 | 支部书记、全体党员 |

### 5.2 材料准备与审核

#### 需要准备的材料

**积极分子阶段：**
- 积极分子培养考察登记表
- 思想汇报汇总
- 培养联系人意见

**发展对象阶段：**
- 发展对象备案表
- 政治审查材料
- 征求党内外群众意见记录

**预备党员阶段：**
- 入党志愿书
- 支部大会决议
- 上级党组织审批意见

**转正阶段：**
- 预备党员转正申请书
- 预备期思想汇报汇总
- 支部大会决议

#### 材料审核要点

**审核标准：**
- [ ] 材料齐全，无遗漏
- [ ] 填写规范，无错误
- [ ] 签字盖章齐全
- [ ] 时间节点准确
- [ ] 内容真实可靠

**材料全案复核权（重要）：**

在发展对象确认及预备党员转正的全部流程中，**所有材料的催缴、收集以及提交后的规范性检查（防缺漏、防错填），均由组织委员一人全权负责**，不得委托他人代为检查或提交。

具体职责包括：
- **催缴**：在规定截止日前主动提醒相关人员按时提交材料
- **收集**：统一汇总所有材料，建立收件台账
- **规范性检查**：逐项核查材料的完整性（无缺项）和准确性（无错填、无漏签），发现问题立即退回当事人补正后重新提交
- **终极把关**：材料转交党委前进行最终审核，确保无误方可移交

### 5.3 与支部书记的配合

#### 配合原则

**支部书记：** 牵头党员发展工作，总体把关

**组织委员：** 协助准备材料，做好组织协调

#### 配合流程

```
支部书记确定发展对象 → 组织委员准备材料 → 支部书记审核 → 
组织委员协调会议 → 支部书记主持会议 → 组织委员整理记录
```

#### 定期沟通

**沟通频率：** 每月至少1次

**沟通内容：**
- 思想汇报提交情况
- 积极分子培养进展
- 发展对象考察情况
- 材料准备进度

## 六、工作协调机制

### 6.1 与块块组长的协调

#### 协调原则

**块块组长：** 负责党小组活动组织，提出信息平台支持需求

**组织委员：** 归档活动记录，协调参与对象范围信息

#### 协调流程

```
块块组长发起活动 → 块块组长/支书发布通知 → 确认参与对象 → 活动实施 → 组织委员归档记录
```

## 七、常见问题解答（FAQ）

### Q1: 如何确保信息通知不遗漏？

**方法：**
1. 使用多个通知渠道（公邮 + 群聊）
2. 建立确认机制（要求回复确认）
3. 提醒未确认者（活动前1天再次提醒）
4. 建立名单制度（确保覆盖所有目标对象）

### Q2: 如果有人长期不提交思想汇报怎么办？

**处理流程：**
1. 第一次未提交：及时提醒
2. 第二次未提交：个别谈话，了解原因
3. 第三次未提交：向支部书记汇报
4. 持续不提交：影响考察意见，延缓发展

### Q3: 党小组活动工作流建设的重点是什么？

**重点：**
1. **简化流程**：减少不必要的环节
2. **明确分工**：每个环节责任明确
3. **提升效率**：信息传递及时准确
4. **强化监督**：确保流程落实到位

### Q4: 如何与纪检委员有效协作？

**有效协作的方法：**
1. 定期沟通：至少每月沟通1次
2. 明确分工：各自职责清晰明确
3. 信息共享：及时交流工作信息
4. 共同优化：一起改进工作流程

### Q5: 信息平台出现技术问题怎么办？

**应对措施：**
1. 立即启用备用通知渠道
2. 及时联系技术支持解决问题
3. 向支部书记和相关人员说明情况
4. 做好问题记录，避免再次发生

### Q6: 如何平衡组织委员和党小组组长的双重身份？

**平衡原则：**
- 以条条职能为主，在本组内履行组长职责
- 职能线工作横跨三个党小组
- 在本组内同时履行组长和委员双重职责
