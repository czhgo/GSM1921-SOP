# 申报材料模板库使用说明

## 概述

本目录包含光华管理学院本科生党支部常用的申报材料模板，由宣传委员负责维护和更新。这些模板旨在提供**高度可复用**的材料，减少重复劳动，提升申报质量和效率。

**维护者：** 宣传委员 闫鑫岳

---

## 📋 材料分类体系

根据材料的用途和性质，我们将模板分为三大类：

### 第一类：工作记录类 📝

**定位：** 日常上报给上级组织备案审查的工作记录

**特点：**
- 正式、规范
- 用于上级备案审查
- 必须按照标准格式填写

**目录：** [工作记录类/](./工作记录类/)

**包含内容：**
- 党支部工作记录模板（三会一课、主题党日等）

### 第二类：宣传材料类 📢

**定位：** 需要发布宣传推送的材料

**特点：**
- 对外发布
- 表述清晰、准确
- 内容无政治风险
- 符合宣传规范

**目录：** [宣传材料类/](./宣传材料类/)

**包含内容：**
- 宣传推文模板
- 海报设计规范

### 第三类：其他模板 📄

**定位：** 支部日常工作中使用的其他各类模板

**特点：**
- 高度可复用
- 提升工作效率
- 保证材料质量

**目录：** [其他模板/](./其他模板/)

**包含内容：**
- 支部基本信息模板
- 活动总结模板
- 评优评先申报书模板

---

## 💡 关于活动复盘

**活动复盘不在本模板库中，而是有专门的管理方式。**

非三会一课活动的复盘记录在 [../活动复盘/](../活动复盘/) 目录中管理。

**复盘的特点：**
- 格式灵活，不要求正规格式
- 重在对未来工作的指导意义
- 使用Markdown文件记录
- 可以结合GitHub Issues进行讨论

**详细说明：** 请查看 [活动复盘/README.md](../活动复盘/README.md)

## 使用指南

### 如何选择合适的模板

1. **确定材料类型**：
   - 工作记录类？→ 查看[工作记录类/](./工作记录类/)
   - 宣传材料类？→ 查看[宣传材料类/](./宣传材料类/)
   - 其他模板？→ 查看[其他模板/](./其他模板/)
   - 活动复盘？→ 查看[../活动复盘/](../活动复盘/)

2. **查找对应模板**：在相应目录中查找需要的模板

3. **下载使用**：下载模板并根据要求填写

4. **定制化修改**：根据具体需求调整模板内容

### 模板使用流程

```
确定需求 → 选择模板类型 → 下载模板 → 填写内容 → 定制化修改 → 提交审核
```

---

## 注意事项

⚠️ **使用前必读：**
- 所有模板仅供参考，需根据具体要求调整
- 模板中的"[X]"表示需要填写的内容
- 模板中的"[待补充]"表示需要补充的内容
- 使用前检查模板的更新日期，确保信息时效性

✅ **使用后注意：**
- 及时向宣传委员反馈使用体验
- 发现错误或需要改进的地方及时提出
- 成功案例可以分享给宣传委员，供其他同志参考

## 模板更新机制

### 更新频率

| 更新类型 | 频率 | 负责人 |
|---------|------|--------|
| 定期更新（支部信息、荣誉等） | 每学期初 | 宣传委员 |
| 应需更新（新增模板、优化现有模板） | 按需 | 宣传委员 |
| 紧急更新（政策变化、格式调整） | 及时 | 宣传委员 |

### 如何申请新模板

如果您需要的模板不在本目录中，可以通过以下方式申请：

1. 联系宣传委员闫鑫岳
2. 说明模板的用途和需求
3. 提供参考案例（如有）
4. 宣传委员将在1周内创建模板

### 如何建议模板改进

发现模板中的问题或有改进建议，请：

1. 联系宣传委员闫鑫岳
2. 具体说明问题或建议
3. 宣传委员将评估并及时更新
