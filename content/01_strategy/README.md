# 战略层索引——支部发展和管理的战略

> 目录定位见 [DOC_MAP.md §五 目录作用表](../03_doc_system/DOC_MAP.md#五目录作用表2026-10-24-立)。

## 作用

本目录存放**知识类型 1：支部发展和管理的战略**，回答「支部为什么存在、根本目标、战略路线」。

## 不负责什么

- 不写制度操作流程与角色分工——归 `02_institution/`。
- 不写系统设计、数据模型与 AI 协作方法——归 `04_web_design/`、`05_ai_coding/`。
- 不加工原始材料——`references/` 只读存档，结论须另行写入本层正文。

| 文件 | 一句话作用 | 权威源？（是/指针） |
|------|-----------|-------------------|

## 权威源与派生

- **权威源**：`SECRETARY_DIRECTIVES.md`（战略与支书论断）与 `DEVELOPMENT_PATH.md`（发展路径叙事），两者互不覆盖。
- **派生**：本 README 只是索引；`02_institution/` 的制度与 SOP 是战略路线的落地派生；`03_doc_system/DOC_MAP.md` 提供全仓导航。
- **原始依据**：`references/合规文件/`（上级文件原文）与 `references/历史会议材料/`（支部存档）是论证来源，不是本层结论。

## 知识流向

支书论断、会议共识与上级文件 → 在 `SECRETARY_DIRECTIVES.md` / `DEVELOPMENT_PATH.md` 沉淀为战略结论 → 向下派生出 `02_institution/` 的组织与制度、`04_web_design/` 的系统设计 → 实践中的新经验经 `insights/` 串讲后回流本层修订。

## 是否保留原始材料

保留。原始材料集中在 [`references/`](references/README.md)：合规文件、历史会议材料、建设探索三类，均为只读；修改须按仓库授权流程申请。

## 维护触发器

- 新增、删除或重命名本层文件；
- 支书路线级论断或发展路径叙事发生变更（权威源变更）；
- `references/` 子目录增减或原文替换；
- [DOC_MAP.md §五 目录作用表](../03_doc_system/DOC_MAP.md#五目录作用表2026-10-24-立) 中本目录职责调整。
