# Agent 操作手册

> 适用范围：当前工作区已完成 `.github/` 原生对齐（原生 `handoffs` + 原生 `Allow/Cancel`）。
> 核心目标：把"正文里手写 `@` 指挥"升级为"按钮驱动、可审计、低阻尼"的工业化流水线。

## 1. 绝对起手式（Set Agent）

### 为什么必须先选“秘书处”
- 所有任务入口统一收敛到“秘书处”，由其执行全局路由与边界判定。
- 避免多入口并发导致的上下文分叉、职责越权和链路失真。
- 与宪章“原生委派纪律”保持一致：跨 Agent 交接应走 `handoffs`，不是正文乱 `@`。

### 标准起手动作
1. 打开 Chat 面板顶部 Agent 下拉菜单。
2. 选择“秘书处”作为当前 Agent。
3. 再输入你的任务目标（不要先写 `@发改委`、`@工信部` 等正文唤醒语句）。

### 反模式（必须淘汰）
- 在正文直接写“@某部门去做 X”作为主要调度手段。
- 未锁定“秘书处”就直接切换到执行部门开工。
- 把委派信息写成长段自然语言而不走按钮交接。

---

## 2. 流水线委派（Native Handoffs）

### 标准闭环范式（文本 SOP 变更示例）
1. 用户在“秘书处”提交需求，秘书处完成分解、约束和风险前置。
2. 用户点击按钮：`[fagaiwei: 委派给发改委 (修改文本 SOP)]`。
3. 发改委执行实质修改（遵循 Blueprint + /ask + SSOT 溯源）。
4. 发改委完成后，用户点击底部按钮：`[danganguan: 委派给档案馆 (记账)]`。
5. 档案馆按月度日志规范补记变更摘要，形成可审计闭环。

### 你将获得的工程收益
- 委派路径可见：谁发起、谁执行、谁记账，一眼可追踪。
- 边界清晰：秘书处负责规划，执行层负责修改，档案层负责沉淀。
- 变更闭环：任务不是“改完就散”，而是“改完即入账”。

---

## 3. 一键即发（`send: true` 机制）

### 机制解释
- `handoffs` 按钮配置了 `send: true` 后，点击按钮会同时触发两件事：
1. 切换到目标 Agent 并继承当前上下文。
2. 自动发送该按钮绑定的委派 `prompt`（无需二次点击发送）。

### 结果：零点击阻尼流水线
- 无需“点按钮 -> 再复制指令 -> 再点发送”的重复动作。
- 从路由到执行一跳到位，减少人为漏发、错发和节奏中断。
- 非常适合多阶段任务：分析 -> 执行 -> 记账 的连续推进。

### 使用要点
- 按钮文案应包含可识别前缀（如 `fagaiwei:`），避免标签校验失败。
- 委派语句尽量短、动作明确、目标单一，保证自动发送后可直接执行。
- 若进入下一阶段前需确认，继续使用原生 `Allow/Cancel`，不要回退到文本伪确认。

## 4. 安全与熔断（Diagnostics & New Session）

### A. Diagnostics：先查健康，再判异常
当你怀疑“按钮没刷新”“规则没生效”“行为像旧缓存”时：

1. 在相关消息或会话节点上右键。
2. 选择 `Diagnostics`。
3. 检查当前会话是否加载了最新 Agent 配置与指令上下文。
4. 若发现缓存滞后，不要硬顶执行，先刷新会话状态。

### B. New Session：架构变更后的硬规程
凡修改以下文件后，必须开启新会话：
- `.github/copilot-instructions.md`
- `.github/agents/*.agent.md`
- `.github/skills/*/SKILL.md`
- 其他会影响路由、边界、委派或授权语义的配置文件

#### 操作步骤
1. 完成配置修改并确认保存。
2. 点击会话列表旁 `+` 新建 `New Session`。
3. 在新会话重新执行“绝对起手式（Set Agent -> 秘书处）”。
4. 再启动下一轮任务，避免脏上下文污染。

### 熔断原则（记忆口诀）
- 看不准：先 `Diagnostics`。
- 改过架构：立刻 `New Session`。
- 涉及执行：走原生 `Allow/Cancel`。
- 涉及委派：点 `handoffs`，不乱 `@`。

## 极简速查卡（可贴在团队 Wiki 首页）

1. 先选“秘书处”，再提需求。  
2. 跨 Agent 一律点 `handoffs` 按钮。  
3. 按钮 `send: true` = 切换并自动发指令。  
4. 执行后点 `danganguan` 完成记账闭环。  
5. 架构文件一改，必须 `+` 开新会话。  
6. 有疑似缓存问题，右键先看 `Diagnostics`。  

---

## 结语（执行口令）

- 路由入口统一：秘书处。  
- 委派通道统一：Native Handoffs。  
- 授权确认统一：Allow/Cancel。  
- 变更收口统一：档案馆记账。  
- 会话卫生统一：改架构必开 New Session。
