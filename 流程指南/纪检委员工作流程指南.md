# 纪检委员工作流程指南

## 文档说明

本文档详细说明纪检委员（韩思宁）的工作流程、职责范围和操作规范，是纪检委员开展日常工作的核心参考文件。

**核心定位：** 纪检委员作为块块委员，横跨三个党小组，负责学习与考察制度建设、监督与议事制度建设、党员出勤与补课规范、意见建议反馈平台建设。

**特别说明：** 根据11月支部大会精神，学生支部不涉及特别多的"纪律问题"，因此纪检委员的工作重点包括**活动组织监督**和**考勤考察管理**。

**术语说明：**
- **支部党员** = 党员 + 预备党员
- **支部成员** = 党员 + 预备党员 + 发展对象 + 积极分子
- 不使用"普通党员"等具有层级性的表述

## 一、工作职责总览

### 1.1 核心职责

| 职责类别 | 工作内容 | 对象 | 说明 |
|---------|---------|------|------|
| 📋 **考勤管理** | 记录三会一课出勤情况 | 党员、预备党员 | 二元记录（出勤/请假/缺勤），提交宣传委员备案 |
| 📝 **考察管理** | 记录支部工作参与情况 | 所有支部成员 | 分三层记录（组织/深度参与/出勤），采用倒查法 |
| 👁️ **活动监督** | 监督活动复盘完成 | 活动组织者 | 确保组织者亲自完成复盘 |
| 📋 **制度建设** | 建立考勤考察规范 | - | 补课制度、意见反馈机制等 |

### 1.2 考勤与考察的核心区别

| 维度 | 考勤（0-1变量） | 考察（复杂变量） |
|------|----------------|-----------------|
| **对象** | 党员、预备党员 | 所有支部成员 |
| **适用** | 三会一课 | 所有支部工作 |
| **记录** | 出勤/请假/缺勤 | 组织/深度参与/出勤 |
| **方式** | 实时记录 | 倒查法（申请时核查） |
| **流向** | 提交宣传委员备案 | 用于党员发展考察 |

## 二、考勤管理（三会一课）

### 2.1 考勤范围与记录标准

| 活动类型 | 考勤对象 | 记录状态 |
|---------|---------|---------|
| 支部委员会 | 支委会成员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 支部党员大会 | 党员、预备党员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 党小组会 | 本组党员、预备党员 | ✅出勤 / 🏥请假 / ❌缺勤 |
| 党课 | 党员、预备党员、发展对象、积极分子 | ✅出勤 / 🏥请假 / ❌缺勤 |

**说明：** 考勤是0-1记录，只记录客观出勤事实，不考虑质量。其他党小组活动根据性质决定是否记考勤或转入考察系统。

### 2.2 请假与补课

| 类型 | 申请时间 | 处理方式 |
|------|---------|---------|
| **事假** | 提前1天 | 联系纪检委员，说明原因 |
| **病假** | 事后补假 | 提供就医证明 |
| **缺勤** | 事后说明 | 及时联系，无故缺勤影响考察 |

**补课要求：** 请假/缺勤后1周内完成（特殊情况2周），形式包括：阅读材料、观看录像、提交心得等。完成后标注"已补"。

### 2.3 考勤工作流程

```
活动前：准备考勤表 → 活动中：签到记录 → 活动后：整理汇总 → 定期提交给宣传委员
```

| 阶段 | 工作内容 | 时间 |
|------|----------|------|
| **活动前** | ① 准备考勤表<br>② 收集请假信息 | 活动前1天 |
| **活动中** | ③ 组织签到<br>④ 核对人数 | 活动开始时 |
| **活动后** | ⑤ 整理考勤（标注状态）<br>⑥ 联系缺勤人员<br>⑦ 安排补课<br>⑧ 提交宣传委员 | 1-5天内 |

**考勤表模板：**
```
【活动名称】考勤表
时间：____  地点：____  类型：□支委会 □大会 □党小组会 □党课

序号 | 姓名 | 身份 | 状态 | 备注
----|------|------|------|-----
1   |      |      | □出勤 □请假 □缺勤 | 

应到/实到/请假/缺勤：__/__/__/__人
记录人：韩思宁  日期：____
```

## 三、考察管理（支部工作参与）

### 3.1 考察目的与原则

**目的：** 记录支部成员参与支部工作情况，为党员发展提供依据，鼓励党员【组织】或【深度参与】活动。

**原则：倒查法** - 不主动追踪每个行为，而是在个人申请时根据其自述倒查档案验证。如果自己都忘记了，说明参与度不够，无需追认。

### 3.2 考察对象与三层记录

| 参与层次 | 定义 | 记录内容 | 适用场景 |
|---------|------|---------|---------|
| **【组织】** | 活动策划组织者 | 活动名称、组织工作、效果 | 重点考察，满足党员责任要求 |
| **【深度参与】** | 承担具体工作 | 宣传/现场统筹/技术支持等 | 考察执行力、协调力 |
| **【出勤】** | 参加但无具体工作 | 仅记录出勤 | 基础参与 |

**说明：** 
- 组织者不限于组长或支委，体现项目制灵活性
- 深度参与工作必须可验证，不能挂名
- 所有记录用于党员发展、转正、评优评先

### 3.3 考察工作流程

```
活动前：了解分工 → 活动中：观察记录 → 活动后：确认归档 → 申请时：倒查验证
```

| 阶段 | 工作内容 | 时间 |
|------|----------|------|
| **活动前** | 与组织者沟通，了解分工 | 活动前3-5天 |
| **活动中** | 观察实际参与情况 | 活动期间 |
| **活动后** | 确认角色、记录档案、监督复盘 | 活动后3-7天 |
| **申请时** | 根据自述倒查档案，出具意见 | 申请提交后 |

**考察档案模板（简化版）：**
```
【姓名】考察档案
身份：□党员 □预备党员 □发展对象 □积极分子

| 时间 | 活动 | 角色 | 具体工作 |
|------|------|------|---------|
| 2026-02 | XX活动 | 【组织】 | 策划实施 |
| 2026-02 | XX活动 | 【深度参与-宣传】 | 推文撰写 |
| 2026-02 | XX活动 | 【出勤】 | 参与 |

统计：【组织】_次 | 【深度参与】_次 | 【出勤】_次
记录人：韩思宁
```

### 3.4 倒查法应用

| 申请场景 | 倒查重点 |
|---------|---------|
| 积极分子→发展对象/预备党员 | 是否积极参与，有无深度参与或组织经历 |
| 预备党员转正 | 是否【组织】或【深度参与】活动（11月支部大会要求） |
| 评优评先 | 参与次数、工作质量、影响力 |

**防止造假机制：** 实时记录、组织者确认、多信息源交叉验证、自述与档案核对。

## 四、活动监督与意见反馈

### 4.1 监督活动复盘

**要求：** 活动复盘必须由【组织者】亲自完成，不能委托。

| 步骤 | 工作 | 时间 |
|------|------|------|
| ① 活动后提醒 | 提醒组织者完成复盘 | 活动后1天 |
| ② 跟进检查 | 检查是否由组织者完成、内容是否充实 | 活动后5-7天 |
| ③ 记录反馈 | 在考察档案记录完成情况，定期向支委会汇报 | 活动后1周、每月支委会 |

**合格复盘标准：** ☑ 组织者本人完成 ☑ 内容具体有建议 ☑ 及时（1周内） ☑ 使用模板结构

### 4.2 意见建议反馈平台

**反馈渠道：**
- 直接反馈：向纪检委员韩思宁反馈（紧急/敏感问题）
- 书面反馈：邮件或表单（需详细说明）
- 会议反馈：支部大会提出（公开讨论）
- 匿名反馈：匿名渠道如问卷（不便公开）

**处理流程：** 
```
收集整理 → 提交支委会讨论 → 反馈结果 → 跟踪落实
```

| 问题类型 | 反馈时间 | 处理方式 |
|---------|---------|---------|
| 制度建设建议 | 下次支委会后 | 支委会讨论 |
| 活动组织建议 | 1周内 | 转条条组长 |
| 工作流程建议 | 2周内 | 转块块委员 |
| 其他建议 | 1个月内 | 支委会研究 |

## 五、工作协调与检查清单

### 5.1 工作协调

| 协调对象 | 协调内容 | 协调方式 |
|---------|---------|---------|
| **条条组长** | 活动分工信息、复盘监督、考察记录 | 活动前沟通分工，活动后确认角色 |
| **宣传委员** | 考勤记录提交、活动档案协同 | 定期提交考勤（每月/每季度） |
| **组织委员** | 考察信息交流、党员发展配合 | 倒查时提供考察意见 |
| **支部书记** | 工作汇报、重大问题请示 | 定期汇报，支委会报告 |

### 5.2 工作检查清单

**每周：**
- [ ] 即将召开的三会一课，准备考勤表
- [ ] 活动需记录考察档案
- [ ] 补课安排
- [ ] 意见建议处理

**每月：**
- [ ] 考勤记录完整性
- [ ] 考察档案建立情况
- [ ] 活动复盘完成率
- [ ] 考勤记录提交宣传委员

**学期初/中/末：**
- 学期初：建立模板、制定计划
- 学期中：检查进度、处理反馈
- 学期末：整理汇总、总结汇报
