# Help 页视觉再设计 — Design Spec

- 日期：2026-08-03
- 状态：书记已批准设计（浏览器视觉伴侣逐轮确认）
- 范围：docs/help.html 快速导航 + 正文排版

## 1. 背景与目标

书记对 help 页（系统说明书）视觉设计提出两点不满：

1. **快速导航"罗列无用"**：1.1 页面导航以 7 组 29 张纯文字 quick-card 网格平铺（按角色分组），全面但无层次、无关系表达、无视觉锚点。
2. **剩余正文字体和排版过分单一**：全篇 doc-p 统一 `0.95rem/1.95/#374151/两端对齐`，doc-h2/h3 同构衬线，doc-card 全篇同构白卡，正文只有"段落/表格/列表/提示条"四种形式。

目标：在保留"说明书"可查阅性的前提下，让 help 页视觉层次丰富、扁平化、克制而美观。

## 2. 设计决策（书记逐轮确认）

### 2.1 快速导航 → 矩阵 v4

- 形态：**角色 × 功能域紧凑表格**（替代 quick-card 网格）。
- **扁平化原则（书记明确、全仓库适用）**：党支书不得置于最高/最中心位置；六类角色列完全等宽、同样式、平级，书记列置后。
- 行合并规则（书记指定）：
  - **考勤 + 考察 合并** 为「考勤考察」行；
  - **活动 + 专班 合并** 为「活动专班」行；
  - **专班不与其他合并**（尤其不与统筹合并）；
  - 因此表格为 **4 行功能域 × 6 角色列**。
- 空格子以淡底色填充（#FAFAF9），弱化空洞。
- 公共页面（首页/资料查询/意见反馈/归档库）独立为表格上方的贯通横条。

### 2.2 正文排版 → 风格 A 纯化（克制 + 单点叙事）

- 保留文档结构与 TOC 查阅效率。
- **章眉**：左对齐「红序号 + 衬线大标题 + 红色渐变分隔线 + 左对齐导语」（回归风格 A；**不做**居中标题/居中金线/居中导语——那三连是风格 B，被书记否决）。
- **小节标题**：编号徽章（红色圆角方形，Times 数字，如「4.3」）+ 衬线标题。
- **正文变体**（克制使用，配色收敛为「红=关键、金=引语、灰=正文」）：
  - `要点卡`：左边红条 + 淡红底，承载关键论断，每节最多 1 处；
  - `对比卡`：双列浅灰卡，承载"纵/横线""活动/专班"等两两对比；
  - `查找卡`："遇到具体事务找谁"式功能-角色映射 chips；
  - `金色引语`：小节收尾点睛，全页唯一的叙事流元素（衬线、金左边线）。
- **字体层次**：标题衬线（Noto Serif SC/华文中宋）、正文无衬线（Noto Sans SC）、数字/编号 Times New Roman、引语衬线。

## 3. 详细规格

### 3.1 矩阵结构（help.html 1.1 页面导航内）

```
[公共页面条] 首页 | 资料查询 | 意见反馈 | 归档库
┌─────────┬──────┬──────┬──────┬──────┬──────┬──────┐
│ 功能域   │ 组长 │ 组织 │ 宣传 │ 纪检 │ 成员 │ 书记 │
├─────────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ 活动专班 │ …    │ …    │ ·    │ …    │ …    │ …    │
│ 考勤考察 │ …    │ …    │ ·    │ …    │ …    │ ·    │
│ 宣传与档案 │ ·    │ ·    │ …    │ …    │ ·    │ ·    │
│ 统筹     │ ·    │ ·    │ ·    │ ·    │ ·    │ …    │
└─────────┴──────┴──────┴──────┴──────┴──────┴──────┘
（· = 淡色空格；… = 功能 chip）
```

**行 × 角色功能归属**（29 个功能点全覆盖）：

| 功能域 | 党小组组长 | 组织委员 | 宣传委员 | 纪检委员 | 普通成员 | 党支书 |
|---|---|---|---|---|---|---|
| 活动专班 | 活动写入、复盘提交 | 专班管理 | — | 活动监督复盘 | 活动动态、专班进展 | 工作台 |
| 考勤考察 | 考勤上传、考察上传 | 考察上传、人才库、发展党员 | — | 考勤管理、补课制度、考察管理 | 考勤概况 | — |
| 宣传与档案 | — | — | 宣传任务、项目看板、周报报送、档案归档 | 公邮管理 | — | — |
| 统筹 | — | — | — | — | — | 全局概况、赋权管理、通知发布、反馈管理 |

**跳转映射**（chip 用 `<a>`）：

| 功能域角色 | 目标页 |
|---|---|
| 公共：首页/资料查询/意见反馈/归档库 | index.html / search.html / feedback.html / archive.html |
| 组长（活动写入/考勤上传/考察上传/复盘提交） | workspace/leader.html |
| 组织（专班管理/考察上传/人才库/发展党员） | workspace/org.html |
| 宣传（宣传任务/项目看板/周报报送/档案归档） | workspace/prop.html |
| 纪检（活动监督复盘/考勤管理/补课制度/考察管理/公邮管理） | workspace/disc.html |
| 书记（工作台/全局概况/赋权管理/通知发布/反馈管理） | workspace/secretary.html |
| 成员（活动动态/专班进展/考勤概况） | index.html |

**样式**：新增 `qn-*` 类群（help.html 内联 `<style>`，与现有 doc-* 同文件）。
- `.qn-common`：公共页面横条；
- `table.qn-matrix`：`width:100%; border-collapse:collapse; table-layout:fixed`；
- `.qn-empty`：空格淡色块 `#FAFAF9`；
- `.qn-chip`：白底 + 角色色边框圆角小标签；作为 `<a>` 时带 hover 加深 + `:focus-visible` 轮廓（web-design-guidelines：导航用 `<a>`，focus 可见）；
- 响应式：`@media (max-width:640px)` 表格容器 `overflow-x:auto`，表格最小宽 640px 可横滑。

### 3.2 正文版式结构

**章眉**（每章 doc-card 首部）：
```html
<h2 class="doc-h2"><span class="doc-num">四</span>怎么理解具体的这个组织</h2>
<hr class="doc-divider">
<p class="doc-lead">导语（左对齐 1rem #4B5563，提炼自章首内容）</p>
```

**小节标题**（所有 doc-h3 改为徽章式）：
```html
<h3 class="doc-h3"><span class="doc-h3-badge">4.3</span>扁平化：不靠级别，靠协商</h3>
```

**正文变体类**：
- `.doc-key`：要点卡 `background:#FEF2F2; border-left:3px solid #CE1126; color:#7A0010; border-radius:12px;`
- `.doc-duo`（grid 2 列）+ `.doc-duo-item`（浅灰底 `#FAFAF9` 圆角）+ `.dv` 徽章（Times 纵/横/常规/攻坚）
- `.doc-finder` + `.doc-fmap` + `.doc-fpair`：查找卡
- `.doc-quote`：金色引语 `border-left:2px solid #FFD700; font-family:serif; color:#92400E;`

### 3.4 不动项

- 右侧圆点 TOC（help-entry.js + styles.css L4892+ 的 .help-toc-nav）：**不改**。
- role-hierarchy.js / commissioner-matrix.js 组件本身：**不改**（仅保留在页面原位置）。
- 侧边栏、页眉、页脚：不改。
- 不引入新依赖（矩阵为静态 HTML + CSS；正文变体为纯 CSS）。

## 4. 合规要点（web-design-guidelines）

- 功能 chip 跳转用 `<a>`（非 `<div onClick>`）；提供 `:focus-visible` 可见焦点态。
- 矩阵用语义 `<table>`；表头 `<th>` 标识列含义。
- 标题层级 h2→h3 保持；无跳级。
- hover/focus 动效仅 `transform/opacity/border-color`，无 `transition: all`。
- 编号/数字（章节徽章）用 Times New Roman（`font-variant-numeric` 不需，静态文本）。
- 无 emoji、无硬编码日期格式、无 `...`。
