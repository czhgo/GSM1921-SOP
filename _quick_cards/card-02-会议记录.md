# 📝 会议记录怎么写 - 速查卡

> ⏱️ 阅读时间：2分钟

## 两种情况，两种模板

### 情况 1️⃣：三会一课（正式会议）

**适用于：** 支部委员会、支部党员大会、党小组会、党课

**用什么模板？**
- 使用 `申报材料模板/工作记录类/党支部工作记录.docx`

**必须记录的内容：**
- [ ] 会议时间、地点
- [ ] 主持人、记录人
- [ ] 参加人员名单（签到表）
- [ ] 会议议程和主要内容
- [ ] 讨论要点
- [ ] 决议事项和表决结果
- [ ] 会议照片（至少10张）

**提交时间：** 会后 **3天内** 完成

### 情况 2️⃣：其他活动

**用什么模板？**
- 照片记录 + 简要文字说明即可
- 或使用 `活动总结模板.md`

**基本要求：**
- 照片至少10张（活动全景、讨论场景、重要环节）
- 文字说明：时间、地点、参与人数、主要内容

## 📷 照片要求

| 项目 | 标准 |
|------|------|
| 数量 | 至少10张 |
| 质量 | 不低于1920x1080 |
| 内容 | 全景 + 讨论 + 重点环节 |
| 命名 | 日期-活动名称-序号 |

## ⚠️ 注意事项

- 三会一课记录用于上级审查，要规范！
- 会议记录由宣传委员或指定人员完成
- 记录完成后交给宣传委员归档
