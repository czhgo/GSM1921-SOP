# 支委与党小组定人定责定岗说明

## 一、人员结构与双重身份体系

### 1.1 支委会成员（6人）

| 姓名 | 支委职务 | 是否参与具体事务 | 党小组职务 |
|------|----------|------------------|------------|
| 徐瑗依 | 青年委员 | 否（教师） | - |
| 储子禾 | 支部书记 | 是 | 党小组组长（条条） |
| 王峥旭 | 副书记 | 是 | 党小组组长（条条） |
| 侯嘉嵘 | 组织委员 | 是 | 党小组组长（块块） |
| 闫鑫岳 | 宣传委员 | 是 | 党小组组长（块块） |
| 韩思宁 | 纪检委员 | 是 | 党小组组长（块块） |

### 1.2 党小组结构（3个党小组，6名组长）

#### 党小组设置
- **第一党小组（学术组）** - 面向有志于学术的同志
- **第二党小组（就业组）** - 面向市场化就业的同志
- **第三党小组（就业组）** - 面向金融硕士等发展路径的同志

#### 组长配置
每个党小组设1名组长+1-2名代组长

**特殊说明：** 
- 正式党小组组长：5名支委（除徐瑗依）+ 1名辛长乐（非正式党员，以代组长身份担任）
- 共形成**6名实际承担党小组领导工作的同志**

## 二、"条条"与"块块"双线管理体系

### 2.1 条条（纵向-业务线）管理

**定义：** 按照党小组的功能定位进行纵向管理，侧重于**具体业务推进和活动组织**。

| 条条组长 | 负责党小组 | 主要职责 |
|----------|------------|----------|
| 储子禾 | 第一党小组（学术组） | 党小组日常工作组织 |
| 王峥旭 | 第二党小组（就业组） | 党小组日常工作组织 |
| 辛长乐（代组长） | 第三党小组（就业组） | 协助党小组日常工作组织 |

**条条职责：**
1. 组织本党小组的日常活动（每月至少1次）
2. 落实支委会和支部大会的工作部署
3. 负责本组的具体工作推进和活动组织
4. 关注本组成员的思想动态和成长需求
5. 打造本组的品牌活动和特色项目

### 2.2 块块（横向-职能线）管理

**定义：** 按照支委职能定位进行横向管理，侧重于**制度建设和职能保障**。

| 块块委员 | 支委职务 | 横跨三个党小组的职能职责 |
|----------|----------|-------------------------|
| 侯嘉嵘 | 组织委员 | ①协助党员发展工作<br>②支部信息平台建设<br>③党小组活动工作流建设<br>④思想汇报统计归档 |
| 闫鑫岳 | 宣传委员 | ①宣传与档案制度建设<br>②宣传与档案队伍建设<br>③支部宣传工作统筹<br>④档案归档工作统筹 |
| 韩思宁 | 纪检委员 | ①学习与考察制度建设<br>②监督与议事制度建设<br>③党员出勤与补课规范<br>④意见建议反馈平台建设 |

**块块职责：**
1. 建立并完善本职能领域的制度规范
2. 对三个党小组进行横向的职能指导和监督
3. 统筹本职能领域在支部层面的工作
4. 为党小组活动提供职能支持和保障
5. 确保支部整体工作的规范性和一致性

## 三、双重身份的职责协调

### 3.1 储子禾（支部书记 + 条条组长）

**支委身份职责：**
1. 召集组织支部委员会、支部党员大会
2. 传达贯彻上级决议指示
3. 制定支部工作计划并组织实施
4. 牵头党员发展工作
5. 检查工作执行情况，协调支委分工

**党小组组长身份职责：**
1. 组织第一党小组（学术组）的日常活动和品牌建设
2. 协调第一党小组与相关支部的共建探索

**协调原则：** 以支委职责为主导，党小组工作服从支部整体部署

### 3.2 王峥旭（副书记 + 条条组长）

**支委身份职责：**
1. 协助支部书记组织各类会议
2. 支部书记缺席时代行其职能
3. 监督支委工作开展
4. 牵头落实和监督党小组会
5. 协助分工协调

**党小组组长身份职责：**
1. 组织第二党小组（就业组）的日常活动和品牌建设
2. 探索与相关支部的共建

**协调原则：** 以支委职责为主导，党小组工作服从支部整体部署

### 3.3 侯嘉嵘（组织委员 + 块块组长）

**支委身份职责（职能线）：**
1. 协助党员发展工作
2. 支部信息平台建设
3. 党小组活动工作流建设
4. 思想汇报统计归档

**党小组组长身份职责（具体执行）：**
1. 担任某一党小组的组长，组织该组日常活动
2. 在本组内落实组织委员的职能要求

**协调原则：** 职能线工作横跨三个党小组，在本组内同时履行组长和委员双重职责

### 3.4 闫鑫岳（宣传委员 + 块块组长）

**支委身份职责（职能线）：**
1. 宣传与档案制度建设
2. 宣传与档案队伍建设
3. 支部宣传工作统筹
4. 档案归档工作统筹

**三大工作场景：**

**场景一：支部大会和支委会（个人主导）**
- 支部大会：个人负责找党员、预备党员进行宣传材料和会议档案的归纳整理工作
- 支委会：需要整理会议档案，但**不需要宣传推送**

**场景二：党小组会和其他活动（指导监督）**
- 了解活动组织者中谁负责宣传工作
- 指导宣传材料的准备（格式、内容、标准）
- 监督宣传材料的提交和质量

**场景三：申报材料环节（模板建设）**
- 建立高度可复用的申报材料模板库
- 为支部委员会提供标准化申报材料
- 维护和更新模板，确保合规性和时效性

**党小组组长身份职责（具体执行）：**
1. 担任某一党小组的组长，组织该组日常活动
2. 在本组内落实宣传委员的职能要求

**协调原则：** 职能线工作横跨三个党小组，在本组内同时履行组长和委员双重职责

**详细工作流程：** 参见[宣传委员工作流程指南.md](./宣传委员工作流程指南.md)

### 3.5 韩思宁（纪检委员 + 块块组长）

**支委身份职责（职能线）：**
1. 学习与考察制度建设
2. 监督与议事制度建设
3. 党员出勤与补课规范
4. 意见建议反馈平台建设

**党小组组长身份职责（具体执行）：**
1. 担任某一党小组的组长，组织该组日常活动
2. 在本组内落实纪检委员的职能要求

**协调原则：** 职能线工作横跨三个党小组，在本组内同时履行组长和委员双重职责

### 3.6 辛长乐（党小组代组长 - 条条）

**身份特殊性：** 非正式党员，不能担任支部委员

**党小组代组长职责：**
1. 协助组长组织本党小组日常活动
2. 参与第三党小组（就业组）的品牌活动策划与实施
3. 在实际工作中承担组长等同的工作量
4. 通过工作表现争取早日成为正式党员

**协调原则：** 在党小组层面与正式党员组长同等承担工作，但不参与支委会决策

## 四、工作流程协调机制

### 4.1 纵向协调（条条与块块的配合）

**场景1：组织党小组活动**
1. **条条组长**：负责活动的具体策划和组织实施
2. **块块委员**：
   - 组织委员：提供信息平台支持，归档活动记录
   - 宣传委员：监督指导宣传工作，归档活动材料
   - 纪检委员：记录成员参与情况，纳入考察

**场景2：制度建设**
1. **块块委员**：牵头制定本职能领域的制度规范
2. **条条组长**：在本党小组内试点实施，反馈意见
3. **支委会**：集中讨论，形成全支部制度

### 4.2 横向协调（三个党小组之间）

**统一标准：** 块块委员确保三个党小组在以下方面保持一致：
- 宣传规范和档案标准（宣传委员）
- 考勤要求和考察标准（纪检委员）
- 信息报送和工作流程（组织委员）

**差异化发展：** 条条组长根据本组特点和组织意图，自主确定各党小组的品牌方向和活动内容。

### 4.3 党团班一体化中的协调

**原则：** 活动性质事先认定、过程分工充分沟通、材料产出清晰高效

**具体流程：**
1. **团、班、学组织**发起活动意向
2. **条条组长**评估是否符合党小组定位和组织意图
3. **块块委员**提供职能支持（宣传、组织、监督）
4. **支委会**审批并纳入支部工作计划
5. **党小组**承接活动组织实施
6. **块块委员**负责材料整理和归档

## 六、常见工作场景的操作指南

### 场景1：党小组要组织一次学习活动

**步骤：**
1. **条条组长**（如储子禾）发起活动策划
2. 联系**组织委员**（侯嘉嵘）确认信息平台使用和通知方式
3. 联系**宣传委员**（闫鑫岳）准备宣传材料
4. 联系**纪检委员**（韩思宁）说明考勤要求
5. 组织实施活动
6. 活动后由**条条组长**提交活动总结，**宣传委员**归档材料，**纪检委员**记录考勤

### 场景2：需要建立新的制度规范

**步骤：**
1. **块块委员**（如韩思宁）起草制度初稿
2. 在本人担任组长的党小组内试点征求意见
3. 其他**条条组长**在各自党小组征求意见
4. **块块委员**修改完善制度
5. 提交**支委会**讨论审议
6. **支部党员大会**通过后实施
7. **块块委员**负责监督制度落实

### 场景3：积极分子考察与发展

**步骤：**
1. **条条组长**在本党小组内关注积极分子表现
2. **块块委员**（纪检委员韩思宁）记录积极分子参与情况
3. **块块委员**（组织委员侯嘉嵘）归档思想汇报
4. **条条组长**向**支部书记**（储子禾）反馈考察意见
5. **支部书记**牵头党员发展工作
6. **支委会**讨论决定
7. **支部党员大会**表决

### 场景4：党团班一体化活动

**步骤：**
1. 团支部/班委会提出活动意向
2. 相关**条条组长**评估活动与党小组定位的契合度
3. 确认后，**条条组长**与团班负责人共同策划
4. **块块委员**提供职能支持：
   - **组织委员**：协调信息沟通
   - **宣传委员**：监督指导宣传工作
   - **纪检委员**：明确参与人员和考核标准
5. 活动实施，党小组主导党建内容，团班负责具体执行
6. **块块委员**整理材料，区分党、团、班不同层次的成果归档

## 七、优化建议

### 7.1 加强沟通协调

1. **建立支委-党小组联席会议机制**：每月支委会后，召开党小组组长会议，传达支委会精神
2. **建立块块委员沟通机制**：三位块块委员定期沟通，确保职能工作协调一致
3. **建立条条组长交流机制**：三位条条组长定期交流党小组工作经验

### 7.2 明确工作界面

1. **活动组织权**：归条条组长
2. **制度建设权**：归块块委员
3. **决策权**：归支委会
4. **监督权**：归纪检委员（块块）

### 7.3 工作流程优化

1. **简化审批流程**：党小组常规活动，组长负责制，事后报备即可
2. **强化职能支撑**：块块委员主动为党小组活动提供支持，不等不靠
3. **突出品牌特色**：鼓励条条组长根据本组特点大胆创新，块块委员做好制度保障

### 7.4 人员培养机制

1. **对辛长乐的培养**：明确其作为代组长的职责，提供展示平台，为其转正创造条件
2. **对积极分子的培养**：通过党小组活动参与，考察其能力和态度
3. **对支委的培养**：通过双重身份锻炼，提升全面工作能力
