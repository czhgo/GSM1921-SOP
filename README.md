## 🔧 这个仓库是怎么工作的？

**你所看到的所有指南和模板，都不是手写维护的。** 本仓库运行"**双轨制**"：

- **人工面板（你正在看的这层）**：所有流程指南、速查卡、申报模板，用简洁中文写成，照着做就行。
- **后台控制逻辑（`.vibe_context/` 文件夹）**：AI 协同工作引擎的状态机和规则文件，供书记和 AI 代理维护，普通使用者无需关心。

每次你通过反馈卡提交痛点，书记调整后台规则，AI 引擎会在几分钟内**把所有相关文档一次性改好，不遗漏，不矛盾，有日志可查。**
