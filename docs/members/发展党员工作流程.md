# 发展党员工作流程

根据《中国共产党发展党员工作细则》和学校相关规定制定。

## 一、总体要求

**基本方针**：控制总量、优化结构、提高质量、发挥作用

**基本原则**：
- 坚持党章规定的党员标准
- 坚持慎重发展、均衡发展
- 坚持入党自愿原则
- 坚持个别吸收原则
- 把政治标准放在首位

## 二、发展党员五个阶段

### 第一阶段：申请入党

#### 1. 递交入党申请书

**条件**：年满18周岁的中国公民

**流程**：
- [ ] 本人向党支部递交书面入党申请书
- [ ] 党支部收到申请书后1个月内派人谈话
- [ ] 支部书记或组织委员与申请人谈话

**入党申请书要求**：
1. 对党的认识
2. 入党动机
3. 本人履历和政治历史情况
4. 家庭主要成员和主要社会关系情况
5. 其他需要向党组织说明的问题

#### 2. 确定入党积极分子

**条件**：递交入党申请书6个月以上

**流程**：
- [ ] 党小组推荐
- [ ] 团组织推优（28周岁以下）
- [ ] 支委会（不设支委会的支部大会）研究确定
- [ ] 报上级党委备案
- [ ] 指定2名正式党员作为培养联系人

**材料**：
- 入党申请书
- 推优表（共青团员）
- 入党积极分子确定审批表
- 培养考察登记表

### 第二阶段：入党积极分子的培养教育

#### 时间要求

至少1年以上

#### 培养措施

1. **指定培养联系人**
   - [ ] 了解入党积极分子的思想、学习、工作等情况
   - [ ] 向入党积极分子介绍党的基本知识
   - [ ] 帮助入党积极分子提高对党的认识
   - [ ] 向党支部汇报入党积极分子情况

2. **吸收参加党内活动**
   - [ ] 听党课
   - [ ] 参加主题党日活动
   - [ ] 列席接收新党员的支部大会

3. **分配一定的社会工作**
   - [ ] 参与志愿服务
   - [ ] 承担班级工作
   - [ ] 参与学生组织工作

4. **定期培养考察**
   - [ ] 培养联系人每季度填写考察意见
   - [ ] 党支部每半年分析1次
   - [ ] 入党积极分子每季度书面汇报思想

5. **集中培训**
   - [ ] 参加学院或学校组织的入党积极分子培训班
   - [ ] 学习党的基本理论和基本知识
   - [ ] 培训时间不少于24学时
   - [ ] 考试合格获得结业证书

### 第三阶段：发展对象的确定和考察

#### 1. 确定发展对象

**条件**：
- 入党积极分子培养教育满1年
- 参加入党积极分子培训并考试合格

**流程**：
- [ ] 党小组提出意见
- [ ] 征求党员和群众意见
- [ ] 支委会（不设支委会的支部大会）讨论同意
- [ ] 报上级党委备案
- [ ] 确定2名正式党员作为入党介绍人

#### 2. 政治审查

**审查内容**：
- 对党的理论和路线方针政策的态度
- 政治历史和重大政治斗争中的表现
- 遵纪守法和遵守社会公德情况
- 直系亲属和主要社会关系的政治情况

**方式**：
- [ ] 同本人谈话
- [ ] 查阅档案材料
- [ ] 找有关单位和人员了解情况
- [ ] 必要时外调或函调

**结论**：
- [ ] 形成综合政审材料
- [ ] 由党支部负责人签字盖章

#### 3. 短期集中培训

**要求**：
- [ ] 参加上级党组织组织的发展对象培训班
- [ ] 学习党章、入党教材等
- [ ] 培训时间不少于3天（或24学时）
- [ ] 考试合格获得结业证书

### 第四阶段：预备党员的接收

#### 1. 支部委员会审查

**审查内容**：
- [ ] 入党材料是否齐全规范
- [ ] 培养教育考察是否充分
- [ ] 入党手续是否完备
- [ ] 支委会研究通过后提交支部大会讨论

#### 2. 上级党委预审

**预审内容**：
- [ ] 材料是否齐全、规范
- [ ] 手续是否完备
- [ ] 研究提出预审意见

**预审通过后**：
- [ ] 发展对象填写《中国共产党入党志愿书》

#### 3. 召开支部大会

**会议要求**：
- 有表决权的党员到会人数须超过应到会有表决权党员的半数

**流程**：
- [ ] 申请人汇报个人情况
- [ ] 入党介绍人介绍培养情况并表明意见
- [ ] 支委会报告审查情况
- [ ] 与会党员充分讨论，发表意见
- [ ] 申请人对讨论情况表明态度
- [ ] 采取无记名投票方式进行表决
- [ ] 赞成人数超过应到会有表决权党员的半数，才能通过接收预备党员的决议
- [ ] 支部书记将表决结果告知申请人

#### 4. 上级党委派人谈话

**谈话内容**：
- 了解发展对象的入党动机、对党的认识
- 审查发展对象对党的基本知识的掌握情况
- 征求本人对党需要说明的问题

**谈话后**：
- [ ] 谈话人填写谈话情况和意见

#### 5. 上级党委审批

**时限**：
- 必须在3个月内审批
- 超过6个月未审批的，原审批材料无效

**审批**：
- [ ] 上级党委审批
- [ ] 党委审批意见填入《中国共产党入党志愿书》
- [ ] 通知党支部
- [ ] 党支部将审批结果告知本人和党员

### 第五阶段：预备党员的教育考察和转正

#### 1. 预备期的教育考察

**预备期**：1年

**措施**：
- [ ] 编入党支部和党小组
- [ ] 继续进行教育和考察
- [ ] 参加党的组织生活
- [ ] 分配适当工作
- [ ] 定期汇报思想和工作
- [ ] 党支部每季度讨论1次

#### 2. 预备党员转正

**时限**：
- 预备期满后及时提出转正申请

**流程**：

（1）**本人申请**
- [ ] 预备期满前一周，本人提出书面转正申请

（2）**党小组提出意见**
- [ ] 党小组讨论，提出意见

（3）**征求党员和群众意见**
- [ ] 听取党内外群众意见

（4）**支委会审查**
- [ ] 审查预备党员表现
- [ ] 提出意见

（5）**支部大会讨论表决**
- [ ] 本人汇报预备期表现
- [ ] 支委会介绍考察情况和意见
- [ ] 党员讨论发表意见
- [ ] 无记名投票表决
- [ ] 形成决议
- [ ] 报上级党委审批

（6）**上级党委审批**
- [ ] 必须在3个月内审批
- [ ] 审批后通知党支部
- [ ] 党支部将结果告知本人

（7）**转正后**
- [ ] 材料存入本人人事档案
- [ ] 党龄从转正之日算起

## 三、发展党员材料清单

### 入党积极分子阶段
1. 入党申请书
2. 推优表（共青团员）
3. 思想汇报（每季度1篇）
4. 入党积极分子培养考察登记表
5. 入党积极分子培训结业证书

### 发展对象阶段
6. 征求党员和群众意见记录
7. 政治审查综合材料
8. 直系亲属政审材料
9. 发展对象培训结业证书
10. 公示材料

### 预备党员阶段
11. 《中国共产党入党志愿书》
12. 支部大会接收预备党员的决议
13. 上级党委审批意见
14. 谈话记录

### 转正阶段
15. 转正申请书
16. 预备期思想汇报（每季度1篇）
17. 预备党员考察表
18. 支部大会讨论转正的决议
19. 上级党委审批意见

## 四、注意事项

1. **严格标准**：把政治标准放在首位
2. **程序规范**：严格按照规定程序办理
3. **材料齐全**：各阶段材料完整规范
4. **时限要求**：注意各环节时间要求
5. **民主公开**：充分发扬党内民主
6. **全程纪实**：做好记录存档工作

## 五、常见问题

**Q1：入党申请书应该什么时候递交？**
A：随时可以向党支部递交。

**Q2：可以直接从积极分子发展成正式党员吗？**
A：不可以。必须经过预备期考察，预备期为1年。

**Q3：预备期满能否自动成为正式党员？**
A：不能。必须由本人提出转正申请，经支部大会讨论通过，上级党委审批后，方可成为正式党员。

**Q4：发展党员可否跨支部？**
A：一般不可以。应在本人所在党支部发展。
